- **Software page: keyboard access, Load-more focus and a way in from Hardware.** Title rows now act as buttons (Tab, then Enter or Space opens the per-version drill) and the `versions` and `devices` controls are real buttons. After **Load more** in a devices list, focus moves to the first new row (to the devices filter when the page comes back empty, and back to the button if the request fails). A device's Hardware **Installed software** lens gains an **Open in Software** link into that device's Software host view, and the Software page's device pointer now names that route. Pressing an open **versions** or **devices** control a second time now closes its drill (it re-fetched before), and the expanded state is announced to assistive technology.
