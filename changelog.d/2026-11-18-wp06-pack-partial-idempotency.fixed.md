- **A partially installed product pack no longer answers a retry as a clean success.** `POST /api/product-packs` records its `Idempotency-Key` only when every item installed. A `201` that carried `errors[]` leaves the key unrecorded, so a retry with the same key runs the bundle again and reports its own `errors[]`, instead of returning the half-installed pack's id as a replay. A complete install still replays.
