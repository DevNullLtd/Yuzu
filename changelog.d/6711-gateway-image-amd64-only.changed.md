- **The gateway Docker image (`Dockerfile.gateway`) is now explicitly `linux/amd64` only.** The pinned `erlang:28-alpine` builder index annotates amd64 as Alpine 3.23 but arm64 as Alpine 3.24 (musl 1.2.6), so an arm64 build always failed the builder/runtime ABI guard, but only after the full Erlang build. An arm64 build now stops in its first step with a message that says why and what to do (`--platform linux/amd64`; `Dockerfile.gateway.chisel` is a single-node demo variant that cannot form a cluster). Published gateway images were already amd64-only. A new check, `scripts/ci/check-gateway-base-index.py`, fails a pull request when the pinned index annotates a platform the Dockerfile supports as built on a different Alpine release than the runtime stage (#6711).
