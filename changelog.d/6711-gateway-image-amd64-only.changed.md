- **The gateway Docker image (`Dockerfile.gateway`) is now explicitly `linux/amd64` only.** The pinned `erlang:28-alpine` builder index puts amd64 on Alpine 3.23 but arm64 on Alpine 3.24 (musl 1.2.6), so an arm64 build always failed the builder/runtime ABI guard, but only after the full Erlang build. An arm64 build now stops in its first step with a message that says why and points at `Dockerfile.gateway.chisel`. A new check, `scripts/ci/check-gateway-base-index.py`, fails when a platform the Dockerfile supports is not on the runtime stage's Alpine release in the pinned index (#6711).
