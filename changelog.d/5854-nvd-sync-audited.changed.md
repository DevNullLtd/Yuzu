- **`POST /api/nvd/sync` is now audited.** Each request writes an `nvd.sync.request` audit row (`success`, or `disabled` when sync is off) before the sync is requested; if the row cannot be persisted the request is refused with `503` and no sync starts. That refusal is an A4 error with a `retry_after_ms` hint and carries `Sec-Audit-Failed: true`.
