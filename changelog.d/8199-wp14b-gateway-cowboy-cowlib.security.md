- **Gateway HTTP/2 header-list bound (CVE-2026-113431).** The gateway HTTP/2 stack is cowboy 2.21.0, cowlib 2.22.0 and gun 2.8.0. A request whose decoded header list is over 32768 octets is refused with RST_STREAM `enhance_your_calm` and the connection keeps serving; the bound applies to every listener with no setting, and `http2` does not accept `max_header_list_size`; `max_headers` and `max_fragmented_header_block_size` are accepted keys that no shipped config sets and must stay unset. The one-month dependency pin rule is waived for exactly these three versions; see `docs/security-reviews/wp14b-cowboy-cowlib-gun-age-waiver-2026-11-18.md`.
