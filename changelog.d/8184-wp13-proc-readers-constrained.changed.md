- **Breaking —** **On Linux, `processes.list_hashed`/`list_tree`, `procfetch.fetch` and `netstat.list`/`attribution` now report `CONSTRAINED`/`PARTIAL` instead of a clean `OK` when the agent cannot read another user's `/proc/<pid>/exe` or `fd`.** A non-root agent without `CAP_SYS_PTRACE`, the packaged unit included, cannot read another user's `/proc/<pid>/exe` or `fd`, so those rows have blank path/hash/pid; the status carries `processes:exe_unreadable`, `procfetch:exe_unreadable` or `netstat:proc_fd_unreadable`, so anything that treats a non-`OK` status as a failure will flag those results. Linux only: macOS and Windows denials can still blank rows under `OK`, and other `/proc` readers are not tallied (follow-up). See the WP13 section of `docs/user-manual/upgrading.md`.
