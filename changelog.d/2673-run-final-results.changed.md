- **A run is now `succeeded` only when every intended device answered successfully.** A run with an offline, withheld, failed or timed-out device finishes as `completed`. The first final result from each device stands: a later, different result no longer replaces it and is reported as `late` after a timeout. `agents_failure` includes timed-out devices. On the Executions page, the status filter "With failures" is renamed "Completed, not fully successful". The database migration is automatic; replicas still on the previous build do not record targets, so their runs read `unrecorded`.
