- **Windows `disk_actions partitions` now reads the partition table.** One row per partition `Win32_DiskPartition` reports, with its size, partition type and the drive letters `Win32_LogicalDiskToPartition` maps to it, through the bounded WMI helper, so the `partition` section of the daily device record carries real data on Windows. The read needs no elevation (measured under a non-admin service account). It does not list the 16 MiB Microsoft Reserved partition or folder mount points; an unread drive-letter join marks the section `constrained` rather than showing "none". Linux and macOS still answer `<os>:planned`.
