- **Windows `disk_actions partitions` now reads the partition table.** One row per partition `Win32_DiskPartition` reports, with its size, partition type and the drive letters `Win32_LogicalDiskToPartition` maps to it, through the bounded WMI helper, so the `partition` section of the daily device record carries real data on Windows. The read needed no elevation on the one Windows 11 host it was measured on, under a non-admin service account; other configurations (hardened WMI ACLs, dynamic disks, BitLocker, Storage Spaces) are unmeasured. It does not list the 16 MiB Microsoft Reserved partition or folder mount points; a drive-letter join that could not be read (a failed or unusable association query) marks the section `constrained` and every row's `detail`, so it is not shown as "none". Linux and macOS still answer `<os>:planned`.
