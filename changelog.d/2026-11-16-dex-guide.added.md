- **A DEX (Digital Employee Experience) guide is now in `docs/dex/`.** It is a wiki-style set of pages, one per area (fleet health, signals, application stability, device performance, application performance, network quality, per-device application usage and alerts), plus a collectors and plugins page and a single map of which dashboard page, REST route and MCP tool serves each capability. Each page says what the capability is for, which agent collector or plugin feeds it and how to switch it on or off, and the permission it needs. It describes shipped behaviour only and links the DEX user-manual page for view-level detail.
