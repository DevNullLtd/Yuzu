- **Quiet permission probe.** `AuthRoutes::require_permission` and `require_tier_policy` take an optional `Quiet` argument. A quiet call returns the same verdict, status and body as a normal one but writes no `auth.permission_required` / `auth.approval_required` audit row and moves no denial counter, so a page can ask "may this user do X?" while rendering without filling the audit log with denials. The default is unchanged (loud). A probe is a rendering hint only; action routes still re-check through the normal gate.
