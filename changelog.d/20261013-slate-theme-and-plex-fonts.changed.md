- **The dashboard moves to a new dark slate theme with IBM Plex fonts.** The shared stylesheet replaces the previous navy palette with a slate one: blue is the action colour, and green, orange and red are kept for status. Interface text is set in IBM Plex Sans, replacing Inter, and text in the shared monospace style, such as YAML editors, form text areas and detail values, is set in IBM Plex Mono. The fonts are bundled with the server and served from `/static/fonts/`; the old `/static/fonts/InterVariable.woff2` URL is gone. Buttons, panels, tables, status pills, form fields and the command palette share one set of component styles, every button variant is now a fully styled button with hover, disabled and keyboard-focus states, and chart series colours follow the new palette. Some pages that define their own colours or monospace font keep parts of their previous look until each is restyled. The dashboard now needs a current browser: Chrome or Edge 111, Firefox 121 or Safari 16.2 or later (Safari 16.4 for the fleet map); older browsers still load the pages but lose some state styling, such as hover and selected-row backgrounds. Page routes and behaviour are unchanged.
