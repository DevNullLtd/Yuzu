- **The dashboard moves to a new dark slate theme with IBM Plex fonts.** Every page now uses a slate palette in place of the previous navy one: blue is the action colour, and green, orange and red are kept for status. Interface text is set in IBM Plex Sans and data values such as hostnames, hashes and paths in IBM Plex Mono, replacing Inter. The fonts are bundled with the server and served from `/static/fonts/`; the old `/static/fonts/InterVariable.woff2` URL is gone. Buttons, panels, tables, status pills, form fields and the command palette share one set of component styles, every button variant is now a fully styled button with the same hover, disabled and keyboard-focus states, and chart series colours follow the new palette. Pages, URLs and behaviour are unchanged.
