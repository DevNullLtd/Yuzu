- **A mass echo.db quarantine no longer writes its `echo.db.corruption_quarantined` audit rows one per heartbeat.** The corruption audit gate held a single in-flight slot for the whole server, so when many agents reported a quarantine in the same tick only one was admitted and the rest waited for a later heartbeat. The slot is now per agent: a second report from the same agent while its lookup is in flight is still deferred, but other agents are admitted at once. The per-agent 10-minute row limit, the degraded-store back-off and the durable dedup against the audit store are unchanged.
