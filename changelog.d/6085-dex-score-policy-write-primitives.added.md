- **DEX score policy write primitives (#6085).** The runtime-config store gains a conditional write and a conditional delete on the observed stored text, for non-secret keys, so a later `If-Match` can be enforced in a single statement across server instances. The stored score policy document now carries a `version` field (absent reads as 1); a server meeting a newer version scores under the shipped defaults and reports `unsupported_version`, never a partial document. The policy provider gains a serialised commit-then-install, so overlapping writers on one instance cannot leave an older policy installed. No route, tool or setting changes in this release.
