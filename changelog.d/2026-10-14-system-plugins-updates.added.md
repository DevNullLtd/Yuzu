- **System > Plugins and updates (`/settings/plugins`).** A new admin-only page under the Settings sub-navigation, built over routes that already exist. It shows stored plugin configuration (read-only, with the note that no agent reads these values yet), a four-layer kill-switch lookup (all operating systems, Windows, Linux, macOS) that names the row that decided each layer, product packs, and hosts the existing plugin-signing and agent-update panels. Every new fragment applies the page's admin gate and the REST twin's own permission, and answers a denied or degraded read with an inline note rather than an empty list.
