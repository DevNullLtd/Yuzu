- **The Settings Engine Principals panel now gates on `EnginePrincipal:Read`, as `GET /api/v1/engine-principals` does (#5882).** The panel (`GET /fragments/settings/engine-principals`) used to admit whoever the `/settings` page admits. With RBAC enabled, an account administrator without the grant is now refused and sees a short "needs the EnginePrincipal:Read permission" note, and a non-administrator who holds it (a `Viewer`, for example) can read the panel URL, although the `/settings` page stays administrator-only; an administrator's MCP-tier token now reads the panel as it already read the REST route. With RBAC disabled only administrator accounts are admitted, as before. A refused browser session writes no denial row (the panel auto-loads); a refused token or engine credential does. See [upgrading](docs/user-manual/upgrading.md).
