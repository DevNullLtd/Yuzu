- **Plugin-init-failed alert label bounded to the server's plugin catalogue.** `yuzu_fleet_plugin_init_failed{plugin}` now labels a reported plugin name only when the server's own capability catalogue knows it, and sums every other well-formed name under `plugin="unknown"` (never `other`), so an agent can no longer fill the label cap with invented names and hide a real plugin's init failure (for example Echo) from `YuzuPluginInitFailed`. New gauge `yuzu_fleet_plugin_init_failed_rejected{reason}` counts the agents whose tag carried names that were not labelled (`unknown_plugin`, `malformed`, `over_cap`), published every sweep including 0. The alert expression is unchanged. Names are still agent-reported, so a hostile agent can name a real plugin that has not failed.
