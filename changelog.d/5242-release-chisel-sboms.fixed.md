- **Every release now carries the chisel images' SBOMs inside its signed `SHA256SUMS`.** The release job did not wait for the chisel image builds, so their CycloneDX/SPDX SBOMs were attached only when those builds finished first. 0.14.0-rc2, rc4 and rc6 shipped without some of them, which were added afterwards and are not covered by those releases' `SHA256SUMS`. The release now waits for the chisel builds (a few minutes) and refuses to publish if any expected SBOM is missing. A re-run of an image build also replaces, rather than adds to, its earlier SBOM.
