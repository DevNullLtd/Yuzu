- **The Instructions page gains sets, response templates, import/export and expression-targeted dispatch.** The Definitions tab has a name/plugin/type filter, a New set and Delete set panel with the set assignment on each row, an Import definition dialog (the JSON export document; the unsigned and duplicate-id refusals are shown), per-row Export (JSON) and Templates. `GET /fragments/instructions/templates?id=` lists a definition's response templates behind `InstructionDefinition:Read` (a denial is an HTTP 200 note) and the template create, edit and delete dialogs call the existing REST v1 routes. New, Edit, Delete and the set controls now follow the caller's permission, probed once per capability per render, instead of the administrator role test. The Execute form reads parameters from `GET /api/v1/instructions/{id}` (so they render), shows `grant_secret` and `grant_id` as write-only password inputs, can target a scope expression with Validate and Preview, and confirms with the instruction, target and "will be submitted for approval, not run" when the definition needs approval. Denied permission probes are audited as before, so a page load by a caller lacking a capability writes one denial row per missing capability.
