- **privacy_permissions Windows leg.** Reads each real profile's `CapabilityAccessManager` ConsentStore (the loaded HKU hive first, else the profile's `NTUSER.DAT` under `SeBackup`/`SeRestore`) and the HKLM device toggle for camera, microphone, location and full-disk-access, the most restrictive value winning, with per-app last-used times; it replaces the `unsupported`/`windows:planned` placeholder row released in 0.14.0. The offline `NTUSER.DAT` load is refused for a UNC, non-fixed-drive, reparse-point or reparse-ancestor, redirected, oversized or foreign-owned hive file, and a file whose identity changes across the load is unloaded unread; a ConsentStore change reported during the read refuses that source rather than guessing. The 15 s deadline is cooperative, not a hard cap. The plugin is still off until an operator enables it. An offline mount alters the logged-off profile's hive sequence number and hash.
