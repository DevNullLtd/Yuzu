- **Server capability advertisement for the certificate inventory source.** `RegisterResponse` gains `server_capabilities` (field 9); the server lists `certificate_inventory_v1` on both direct registration and the gateway `ProxyRegister` path, and only while the certificate inventory store is open. An agent sends the source only to a server that lists it, so an older server never receives it. The gateway protobuf modules are regenerated to relay the field.
