- **Server capability advertisement for the certificate inventory source.** `RegisterResponse` gains `server_capabilities` (field 9); the server lists `certificate_inventory_v1` on both direct registration and the gateway `ProxyRegister` path, when the certificate inventory store opened at server start. Agents gate the source on it from the agent collector release onward. The gateway protobuf modules are regenerated to relay the field; upgrade gateways with or before servers, since an older gateway drops it.
