- **Server capability advertisement for the certificate inventory source.** `RegisterResponse` gains `server_capabilities` (field 9); the server lists `certificate_inventory_v1` on both direct registration and the gateway `ProxyRegister` path, when the certificate inventory store opened at server start. Agents gate the source on it from the agent collector release onward. The gateway protobuf modules are regenerated to relay the field; upgrade gateways with or before servers, since an older gateway drops it. The gateway also enforces the capability, fail closed, per upstream connection: it records the capabilities of each connection's latest accepted `ProxyRegister` answer, including replays, and removes the `certificate_inventory` key from a relayed inventory report sent on a connection that did not list it or cannot be identified. The rest of the report is forwarded, and each removal is counted in the new `yuzu_gw_inventory_source_stripped_total{source,reason}` metric.
