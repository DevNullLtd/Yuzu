- **The OpenAPI ecosystem enums are generated from the software catalogue's ecosystem table (#6095).** The ecosystem enum on GET /api/v1/inventory/software, the two software catalogue routes and the three /crypto routes, and the ecosystem list in the /inventory/software description, are generated from kEcosystemFamilies; the published arrays follow the table's order (windows, optional_feature, msi, macos, macos_pkgutil, brew, rpm, deb, apk, pacman, snap, flatpak), so consumers should compare them as sets.
