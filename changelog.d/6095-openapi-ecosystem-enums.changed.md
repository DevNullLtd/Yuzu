- **The `ecosystem` enums in the OpenAPI document now follow the software catalogue's order (#6095).** The set is the same twelve values; the members are now listed `windows`, `optional_feature`, `msi`, `macos`, `macos_pkgutil`, `brew`, `rpm`, `deb`, `apk`, `pacman`, `snap`, `flatpak` (they began `rpm`, `deb`), so clients that derive constants from array position will see them shift and should compare them as sets. This covers `GET /api/v1/inventory/software`, its `/catalogue` and `/catalogue/versions` reads and the three `/api/v1/crypto/...` reads, plus the `ecosystem (a|b|c)` sentence in the `/inventory/software` description; all are now generated from `kEcosystemFamilies`.
