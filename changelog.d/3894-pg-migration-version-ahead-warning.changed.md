- **A server that starts against a database a newer build has already migrated now says so.** `PgMigrationRunner` logs one warning per store (`store '<name>' is at schema v<N> in the database but this binary only knows migrations up to v<M>`) and carries on; it still applies nothing and does not refuse to start, because many releases are additive and an older build can run against them. Builds from before this change stay silent. `docs/user-manual/upgrading.md` gains a general "Rolling upgrade and rollback (every Postgres store)" section (#3894).
