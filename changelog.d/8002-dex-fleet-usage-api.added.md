- **Digital Employee Experience: the REST API now serves fleet application usage per Apps application.** `GET /api/v1/dex/apps/usage` returns, for each application on the Apps list, how many devices ran it, its run time and launches over 30 days, and its crashes and hangs per hour of use, marked as estimated. Figures can be split by platform, management group or device tag, and a figure that is held back is `null`, never zero (an application whose name matches more than one entry also shows a `null` device count). It needs the forensics read permission as well as the DEX read permission (administrators only while RBAC is off), every request that passes parameter validation is audited, and a read that cannot be completed is a `503` that names the reason.
