- **Gateway HTTP/2 stack moved to cowboy 2.21.0, cowlib 2.22.0 and gun 2.8.0 (CVE-2026-113431).** cowlib 2.21.0 and earlier did not enforce `SETTINGS_MAX_HEADER_LIST_SIZE`, so an unauthenticated peer on the agent-facing gateway listener could send an HPACK header block that decoded to an unbounded header list. cowlib 2.22.0 enforces the limit and defaults it to 32768 octets (name + value + 32 per header): an over-limit request is refused with a stream error (`enhance_your_calm`) and the connection keeps serving. The listeners need no setting for it, and `http2` does not accept `max_header_list_size`. gun is raised with it because gun before 2.8.0 does not handle cowlib 2.22.0's `window_changed` result. All three releases are under one month old, so the gateway's one-month pin rule was waived for exactly these three versions by the owner (Fraser Jarvis, 2026-11-17 for cowboy and cowlib, 2026-11-18 for gun); the rule applies to every other pin.
