- **The Result sets create form now clears after a create.** The form's reset was an `hx-on` attribute, which the server's Content-Security-Policy (no `unsafe-eval`) blocks, so the name and device list stayed filled after Create and a second click repeated the request. A script listener now resets the form once the server answers the request. The server replies 200 with an error toast when it rejects a create (for example an unknown device id), so the form also clears then; a failed request (a 4xx or 5xx status or a network error) leaves it filled.
- **The dashboard clears the previous result chart when a new instruction is sent.** The same blocked `hx-on` attribute meant a chart from the last query stayed over the new results until Clear was clicked. The chart is now cleared when you send an instruction, and typing in the instruction box leaves it in place.
