- **Windows MSVC release build no longer fails with `LNK1248` on `libyuzu_server_core.a`.** The server core static library is split into two archives (`yuzu_server_core` and `yuzu_server_routes`), so neither LTO archive approaches the 4 GiB COFF archive limit, and link-time optimization stays on.
