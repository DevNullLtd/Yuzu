- **OIDC sign-in start and callback count against `--login-rate-limit`.** `GET /auth/oidc/start` and `GET /auth/callback` now share the per-source login rate bucket with local login and SAML (default 10 per second per source address; one sign-in uses two requests). A source over the rate gets HTTP 429 with `Retry-After: 1`. Deployments where many users share one source address, such as behind a proxy or NAT that does not preserve the client address, should raise the flag.
