- **The Windows Echo `$Module` signing cache is keyed on file id, size and USN, not the last-write time.** A writer who restored an image's last-write time inherited the old `signed` verdict and signer for a replaced DLL. An image whose USN cannot be read (or is 0, no change journal) is re-verified on every load. Measured on one NTFS host with a standalone harness; ReFS and journal-less volumes were not.
