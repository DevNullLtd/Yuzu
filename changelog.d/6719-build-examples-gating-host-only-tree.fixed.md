- **CI: the `build_examples=false` gating smoke test no longer fails the sanitizer legs on a host-tools-only vcpkg tree.** A sanitizer-triplet install leaves only the host-tool packages in `vcpkg_installed/x64-linux`, which passed the test's directory-exists check and then failed at configure with `Dependency "CLI11" not found`. The test now skips (exit 77) unless that tree contains `share/cli11/CLI11Config.cmake`. On those legs the #4262 guard now reports SKIP rather than running; it still runs where the host-triplet tree is fully populated.
