- **A Guaranteed State delta push (`full_sync=false`) that omits a still-unresolved rule no longer drops that rule's retry obligation (#5547).** The agent used to replace its open acknowledgment application on every push, so a delta that named only some rules forgot the pending, wedged or failed arm of the rules it left out, and the policy generation could then be acknowledged while an omitted rule was still unarmed with nothing left to retry it. A delta now carries the unresolved outcome of every rule it does not name into the new application (pending arms, retained wedges, drained arm failures and per-rule apply failures), so the generation stays held and `yuzu.guardian_arm_failed` keeps counting the rule until a full push, or a push that names the rule, replaces it. A carried failure is not retried by repeating the delta, and the REST and MCP push endpoints do not bump the generation, so a delta at the generation the agent already holds is not followed by an automatic full push: send a full push to repair it. An apply failure with no rule id (a full push's rule-key sweep, key delete or teardown failure) is now inherited by later deltas, on the legacy path too, and cleared only by a full push whose steps all succeed; before, the next delta forgot it and the generation was acknowledged. A boot re-arm failure is recorded against its rule, so an unrelated delta can no longer clear `yuzu.guardian_boot_rearm_unresolved` and a delta that names the rule and arms it cleanly does; only a full push now counts toward the boot catch-up back-off. A push that names the same rule id twice is rejected before anything is changed, and an allocation failure after the agent has begun applying a push now leaves the application latched instead of acknowledgeable. The wedged-rule suppress budget restarts on every replacement, so alternating deltas and full pushes bound a hold by no elapsed time, and `yuzu.guardian_arm_failed` can hold at a nonzero value across omitting deltas, including for a wedge that was adopted or settled before the agent retained it (see the Spark flip gate, AC-11 and AC-15).
