- **Echo rename migration leaves archive-tool text alone.** The lowercase `tar` rewrite in an operator-edited built-in definition no longer touches archive-tool commands, file names, pipes or package lists; the feature name and `tar|snapshot` still rewrite. Shapes the rename script protects that are not ported (`curl tar`, `--entrypoint tar`, `unzip tar`, `zip tar`, `tar/zstd`, `tar archive`, `tar stream` and the prose sentences) are still rewritten in such a row.
- **macOS nstat closing-state opens are stored once per hour.** An open event for a flow first reported already closing is one row per process, remote address and remote port per hour, sharing the poll path's set, so the subscription dump at each restart no longer stores one row per socket; close events are not filtered. A row dropped from the insert-retry backlog gives its hourly key back, so the next sighting in that hour is stored.
- **Bounded agent reads and per-tick bookkeeping.** The `/proc/<pid>/cmdline` read stops at 256 KiB (cut at a UTF-8 character boundary, with no marker), the login-record readers close their session on every exit path, and the hourly de-duplication sets no longer copy 20,000 keys every tick.
- **Byte-budget wording.** The capability catalogue and the retention-tier comment now state what a device over its byte budget removes.
