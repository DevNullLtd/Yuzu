- **firewall plugin gains device containment.** New actions `quarantine`, `release`, `quarantine_status` and `quarantine_allow` on Windows (Windows Firewall rule group + profile default-block, pre-existing allow rules disabled for the duration and restored on release) and Linux (own nftables table applied as one transaction, iptables fallback); macOS (pf anchor with an enable token, true undo) follows once its design note has been reviewed, and the actions answer an unsupported status there until then. The allow set keeps the agent's control channel, DHCP, DNS to the configured resolvers and operator exceptions (address, prefix, port, protocol, direction); the agent verifies the block after applying and rolls back on failure, re-applies containment at start so it survives a reboot, completes an interrupted apply or release at start, and accepts an optional time limit. The existing `quarantine` plugin is unchanged in this release.
