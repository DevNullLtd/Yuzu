- **Console results page is honest about what it shows.** Sorting, paging and Search now read the live filter bar under one newest-wins request scope, so a changed filter is never reverted by a stale link and the latest click is never dropped. Sending a command, or `help`, aborts an in-flight results request, and a late response for an earlier command is ignored. The Search term is part of "Create Group from N Agents" and of the agent count, so a search-only set can be made a group (a Search term also needs read access to responses, as the table does); the count is distinct agents rather than stored rows. A filtered read cut by the 10,000-row read cap now says it is partial, and a group is refused from a partial set (refusals, including "no agents match" and a duplicate name, now appear as a toast). A "View without saved filters" switch shows the data without a View's saved defaults while it is ticked, including the sort, page and Search requests that follow. The summary and pager follow responses as they arrive for up to five minutes after this tab's own Send, without adding a forensics read audit row, and an operator-driven results change closes a stale Create Group form. The hardware list's sort headers and pager use the same newest-wins scope.
