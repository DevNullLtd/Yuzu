- **The filesystem plugin refuses a path it cannot prove is not the agent's own file.** A stat error other than "no such file" on the candidate path, or while scanning a reserved directory for a hard link, refuses (an unsearchable or read-only-mode reserved directory, a listable but unenterable subdirectory and an unsearchable parent all refuse a hard link into them). `/dev/fd/N`, `/dev/stdin`, `/dev/stdout` and `/dev/stderr` are refused on Linux and macOS, and on Windows a write whose not-yet-existing leaf is a junction or other reparse point is refused (that Windows refusal is compiled with MSVC but not executed on Windows). A reserved path is re-resolved at every decision, so a symlink planted later at a reserved name that did not exist yet is followed; a reserved file that does not exist is compared by path string, not by identity, because there is nothing to compare. A path containing a NUL byte is refused. A reserved path the agent cannot stat refuses only a candidate that could be a hard link to it, never an unrelated path. On macOS the `/dev/fd` rule is case-folded and a literal `/.vol/` path is refused; neither is executed on macOS.
