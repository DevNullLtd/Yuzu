- **The filesystem plugin refuses a path it cannot prove is not the agent's own file.** Any stat error other than "no such file" while comparing a candidate with a reserved file, directory or ancestor, or while scanning a reserved directory for a hard link, now refuses (an unsearchable or read-only-mode reserved directory, a listable but unenterable subdirectory and an unsearchable parent were read as "different file"). `/dev/fd/N`, `/dev/stdin`, `/dev/stdout` and `/dev/stderr` are refused on Linux and macOS, and on Windows a write whose not-yet-existing leaf is a junction or other reparse point is refused (that Windows refusal is not executed by this change).
