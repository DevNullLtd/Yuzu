- **Breaking —** **`install-agent-user.sh --no-cap-cleanup` skips stripping file capabilities.** The script never sets file capabilities; the flag only skips the capability strip. The installer exits non-zero when a step fails (1 a root-owned helper or another install step failed, 2 an argument error, an unknown flag or an unsupported OS, 3 the sudoers file failed validation, 5 file capabilities may still be live), and `--check` exits 1 on drift (when a binary exists at the path, a present capability or a `getcap` that cannot verify it is drift; with no binary at the default path the installer skips the capability test and says so). With `--no-cap-cleanup` the install exits 0 even when file capabilities are still live on the binary (it warns on stderr), and `--check` skips the capability test and says so. See the WP13 section of `docs/user-manual/upgrading.md`.
