- **Breaking —** **`install-agent-user.sh --no-cap-cleanup` skips stripping file capabilities.** The script never sets file capabilities; the flag only skips the capability strip. The installer exits non-zero (3 sudoers, 4 systemctl wrapper, 5 capabilities not stripped or not verifiable) and `--check` returns a non-zero exit on drift (6 means nothing drifted but the sudoers file was unreadable to the caller, so it could not be verified). With `--no-cap-cleanup` the install exits 0 even when file capabilities are still live on the binary (it warns on stderr), and `--check` skips the capability test and says so.
