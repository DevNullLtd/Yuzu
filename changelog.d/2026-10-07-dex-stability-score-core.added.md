- **Server: application stability score core.** A pure, transparent stability score for an application or one version of it, from the share of reporting devices affected, per-device-capped crash and hang counts, and an optional version-over-version rate-ratio interval. It returns the four deductions (breadth 60, crashes 20, hangs 8, regression 12 points) alongside the 0-100 score and an excellent / good / fair / poor band (90 / 75 / 60), and withholds the score rather than showing 0 or 100 when the population is too small or the inputs contradict each other. Not yet surfaced: no page, route or API reads it, so there is no operator-visible change.
