- **The shell Settings link now follows the server's own decision.** `GET /api/me` and `GET /api/v1/me` report `effective_role`, `elevated`, `elevated_until` (only while elevated) and `can_access_settings`, computed by the same function `require_admin` uses. Users with an active just-in-time elevation now see the Settings link they can open, and RBAC PlatformEngineer or Administrator-label holders who are not legacy admins no longer see a link that redirects away. Both routes now send `Cache-Control: no-store, private`.
