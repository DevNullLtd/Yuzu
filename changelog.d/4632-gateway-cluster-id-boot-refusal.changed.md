- **Breaking - a gateway whose configured `cluster_id` cannot be represented as UTF-8 now refuses to start (gateway restart required).** The previous gateway started and stamped a wrong value on every stream-status notification. The `YUZU_GW_CLUSTER_ID` text is read in the VM's native name encoding (latin1 in the shipped images); in `sys.config` write a non-ASCII name as a string (`"Z\x{FC}rich"`) or `<<"Z\x{FC}rich"/utf8>>`, because a plain `<<"...">>` holding the character is refused. The boot fails with a critical line that names the source and never prints the value. Check the name before the restart. The breaker thresholds and timeouts are also range-checked now: an invalid value logs a WARN that names the key and takes the default. Refs #4632
