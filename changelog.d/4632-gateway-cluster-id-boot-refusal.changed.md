- **Breaking - a gateway whose configured `cluster_id` cannot be represented as UTF-8 now refuses to start (gateway restart required).** The previous gateway started and stamped a wrong value on every stream-status notification. The name is read from `YUZU_GW_CLUSTER_ID`, which replaces the `sys.config` setting when set; a name with a code point above 16#10FFFF, a surrogate or bytes that are not UTF-8 stops the boot with a critical log line that names the source and never prints the value. Check the configured name before the restart. The circuit breaker timeouts and failure threshold are also range-checked now: an invalid value logs a WARN that names the key and takes the default. Refs #4632
