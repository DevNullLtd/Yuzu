- **A request body of more than 100000 JSON values is refused `400` on the definition import routes and the v1 definition routes (#2146).** The legacy `POST /api/instructions/import`, `POST /api/v1/instructions/import` and the MCP `import_definition` (and every v1 definition JSON body) refuse a body that holds more than 100000 structural values (`[`, `{` and `,` outside a string) with `... too many values`, before parsing it: a 16 MiB body of `[],[],...` built a parse tree of 250 to 430 MiB per request, and a few concurrent ones by a holder of `InstructionDefinition:Write` exhausted the memory of the server. A definition is a few hundred values, so no real document is near the limit. The MCP JSON-RPC envelope is parsed before the tool runs and is not covered by this limit.
