- **The audit trail is now admin-only while RBAC is disabled (#5771).** `AuditLog:Read` joins the authorization topology floor, so on the RBAC-off default a non-admin authenticated session or API token is refused (`403`, audited as `topology floor: non-admin role denied AuditLog:Read`) on `GET /api/audit`, `GET /api/v1/audit`, `GET /api/v1/audit/auth-sample`, `GET /api/v1/engine-principals/audit/no-admin`, MCP `query_audit_log` / `audit_engine_no_admin` and the `yuzu://audit/recent` resource. Previously any signed-in user could read the full trail, including (on the legacy route) each actor's role and source IP. Admin sessions, admin-owned MCP tokens and every RBAC-enabled `AuditLog:Read` holder are unchanged; to give a non-admin the trail, enable RBAC and assign a role holding `AuditLog:Read`.
