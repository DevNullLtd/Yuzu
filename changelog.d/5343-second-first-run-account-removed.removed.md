- **Breaking — the second first-run account and the Windows installer's `/OPERATOR_USER`/`/OPERATOR_PASS` are removed (#5343).** They were written to `yuzu-server.cfg` only and could never sign in on PostgreSQL. First-run setup now creates the administrator only; a fresh install passing either parameter (or an upgrade passing `/OPERATOR_USER=` alone) is refused with exit code 7; create further accounts in Settings → User Management (`POST /api/settings/users`). Upgrades are unaffected; a leftover cfg line is reported at boot.
