- **Echo's roll-up storage substrate is in the agent.** An interned string dictionary, one physical table per source and tier behind the existing tier view names (`$Process_Hourly` and the rest keep their columns), and a transactional fold-time writer that merges events into hourly, daily and monthly rows are built and tested. Nothing opens, writes or reads them, so stored data is unchanged. There are no new settings, and no setting selects between this storage and the existing one.
