- Tokens and principals page (`/access/tokens`): read-only list of API tokens (Active / All, rotation and expiry state, engine credentials marked) and of engine principals with their active credentials and roles, plus the no-administrator role check. The principal panels need `EnginePrincipal:Read` (the same permission as `GET /api/v1/engine-principals`; administrators only while RBAC is off), the revoked principal's free-text detail also needs `AuditLog:Read`, and the check runs only when the caller holds `AuditLog:Read`. Administrators on a cookie session see every owner's tokens; every other caller, including an administrator's API or MCP token, sees their own tokens only. Refused browser sessions write no audit row. A read that does not answer is stated as such, never rendered as empty. Creating, rotating and revoking stay in Settings. New dashboard fragments `/fragments/access/tokens/list`, `/fragments/access/principals/list` and `/fragments/access/principals/detail`.
