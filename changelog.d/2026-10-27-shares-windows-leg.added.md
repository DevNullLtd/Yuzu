- **The shares plugin now reads what a Windows host serves over SMB.** list on Windows enumerates the live shares through NetShareEnum (level 2; level 1 names without paths when level 2 is refused): name, path, kind (disk, print, device, ipc, other), with temporary shares flagged temporary and the administrative ADMIN$, C$ and IPC$ shares flagged special rather than hidden; a stopped Server service is reported as unavailable with a named token, never as an empty list; ACLs are never read. The macOS leg is still planned.
