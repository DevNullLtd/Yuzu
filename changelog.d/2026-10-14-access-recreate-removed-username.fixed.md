- **Creating an account with the name of a removed account no longer claims the password is too short.** Removed accounts keep their name reserved, so adding one again was refused with "Password must be at least 12 bytes" even for a long password. The server now answers 409 with "The account could not be created. The name may still belong to a removed account, or the user store did not answer." and audits `user.create` as denied with the reason `create_refused`. A password that really is too short still gets the 400 weak-password answer.
