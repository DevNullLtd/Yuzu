- **The DEX Scoring tab lets an operator who holds `Infrastructure:Write` (Administrator by default) and `GuaranteedState:Read` view and edit the whole score policy from the dashboard.** It shows the policy in force and edits every parameter: tier edges and names, the four weights, the scoring model parameters and per-application overrides. A refusal is shown against the field that caused it, a stale save is refused without overwriting anything, Preview tier changes lists which applications would change tier before anything is saved, and Reset to defaults restores the shipped policy. It uses the same write permission, validation, revision check and audit rows as `PUT /api/v1/dex/score-policy`, and additionally needs `GuaranteedState:Read`; no API route changes.
