- **The agent's installed-software collector now reads its plugins' status row, per-action constrained policy and manager-to-ecosystem map from shared code and data tables (#6095).** The `pkg_inventory` and `msi_packages` plugins previously each carried their own copy of the `status|<action>|<level>|<tokens>` row writer; both now call one helper in `agents/shared`, which also owns the collector's parse of that row. The collector's per-action "a constrained roster fails the cycle" flag is now a `constrained` column beside `accept_partial` in its action table, and the manager-to-ecosystem map (`homebrew` -> `brew`, `snap` -> `snap`, `flatpak` -> `flatpak`) is a data table. This is a pure refactor: the status-row bytes, the installed-software blob and its hash, skip reasons and log lines are unchanged for every fixture in the unit suites — the Mac- and Windows-shaped sample blobs are digest-pinned — so no operator or server-side action is needed.
