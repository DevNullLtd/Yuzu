- **The agent-count previews now name a filter whose value is too long to be indexed.** `GET /api/v1/management-groups/agent-count-preview` and the MCP tool `preview_management_group_agent_count` return a new field, `unindexed_filter_keys`: the mangled keys (never the values) of any filter whose value is longer than 2048 bytes, an empty array when none is. Such a value is not indexed in newly stored responses, so when the field is not empty `agent_count` can be 0 or an undercount. The field is always present and additive; `agent_count` and every status code are unchanged (#5623).
