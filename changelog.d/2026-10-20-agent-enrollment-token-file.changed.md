- **Windows agent installer writes the enrollment token to a file instead of the service command line.** The installer now writes the token to `%ProgramData%\Yuzu\enrollment-token` (restricted to Administrators and SYSTEM) and configures the service with `--enrollment-token-file`, which the agent reads once at start and removes after its first accepted registration. `/TOKEN_FILE=<file>` is a new installer parameter alongside the existing `/TOKEN=`. The registered service command line no longer carries the token.
