- **Windows agent installer writes the enrollment token to a file instead of the service command line.** The installer writes the token to `%ProgramData%\Yuzu\enrollment-token` (restricted to Administrators and SYSTEM, owned by Administrators) and configures the service with `--enrollment-token-file`, which the agent reads once at start and removes after its first accepted registration. A service registered by this installer no longer carries the token on its command line; a service registered by an earlier installer keeps its earlier command line until the installer is run again with the original `/SERVER=` and `/NOTLS`. `/TOKEN_FILE=<file>` is a new installer parameter alongside `/TOKEN=`; the token must be exactly 64 lowercase hexadecimal characters, and a refusal exits with code 7. The agent accepts a token file only if a 64-hex token is on its first line and the file is owned by SYSTEM/root, Administrators or the account the agent runs as (on Linux and macOS also not group- or other-writable). A token file holding a token the server has expired, revoked or used up is refused on every start until it is replaced or removed. See `docs/user-manual/upgrading.md`.
