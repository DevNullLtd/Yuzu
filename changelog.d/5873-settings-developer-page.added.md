- **Settings > Developer and API page (read-only).** `GET /settings/developer` (admin only) shows the OpenAPI document link with a live operation count, the REST route catalogue with a filter, the permission catalogue with the roles that allow each pair, and the build-embedded plugin manifests with per-OS support. It reads the existing discovery builders in process, so it adds no REST route or MCP tool; the five new fragments are ledgered against their `/api/v1/discover/*` twins.
