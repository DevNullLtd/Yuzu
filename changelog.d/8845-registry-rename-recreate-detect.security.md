- **A Registry spark watch now notices a parent renamed away with the watched path re-created, and a path re-pointed to another key, when the opt-in check is enabled (Windows, #7877 item 31).** Before this, the check took any key that opened at the registered path as healthy, so a renamed parent with a re-created path left the watch Healthy and deaf. Each check now compares the held handle's canonical name with the name recorded at establishment (even when the fresh open is refused) and the path's current name with the held one; a mismatch faults the watch (`registry watch key moved from its path`, `registry watch path re-pointed to another key`, `registry watch hive unloaded`) and the ordinary retry re-opens the path. With the check on, a commit is accepted only when a second read of the key's name agrees with the first (a rename between open and read is retried, never recorded), and names past the first buffer are read through a retry up to 64 KiB. A name that cannot be read or a deleted held key is undecided, never a fault: the agent log says once per episode that the watch is not protected. The check stays OFF by default (`--spark-registry-path-verify-interval`); with it off the only addition is one name read per establishment on the handle already held (a peer measured no audit event for it). The Spark layer is not live in production (`prefer_spark_` is false). Not covered (owner decisions: Dave, no independent adjudicator, 2026-11-26; register in `docs/spark-flip-gate.md`): a rename away and back inside one interval; an undecided check, which an administrator can force to persist (closed by #7877 item 32); a predictable check phase (jitter deferred); an Ancestor-mode watch is never checked. Audit load, measured once on one key: 1 event per check with Registry auditing alone, 6 with Handle Manipulation also on; the confirming second open adds one and four, derived and not measured. This supersedes the "Not covered" clause of `changelog.d/8016-spark-registry-rename-deaf-watch.fixed.md` for a parent renamed away and the path re-created.
