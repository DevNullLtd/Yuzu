- **Settings > Data and retention page (read-only).** `GET /settings/data` (admin only) shows the instruction-response, audit-log and Guardian-event windows the server is actually enforcing, flags a stored value that is not in force, and adds a JSON-to-CSV converter over `POST /api/export/json-to-csv`. `GET /api/v1/settings/data-retention` gains `guardian_event_retention_days` and an `enforced` object (null when a store is not open). Docs now state that `PUT /api/config/<retention key>` is stored but not enforced (#483).
