- **Tag and property edits on the device record go through dialogs.** Add tag, Remove tag, Add or
  edit property, Delete property and Save schema now open a confirmation or form dialog instead of
  a browser prompt. Removing or setting the `service` tag says that it decides which service-scoped
  API tokens can reach the device. The bulk tag bar on the Hardware list asks for confirmation with
  the device count and key before it applies.
