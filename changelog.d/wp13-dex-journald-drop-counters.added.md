- **The Linux DEX journald source now logs how many entries failed the trusted-sender check and when its cursor re-baselines.** Each poll that drops entries logs `dropped N journal entries failing the trusted-sender check` with a running total, and a journalctl failure that re-baselines the cursor logs a gap line (`gap #N since start`) noting that entries between the old cursor and the journal end were not observed. These are log lines, not metrics. They make a wrong coredump identity, or a rotation/vacuum gap, visible.
