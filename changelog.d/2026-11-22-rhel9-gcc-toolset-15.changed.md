- **The RHEL 9 build recipe now uses gcc-toolset-15, the GCC that CI's Linux leg builds with.** `scripts/setup-rhel9.sh` installed and activated gcc-toolset-14, and `dev` no longer built on it: `yuzu_agent_tests` failed to compile, because libstdc++ 14 cannot build a `std::string` set from a `string_view` range. The script now installs gcc-toolset-15 from AppStream and writes it into `~/.config/yuzu/toolchain-env.sh`. To move an existing gcc-14 host, re-run the script, open a new shell and run `./scripts/setup.sh --tests --wipe`, because a build directory keeps the compiler it was configured with. The test that tripped libstdc++ 14 now compiles on 14 as well, and the device-inventory test that faked an interrupted index build now skips, instead of failing, when the test database role cannot write `pg_index`, as the recipe's least-privilege role cannot.
