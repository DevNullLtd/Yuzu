- **New read-only `remote_access_audit` agent plugin — who can log in to a host over SSH, on Linux and macOS.** The single `list` action reports the `sshd_config` values that govern inbound access as written (not sshd's effective policy), a SHA-256 fingerprint and the option names for every public key in each account's `authorized_keys`, and whether the `sshd` service is enabled. It never emits a key comment, an option value or a key-file path. A home or file the agent cannot read is reported as refused with a reason token, never as an empty result. The plugin is Forensics-class: it ships off behind the plugin-config kill switch and is gated at `Forensics:Read` with approval, one device at a time. The Windows leg is a planned placeholder that reports one `unsupported` status row (`windows:planned`).
