- **New read-only `remote_access_audit` agent plugin — who can log in to a host over SSH, on Linux and macOS (the Windows leg is a planned placeholder).** The single `list` action reports the `sshd_config` values that govern inbound access as written (Include files are followed and the first value wins, as in `sshd`; `Match` blocks are counted but not evaluated), a SHA-256 fingerprint and the option names for every public key in each account's `authorized_keys` (a certificate reports the fingerprint of the key it carries, matching `ssh-keygen -lf`), and whether the `sshd` service is enabled. It never emits a key comment, an option value or a key-file path. A home or file the agent cannot read is reported as refused with a reason token, never as an empty result, and a symlinked key file or a network mount is refused or skipped rather than followed. The plugin is Forensics-class: it ships off behind the plugin-config kill switch and is gated at `Forensics:Read` with approval, one device at a time. The Windows leg reports one `unsupported` status row (`windows:planned`) until it ships.
