- **Breaking —** **`install-agent-user.sh --no-setcap` is renamed `--no-cap-cleanup`.** The script never sets file capabilities any more; the flag only skips stripping ones an earlier version set. The old name still works and prints a deprecation warning. The installer also now exits non-zero (3 sudoers, 4 systemctl wrapper, 5 capabilities not stripped or not verifiable) where it used to report success, and `--check` now returns a non-zero exit on drift (it always exited 0).
