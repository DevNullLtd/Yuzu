- **A sidecar whose copy fails part-way no longer leaves a truncated file in a corrupt-database quarantine set.** When a corrupt `echo.db` or `command_dedup.db` is set aside and a `-wal`, `-shm` or `-journal` file cannot be renamed, it is copied into the set; a copy that failed part-way (a full volume) left a partial `<name>.corrupt-<epoch>-wal` that read as the real sidecar. The partial copy is now removed where possible, and the log says whether it was. The copy also no longer runs when anything, a dangling symbolic link included, already sits at the quarantine name: that entry is left as found and the sidecar's content is reported as not kept.
