- Untrusted text is now neutralised before it reaches server and agent logs and audit rows: the unauthenticated `POST /login` failure and lockout log lines, the SAML ACS validation error (log, audit detail and event), the `kek_meta.kcv_alg` value in boot errors, and the journald-sourced DEX subject and reason. `log_key_token` now folds the whole C1 control block (CSI, OSC and the other 8-bit escapes), not just NEL. Postgres connect failures are logged as a fixed cause instead of libpq's text, which could quote a fragment of a URI-DSN password; the agent no longer logs the session id (a bearer credential readable through `agent_logging.get_log`), only a short SHA-256 fingerprint.
