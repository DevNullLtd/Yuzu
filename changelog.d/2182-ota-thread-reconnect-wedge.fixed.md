- **Agent no longer stalls reconnect on the OTA update thread.** The update-check loop waited on `AgentImpl`'s stop flag while the reconnect teardown only signals `Updater::stop()`, so with `auto_update` on (the default) a dropped Subscribe stream left the agent unreconnected until the update interval elapsed. The loop now waits on the Updater's own stop state (condition variable), so teardown joins promptly (#2182).
