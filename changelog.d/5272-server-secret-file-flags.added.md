- **`--postgres-dsn-file` and `--oidc-client-secret-file` read the server's database connection string and OIDC client secret from a file**, so they no longer have to appear on the command line or in the environment, where other local users can read them. The whole file is the value; a trailing newline and a UTF-8 byte-order mark are ignored. The server refuses to start if the file is missing, empty or larger than 64 KiB, or if the matching direct option (`--postgres-dsn`/`YUZU_POSTGRES_DSN`, `--oidc-client-secret`/`YUZU_OIDC_CLIENT_SECRET`) is also set. This works with the usual Docker and Kubernetes secret files. Env: `YUZU_POSTGRES_DSN_FILE`, `YUZU_OIDC_CLIENT_SECRET_FILE`. (#5272)
