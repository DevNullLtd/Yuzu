- The Settings fragments for users, enrolment tokens, pending agents, API tokens, MFA, analytics and access reviews, and the answers of the actions that re-render them, are now sent with `Cache-Control: no-store, private` and `Vary: Cookie`, so neither the browser's HTTP cache nor a shared proxy stores them for another session or for use after a permission is withdrawn. The MFA routes keep their `Pragma` and `Referrer-Policy` headers and gain `Vary: Cookie`. (#6940)
