- **The Windows Echo `$Module` signing cache is keyed on file id, size and USN, not the last-write time.** A restored last-write time does not carry a `signed` verdict and signer over to a replaced DLL. An image whose USN cannot be read (or is 0, no change journal) is re-verified on every load. Measured on one NTFS host with a standalone harness; ReFS and journal-less volumes were not.
