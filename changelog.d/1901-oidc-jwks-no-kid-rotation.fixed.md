- **OIDC sign-in accepts an ID token with no `kid` signed by any of the IdP's first 16 usable signing keys (#1901).** A token with no `kid` member used to be checked against the first published key only, so an IdP that omits `kid` while it publishes several signing keys, as it rotates, had sign-ins refused intermittently. It is now checked against each usable key in turn, at most 16, in the order published (the log says when more were left untried); a token that names a `kid` is still checked against that key alone and refused if the key set lacks it.
