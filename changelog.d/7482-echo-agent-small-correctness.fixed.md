- **Echo: four small agent correctness fixes.** Recovering a source from a corrupt enable flag (`<source>_enabled=true` over an `errored` value) now clears its stored baseline in the same transaction as the flag, resets the perf and per-application samplers' in-memory reading and logs a warning naming the source, so the next collection no longer reports ghost events or one averaged row spanning the errored interval (#1624). Version ordering for the installed-software de-duplication is now a strict weak order, with numeric segments ahead of non-numeric ones and compared by value without integer overflow, so the kept entry no longer depends on enumeration order; a version such as `1a` now ranks above `9` (#7482). A corrupt stored retention clock reading is now counted once per pass under `retention_guard_failed|__implausible_stored__`, with a warning, even when no table has expired rows (#3104). `echo status` now always carries `config|schema_version|<N>` and `config|warehouse_tables_ok|<true|false>`, and a failed warehouse table create is logged at error level (#2626).
