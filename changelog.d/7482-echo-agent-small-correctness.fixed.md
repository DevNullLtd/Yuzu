- **Echo: recovering an errored source no longer replays its errored interval.** Recovering a source from a corrupt enable flag (`<source>_enabled=true` over an `errored` value) now clears its stored baseline in the same transaction as the flag, resets the perf and per-application samplers' in-memory reading and logs a warning naming the source, so the next collection no longer reports ghost events or one averaged row spanning the errored interval (#1624).
- **Echo: installed-software de-duplication keeps a stable entry.** Version ordering is now a strict weak order, with numeric segments ahead of non-numeric ones and compared by value without integer overflow, and same-name entries whose versions rank equal (`1.0` and `1`) are settled by the text of the version, then the publisher, then the install date, so the kept entry no longer depends on enumeration order; a version such as `1a` now ranks above `9` (#1620, #7482).
- **Echo: a corrupt stored retention clock reading is now reported.** Each retention pass that finds one counts it under `retention_guard_failed|__implausible_stored__`, with a warning, even when no table has expired rows, and skips that pass's byte-budget eviction. The pass then re-anchors the reading, so it is normally counted once; it repeats only if the row is corrupted again or the re-anchor cannot be written (#3104).
- **Echo: a failed warehouse table create is now visible in `echo status`.** `echo status` now always carries `config|schema_version|<N>` and `config|warehouse_tables_ok|<true|false>`, and a failed warehouse table create is logged at error level (#2626).
