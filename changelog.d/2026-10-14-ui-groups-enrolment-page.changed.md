- **Settings enrolment panels (Enrollment Tokens, Pending Agent Approvals, Auto-Approve Policies) now look and act like the Groups and enrolment page.** Token expiry is shown in UTC (it was epoch seconds) and the status is a pill, with active tokens first. The approval queue shows when each agent asked to join and gains Forget. Approve all and Deny all ask for confirmation with the total and the first ten hostnames, and are disabled while the list shows only part of the queue. Rules are described by what they match: the hostname and the cloud provider are marked as agent-reported and not verified, address rules are IPv4 only, and a CA fingerprint rule is marked as never matching at this release. The match mode, Enable and Add rule now ask for confirmation, and the Remove confirmation names the rule (so does Disable, which asks only in "all must match" mode). Long lists show the first rows and say how many are not shown. The "unlimited" token warning hides once a limit is typed. Approve and Deny now act only on an agent that is still waiting: on one already decided they answer `409` with the refreshed list and an error message, where they used to overwrite the earlier decision. Enable, Disable and Remove on a rule that moved or changed since the list loaded are refused with `409` and the refreshed list. Token and pending responses are sent with `Cache-Control: no-store, private` and `Vary: Cookie`.
