- **Settings enrolment panels (Enrollment Tokens, Pending Agent Approvals, Auto-Approve Policies) now look and act like the Groups and enrolment page.** Token expiry is shown in UTC with an Active, Expired, Exhausted or Revoked status. The approval queue shows when each agent asked to join and gains Forget. Approve all and Deny all ask for confirmation with the total and the first ten hostnames, and are disabled while the list shows only part of the queue. Rules are described by what they match; the match mode, Enable, Remove and Add rule ask for confirmation (Disable only in "all must match" mode). Long lists show the first rows and say how many are not shown. The "unlimited" token warning hides once a limit is typed. Token and pending responses are sent with `Cache-Control: no-store, private` and `Vary: Cookie`.
