- **Engine principals are default-deny in `GET /api/v1/upload-grants` and in the shared per-agent visibility and dispatch-permission checks.** An engine principal needs RBAC enabled and an explicit grant (`UploadGrant:Read` to list upload grants). `GET /api/v1/upload-grants` answers it `403` with RBAC off or no grant (`503` when the RBAC store is unavailable), the same as the MCP `list_upload_grants` tool; the shared checks return no agents or refuse it instead of treating it as legacy-open when RBAC is off. Human sessions are unchanged. See the Upgrading guide, "Behaviour change: engine principals are default-deny when RBAC is off".
