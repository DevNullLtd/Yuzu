- **Engine-principal default-deny now applies to `GET /api/v1/upload-grants` and the MCP `execute_bundle` tool.** An engine principal needs an explicit RBAC grant (`UploadGrant:Read` for the list, `Execution:Execute` on the target device for a bundle); without one it gets `403` (`503` when the RBAC store is unavailable), the same answer as the REST bundles route and the MCP `list_upload_grants` tool. Human sessions are unchanged.
