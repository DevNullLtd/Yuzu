- **`registry.get_value`, `key_exists`, `enumerate_keys` and `enumerate_values` refuse a per-user hive under `HKU`.** `hive=HKU` with a user or Entra SID read a logged-on user's data without the administrator-or-approval gate that `get_user_value` carries. They now answer `error|per_user_hive_requires_get_user_value` for any first key component that is not machine scope (`.DEFAULT`, `S-1-5-18/19/20`, each also `_Classes`); use `get_user_value`. The four reads also open through the checked walk and refuse a registry link (`error|key_is_link`) instead of following it into another hive, and a `HKLM` or `HKCR` request whose key resolves under `\REGISTRY\USER` gets the same per-user refusal. `key_exists` answers `exists|false` only for a key that does not exist: a link or an unreadable key is an `error|...` line. Windows only.
