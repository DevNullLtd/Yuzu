- **Breaking —** **Linux `services.set_start_mode` now reads the unit's state back and fails if it does not match the requested mode.** After `systemctl enable|disable|mask` it runs `systemctl is-enabled` and returns an error when the state does not match (automatic: not disabled/masked; manual: not enabled/masked; disabled: masked) or cannot be read, so a privileged helper that exits 0 without acting is no longer reported as success. A non-root agent with no root-owned `/usr/libexec/yuzu/yuzu-systemctl` answers `PERMISSION_DENIED` (`services:privilege_unavailable`); on the packaged unit (non-root, `NoNewPrivileges`) that is permanent.
