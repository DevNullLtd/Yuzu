- **Integrations page: webhooks, offload targets and directory sync (System pages).** Three new panels on Settings > Integrations, backed by six admin-only read fragments that also require the matching JSON route's securable (Infrastructure Read, Directory Read). Webhooks and offload targets list by destination host with the full URL on demand, show the newest delivery, open a delivery history, and can be created or deleted; creating one asks for a confirmation that names the destination host and the data the chosen events carry, and says it is not an approval. Directory sync shows Entra ID status from checked reads (a failed read, a never-synced directory and a failed run are separate states), a sync form whose tenant, client and secret are used for that request only, a group-to-role mapping editor that flags a mapping the server did not store, and a lazy, audited user list that is withheld if its audit row cannot be written. Every write calls the existing JSON route; there is no new write route and no new MCP tool.
