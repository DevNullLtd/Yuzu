- **Bounded executable-header readers for the agent (no operator-visible change yet).** New shared, header-only readers parse the Windows PE version resource, ELF headers (program headers, notes, build id, SONAME) and Mach-O headers (thin and universal files, load commands, library id and versions) from an injected byte reader, without loading the image or calling an operating-system version API. Every offset is overflow-checked and every count is capped; each reader has a fuzz target and a seed corpus. Nothing calls them yet: the software component inventory adopts them in a later change.
