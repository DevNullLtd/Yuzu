- **The plugin catalogue (`discover_plugins`, the dashboard help) serves only what the server recognises.** A plugin or action the server's capability catalogue does not recognise is omitted, the agent-reported description is never served, an agent's plugin name, version, description and action list are bounded at registration (a name, version, description or action outside its bound is dropped whole and counted in `yuzu_server_agent_registry_plugin_meta_dropped_total{field}`; the plugin list is capped at 128 entries per agent and the action list at 64 per plugin, and entries past a cap are dropped from the served catalogue and counted), and each entry is the action set most agents report, so one agent cannot add actions or steer a tie (a tied version is left empty).
