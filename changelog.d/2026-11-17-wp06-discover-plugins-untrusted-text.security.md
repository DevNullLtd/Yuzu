- **`discover_plugins` and the dashboard help no longer serve agent-reported plugin text.** An agent's reported plugin name, version, description and action list are bounded at registration (a field outside its bound is dropped and counted in `yuzu_server_agent_registry_plugin_meta_dropped_total{field}`), the plugin description is never served (it was a prompt-injection channel to LLM clients), and the catalogue entry for a plugin is the version/action list most agents report, so one agent reporting many actions cannot override the fleet's entry.
