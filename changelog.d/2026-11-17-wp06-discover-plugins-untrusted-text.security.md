- **The plugin catalogue (`discover_plugins`, the dashboard help) serves only what the server recognises.** A plugin or action the server's capability catalogue does not recognise is omitted, the agent-reported description is never served, an agent's plugin name, version, description and action list are bounded at registration (a field outside its bound is dropped and counted in `yuzu_server_agent_registry_plugin_meta_dropped_total{field}`; at most 64 plugin entries per agent), and each entry is the action set most agents report, so one agent cannot add actions or steer a tie (a tied version is left empty).
