- **A Windows agent build no longer fails at random while copying plugin DLLs (#8926).** The build step that gathers the plugin DLLs into `plugins\` could run while some plugins were still being linked, and failed with `[WinError 32] The process cannot access the file because it is being used by another process` on those DLLs. It now waits until every plugin has linked. A plugin added to the build must append its library to `yuzu_plugin_libs` in its `meson.build`; a lint (`tests/test_deploy_dlls_plugin_depends_lint.py`) fails if one does not.
