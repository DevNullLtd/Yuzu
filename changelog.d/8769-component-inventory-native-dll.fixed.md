- **`component_inventory`: `native` no longer lists files whose header says they are not libraries.** A stated non-library type now gives no row on every OS, also when the rest of the file is damaged (on Linux and macOS intact files of those types already gave none): an ELF that is not a shared object, a Mach-O that is not a dylib, and on Windows a `.dll` whose PE header does not set `IMAGE_FILE_DLL`, such as a renamed executable or some .NET application entry assemblies (`pwsh.dll`). (#8769, #8784)
