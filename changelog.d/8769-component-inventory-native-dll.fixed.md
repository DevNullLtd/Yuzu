- **`component_inventory`: `native` no longer lists files whose header says they are not libraries.** On every OS a stated non-library type now gives no row, also when the rest of the file is damaged: an ELF that is not a shared object, a Mach-O that is not a dylib, and on Windows a `.dll` whose PE header does not set `IMAGE_FILE_DLL`, such as a renamed executable or a .NET application's own entry assembly. (#8769, #8784)
