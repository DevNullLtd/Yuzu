- **DEX Trends: the "By operating system" cards no longer pin their "Collects N of M signal types" line to a 220 px width on windows 1440 px wide or narrower.** A leftover dashboard rule in the shared stylesheet (`.scope { width: 220px !important }`) matched that line, so at those widths it wrapped inside a 220 px column on each card instead of using the card's width, and each card was one line taller.
