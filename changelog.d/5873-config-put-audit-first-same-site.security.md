- **`PUT /api/config/{key}` is audited before it changes anything, refuses cross-site browser writes, and keeps `heartbeat_timeout` at 30 seconds or more.** An `attempted` `config.update` row is written first; if it cannot be stored the change is refused with `503` and `Sec-Audit-Failed: true`, and a `success` (or `failure`) row follows, so each call leaves two rows. A lost outcome row leaves the change applied and sets `Sec-Audit-Failed: true`. A session-cookie call must carry an `Origin` or `Referer` naming this site (or a `--csrf-trusted-origin` entry), else `403 cross-site request refused` (audit `csrf.denied`); API and MCP token callers are unaffected. `heartbeat_timeout` below 30 is refused with `400` because a shorter window than the default 30 second agent heartbeat disconnects directly connected agents repeatedly. The Developer page fragments are admin-only like the page itself, and the role grid no longer writes a denial row on each load. The server's live heartbeat timeout is now read and written atomically.
