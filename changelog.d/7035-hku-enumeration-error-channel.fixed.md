- **A failed or unstable listing of the loaded user hives (`HKEY_USERS`) is no longer read as a complete list on Windows.** The `registry`, `installed_apps`, `license_scan`, `autoruns` and `privacy_permissions` plugins and Echo's mapped-drive history and start-up hive sweep took whatever `HKEY_USERS` enumeration returned, so an enumeration error part-way, or a hive loading or unloading during the walk, could make a logged-on user look logged off and send their profile down the offline-mount path, or hide a leftover mount from the sweep. The listing is now read until it is stable, and a failure is reported as `hku_list_incomplete` (an `error|hku_list_incomplete` line for `registry` and `installed_apps`, a constraint on the per-user sources for `autoruns`, `license_scan` and `privacy_permissions`, a skipped per-user leg with a warning for Echo's mapped drives). A run that previously returned partial per-user data from a failed listing now reports that failure for that run. Echo's start-up sweep retries once at the first offline mount, then logs one warning and completes.
