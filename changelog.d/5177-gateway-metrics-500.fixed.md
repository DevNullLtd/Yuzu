- **The gateway's Prometheus endpoint works again.** From 0.14.0-rc1, every scrape of the gateway's `:9568/metrics` returned HTTP 500, because five metric descriptions contained a non-ASCII dash that the Prometheus text formatter can't encode. Every gateway metric and the whole `yuzu-gateway` alert group were blind, including the management-plane authentication alerts, and `YuzuGatewayDown` fired while the gateway was healthy. A test now renders every gateway metric the way a scrape does and requires ASCII descriptions. (#5177)
