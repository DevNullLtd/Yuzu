- The server now refuses to start a Postgres store whose recorded migration differs from this build's (#7158). The migration runner records the SHA-256 of each migration it applies and checks it on every start; a mismatch means the database applied different SQL, and the store logs the version and both hashes and does not open. This affects development and UAT databases that applied an earlier build of an unreleased migration; see "the server refuses to start when a recorded migration differs from this build" in the upgrade notes.
