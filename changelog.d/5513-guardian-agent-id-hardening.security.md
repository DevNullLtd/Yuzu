- **Agent-supplied values on registration and related log lines can no longer start a new log line.** On the registration, update-check and update-download request logs, the agent certificate signing logs on the registration path, the agent registry's registration and revoke logs, the command-completion logs, the gateway stream-status, command-drop and Guardian-forwarding logs, the custom-properties store's and the tag store's database error text, agent ids and tag keys, the custom-properties store's invalid-pattern warning, the runtime-config route's store error and key logs, the database pool's connect-failure and transaction-start failure text, and the Guardian ingest warnings, line breaks and control characters in agent-supplied values are folded. Agent ids, the hostname on the registration line, command ids, the plugin name on the command-response line, Guardian observation types and action names, and the cluster id on the command-drop line are additionally folded to a closed character set, so they also cannot add a same-line `key=value` token. Tag keys, store and database error text (including the Guardian ingest error text), and the gateway node names, cluster ids, session ids and plugin names on the gateway stream-status, heartbeat and inventory lines keep spaces and `=`, so a same-line token can still be forged there; the update-download admission and identity-rejection lines likewise replace only control characters. Log lines that print an id read back from the session table or the enrollment store (the Heartbeat, BatchHeartbeat, ReportInventory and ProxyInventory ingest paths and the shared ingestion modules they call, the Subscribe stream open and close lines, and the agent registry's other log lines that print a session-table id (removal, rollback, session-timeout, sweep and dispatch-routing lines)) print it as stored. The enrollment store's agent-id check refuses control bytes and `,` but accepts a space, `=` and non-ASCII characters including U+0085, U+2028 and U+2029, so a legacy or imported id can add same-line `key=value` tokens and, for a log reader that also splits on those code points, extra lines. The exception text of the ingest catch-alls is printed as is.
