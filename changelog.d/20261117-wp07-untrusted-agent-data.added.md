- **Warning when the PostgreSQL database is not UTF8, and an alert for skipped policy targets.** The server logs an error once at start and sets the gauge `yuzu_pg_server_encoding_not_utf8` to 1 when the database encoding is not UTF8 (warning only; it keeps starting), with the alert `YuzuPgServerEncodingNotUtf8`; the alert `YuzuPolicyCollectSkipped` fires when the policy collect pass skips targets or items (`yuzu_server_policy_eval_errors_total{phase="collect_target"|"collect_item"}`). The counters `yuzu_server_policy_unevaluable_responses_total{reason}` and `yuzu_agent_plugin_output_dropped_total{plugin}` (agent-local) are new.
