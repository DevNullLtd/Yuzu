- **OIDC sign-in now works with IdPs whose endpoints are not the derived ones, and verifies ID tokens against the IdP's own JWKS (#5692).** The server pre-set the authorization and token endpoints from the issuer URL, which skipped OIDC discovery, so `jwks_uri` was never learned (every ID token failed signature verification) and an IdP such as Keycloak returned 404 at `/auth/oidc/start`. The three endpoints are now read from `{issuer}/.well-known/openid-configuration` on first use, with no fallback: the document's `issuer` must equal the configured issuer exactly and every endpoint must be an absolute URL on the issuer's scheme, otherwise the sign-in fails closed. The Settings "Test Connection" button applies the same validation and also fetches the JWKS. Discovery and JWKS requests are bounded (5 s timeouts, 256 KiB, no redirects). The unused `exchange_script` plumbing is removed. See the upgrading guide: the server must now reach the issuer host at sign-in time.
