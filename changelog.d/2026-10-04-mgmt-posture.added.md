- **New read-only `mgmt_posture` agent plugin — whether a device is enrolled in mobile-device management or joined to a directory, on Linux and macOS (the Windows leg is not read yet).** The single `posture` action reports facts only and changes nothing. On Linux it reads `/etc/sssd/sssd.conf` and `/etc/sssd/conf.d/*.conf` for the active SSSD domains and classifies the directory plane as Active Directory, FreeIPA, LDAP or other, and reports whether `/etc/ipa/default.conf` and `/etc/krb5.keytab` are present; it reports the configuration as written, not the live join state. On macOS it reads MDM enrolment from `profiles status -type enrollment`. A configuration file the agent cannot read reports `permission_denied` with a reason, never "not joined", and a failed or partial read reports a constrained status with a token instead of an empty result. The Windows leg reports one `unsupported` status row (`windows:planned`) until it ships.
