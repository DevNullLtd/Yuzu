- `scripts/test/coverage-gate.sh` now configures the coverage build with `pkg_config_path` as well as `cmake_prefix_path`, on a fresh build directory and when reconfiguring an existing one (the link no longer fails on undefined c-ares or zlib symbols, #5803). It also runs `meson test` with a validated `--timeout-multiplier` (default 3; `YUZU_COVERAGE_TIMEOUT_MULT` overrides, a non-positive or non-numeric value is refused up front) so instrumented tests are not cut off before their coverage data is written, deletes stale `.gcda` counters before each run so tests that did not run cannot keep contributing coverage, and no longer passes `--branches` to gcovr (a text-report-only option that gcovr 8.7 removed).
