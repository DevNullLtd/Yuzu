- `scripts/test/coverage-gate.sh` (the local `/test` coverage gate) now passes `pkg_config_path` as well as `cmake_prefix_path`, on a fresh build directory and when reconfiguring an existing one, which fixes the undefined c-ares/zlib link errors (#5803). It also runs `meson test` with a validated `--timeout-multiplier` (default 3; set `YUZU_COVERAGE_TIMEOUT_MULT` to a number of at least 1), clears stale `.gcda` counters before each run, and no longer passes `--branches`, which gcovr 8.7 removed. A second concurrent run on the same build directory is refused, a run with failed or timed-out tests, libgcov counter-write errors or a nearly full disk is reported as inconclusive (WARN, no metric, no baseline comparison or capture) instead of as an ordinary figure, an unknown line figure is no longer recorded as 0.0, and a failed gate or metric DB write now fails the gate (#6112, #6113, #6114).
