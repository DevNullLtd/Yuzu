- **Installed-software daily sync: a skipped cycle is now visible and retried sooner.** A failing inventory action still skips the whole report (nothing is deleted), but the agent now records why (`sync.<source>.last_skip` / `sync.<source>.skip_streak`, the count of consecutive skips, in its `__sync__` state) and publishes it on every heartbeat as `yuzu.sync.installed_software.skip_streak` and `yuzu.sync.installed_software.last_skip` while it is skipping; the retry is phase-aligned and backs off (doubling from 1 h, never past the next daily slot — up to four extra attempts), then returns to one attempt at the daily slot until a collection succeeds. A `constrained` Homebrew `managers` answer that still names a present prefix no longer skips the cycle (the constraint concerns facts the presence row never carried); any action whose typed result completeness is PARTIAL now does, unless its table row opts in. An absent non-anchor inventory plugin is logged at warn, a second plugin file declaring an already-loaded name is rejected at scan (`yuzu_agent_plugin_rejected_total{reason="duplicate_name"}`, first file wins), and a unit test pins the collector's action table against the real plugin descriptors.
