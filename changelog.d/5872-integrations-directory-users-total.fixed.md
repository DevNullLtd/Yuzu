- **The Integrations directory user list no longer invents a total when the count fails.** If the user COUNT could not be read, the note said "Showing 200 of 201 users"; it now says "Showing 200 users; more exist (total unavailable)." The timestamp renderer also uses `std::format` instead of a fixed buffer.
- **`DELETE /api/webhooks/{id}` and `GET /api/webhooks/{id}/deliveries` answer `404` for an id too large for a 64-bit integer** instead of a bare `500`; the delete is audited as `webhook.delete` with `not_found`. A failed audit write for the outcome of a webhook, offload-target, directory-sync or group-mapping change now marks the (still `2xx`) response `Sec-Audit-Failed: true`.
