- **Run several native UAT rigs at once.** `scripts/uat-netns.sh run <rig> -- <command>` runs a rig in a private network and PID namespace (bubblewrap), so rigs that all bind 8080/50051 no longer clash; they share one unix-socket-only Postgres container with a database per rig. `scripts/start-UAT.sh` gains `YUZU_UAT_PG_DSN` to use an existing Postgres instead of its `:15433` Docker sidecar. Linux only; not a sandbox. See `docs/uat-environment.md` "Concurrent rigs".
