- **A silent uninstall of the Windows agent or server now finishes.** The uninstaller asked "Remove … data directory?" with a message box that `/SUPPRESSMSGBOXES` does not suppress, so an unattended uninstall (`/VERYSILENT` or `/SILENT` from SCCM, Intune, GPO or a script) waited forever on a dialog nobody could see. A silent uninstall now skips the question and keeps the data directory, the same as the prompt's default answer. That directory holds live credentials: `%ProgramData%\Yuzu` has the agent's identity and mTLS private key, and `%ProgramData%\Yuzu Server` has the server's databases, configuration and TLS keys. To decommission a device, revoke its certificate on the server and delete the directory (see `docs/agent-bundle.md`). An interactive uninstall still asks. The fix is in the new uninstaller, so upgrade a device before uninstalling it silently: uninstallers from releases up to 0.14.0-rc2 still hang. A failed server configuration step during a silent install no longer waits on a message box either; it is written to the setup log. (#5147)
