- **A silent uninstall of the Windows agent or server now finishes.** The uninstaller asked "Remove … data directory?" with a message box that `/SUPPRESSMSGBOXES` does not suppress, so an unattended uninstall (`/VERYSILENT` from SCCM, Intune, GPO or a script) waited forever on a dialog nobody could see. A silent uninstall now skips the question and keeps the data directory (`%ProgramData%\Yuzu` or `%ProgramData%\Yuzu Server`), the same as the prompt's default answer; delete that directory yourself if you want it gone. An interactive uninstall still asks. (#5147)
