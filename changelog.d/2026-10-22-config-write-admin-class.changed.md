- **Config writes by MCP-tier tokens now follow the same per-key refusals as the settings routes.** `PUT /api/config/{key}` now refuses an MCP-tier token, a service-scoped token and a session whose effective role is not `admin` for `plugin_signing_required` and the `dex_alert_routing`, `dex_blast_*` and `dex_cohort_export_key` keys, matching the administrator-only Settings routes that write them. The refusal is audited as `config.update / denied`. The `oidc_*` rule is unchanged, and the other keys stay writable under `Infrastructure:Write`.
