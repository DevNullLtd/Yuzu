- **Plugin enablement store (ADR-3006).** The plugin-config store gains durable enablement rules, per-endpoint desired and reported state and a continuity anchor file `enablement-anchor` beside the server data; `/readyz` and `/healthz` report the store, a pending regression and an unwitnessed anchor. New `yuzu_server_enablement_*` metrics and a `yuzu-enablement` alert group cover rejected rules, unresolved units, regression and report-ahead endpoints. No operator surface yet; rules are authored by a later release.
