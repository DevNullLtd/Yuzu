- **A new `file_search` agent plugin finds files and directories by name across the local disks of a device and reports the extents of every matched file.** Its `search` action takes an absolute root, a leaf-name pattern (`*` and `?`, no regex) and what to match, and answers one slice per call with a cursor to resume from, a per-volume coverage row and a verdict that says whether everything under the root was searched, so an empty result is never confusable with a failed or partial one. It reads names, types, sizes, times and extents only: a matched file is opened and never read, and no file content is read or hashed. Linux and macOS ship constrained legs (names compare byte for byte on Linux and by Unicode normalisation and case folding on macOS); the Windows leg is planned and answers one unsupported status row. The plugin is off until an operator enables its kill switch (`PUT /api/v1/plugin-config/file_search/kill-switch`). An administrator can launch a search and anyone else needs one approval for the whole search over MCP: the first slice spends it, and each later slice that carries the cursor, from the same caller with the same arguments, rides it for 24 hours, or until the approval's 7-day lifetime ends, whichever comes first (a catalogue row declares its resume parameter, so the approval rule of no other action changes, and the audit rows of every ticketed MCP `execute_instruction` call now end with ` approval_id=<id>`). The cursor is dispatched unchanged and erased from the execution record and from the `execute_instruction` approval's recorded arguments, and a schedule that carries one is refused; a cursor placed in a bundle step or a definition run stays in that approval's arguments, and the cursor each slice issues is stored as a `cursor` row in the Forensics tier, sealed so that no stored copy of it shows a name the search found. What a search stores is Forensics-tier and is readable only with `Forensics:Read` (the Administrator and ForensicsAnalyst roles by default, Administrator only while RBAC is off).
