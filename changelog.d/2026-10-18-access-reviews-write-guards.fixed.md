- **Opening, attesting and closing an access review now refuse cross-site browser writes.** `POST /api/v1/access-reviews`, `POST /api/v1/access-reviews/{id}/attestations` and `POST /api/v1/access-reviews/{id}/close` refuse a cookie session whose `Origin` or `Referer` does not name this site (`403`, audited as `csrf.denied`), and the first two accept only `application/json` (`415`). API-token callers are not affected by the same-site rule. The dashboard and the Settings panel already send both, so they keep working; a script that drives these routes with a session cookie and no `Origin` header should switch to an API token.
