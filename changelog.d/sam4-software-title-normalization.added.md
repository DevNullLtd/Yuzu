- **The server now normalises every distinct installed-software title into a permanent title dimension.** An hourly job turns each raw (name, publisher, ecosystem) title into a publisher, product, edition, category and package-URL type, using a versioned alias pack held in Postgres (a provisional seed ships with the server and is loaded on first boot only if no pack exists). Titles the pack cannot resolve are labelled unnormalized and queued for curation, weighted by device count, never guessed; editions are distinct products, so an alias binds one edition and a title is never matched to a neighbouring edition. Automatic creation of new products is off. The job exposes `yuzu_software_titles`, `yuzu_software_unnormalized_ratio`, the curation queue size, the loaded pack version and its own run, duration and last-success metrics, with two alert rules (stale and failing) sized to the hourly cadence. This change adds no REST, MCP or UI surface.
