- **.NET and JVM runtimes are inventoried on Windows and macOS, and join the daily software sync on every OS** (ecosystems `dotnet` and `jvm`, appended to the end of the ecosystem enum). **`hardware.drivers_inventory`** lists installed drivers (Windows `Win32_PnPSignedDriver` with signer, signed state, INF and hardware id; Linux kernel modules with version and taint-derived signed state) as stable-ordered, bounded rows beside the existing `drivers` action.
