- **The installed-software read routes now return `package_id`.** Each row of `GET /api/v1/inventory/software`, the per-host software list, the JSONL export and the `query_installed_software` MCP tool carries a `package_id` string (the Windows Installer product code on `msi_packages.list_inventory` rows, an empty string when the source sets none). The list CSV and XLSX export grow from 23 to 24 columns, with `package_id` as the last column, so a consumer that pinned a column count or position must read by header name. The OpenAPI row schema and the MCP output schema declare the field. The catalogue and per-version routes serve title and version rollups with no install row, so they are unchanged.
