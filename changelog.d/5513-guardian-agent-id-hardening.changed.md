- **Agent registration refuses more malformed ids, and the custom-properties store matches the tag store.** `Register` and `ProxyRegister` now refuse an `agent_id` containing a NUL byte with `INVALID_ARGUMENT`, counted as `yuzu_register_invalid_agent_id_total{reason="nul"}`. An id with a control byte or `,` now logs at warn level and is counted as `reason="control"` instead of being logged as an enrollment store failure; the response is unchanged. The eight `yuzu_register_invalid_agent_id_total` series (four reasons, direct and gateway) are present at 0 from boot. The "Agent registered" log line now quotes the hostname. A custom-properties `PUT` or `DELETE` for an `agent_id` that is empty, contains a NUL byte or is longer than 256 bytes now returns 400 or 404, and reads answer empty, as the tag store already does. The new-id charset rule also holds at the point a row would be created: if a legacy enrollment row is removed between the status read and the write, the write is refused with the same `INVALID_ARGUMENT` and `reason="charset"` count, and the token use is not consumed.
