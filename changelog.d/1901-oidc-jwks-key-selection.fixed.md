- **OIDC sign-in accepts an ID token with no `kid` signed by any of the IdP's first 16 signing keys, and refuses RSA signing keys under 2048 bits (#1901).** A token with no `kid` member used to be checked against the first published key only, so an IdP that omits `kid` while it publishes several signing keys, as it rotates, had sign-ins refused intermittently. It is now checked against each usable key in turn, at most 16, in the order published; a token that names a `kid` is still checked against that key alone and refused if the key set lacks it. A JWKS key whose RSA modulus is under 2048 bits is skipped when the key set is parsed (the log line reads `failed to parse JWK kid=... (RSA modulus under 2048 bits)`) and the other keys are kept, so a weak or downgraded key can no longer verify a token. Operator action: none for an IdP that publishes 2048-bit or larger keys, which is every mainstream IdP; an IdP that serves a smaller key must re-issue it.
