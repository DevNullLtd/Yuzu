- **The agent now syncs installed software in a nightly window and catches up gently after a missed sync.** Installed software reports at a stable per-agent moment between 01:00 and 05:00 in the endpoint's local time (a built-in default; there is no setting for it yet), instead of at a phase offset of the 24 hour interval. A sync that is more than 15 minutes overdue, because the agent was off or the machine slept, is spread over the next 30 minutes rather than sent at once. The `__sync__.now` command also accepts a comma-separated list of sources (all-or-nothing) and an optional `delay_max_s` (0 to 86400) that spreads the forced report by a stable per-agent offset; no server surface sends `delay_max_s` yet.
