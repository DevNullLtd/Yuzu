- **The agent's `__sync__.now` command takes a list of sources and an optional `delay_max_s`.** `source` may be a comma-separated list (all-or-nothing: any unknown name fails the command and arms nothing), and `delay_max_s` (0 to 86400) fires the forced report at a stable per-agent offset within that many seconds instead of at once. No server surface sends either yet, and an agent from before this change ignores `delay_max_s` and rejects a list.
