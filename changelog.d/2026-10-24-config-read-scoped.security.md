- **Breaking: `GET /api/config`, `GET /api/v1/config` and `get_runtime_config` show only the overrides the caller could write.** An MCP-tier token or a non-administrator holding `Infrastructure:Read` no longer receives `oidc_admin_group` or the other administrator-only overrides (the `oidc_*` keys, `plugin_signing_required`, the DEX alert keys and `audit_retention_days`), and an elevated-only session no longer receives the `oidc_*` keys. An administrator account's `GET /api/config` body is unchanged. The v1 route and the MCP tool also list the withheld keys in `withheld_keys`, so a client can tell "not shown to you" from "not set".
