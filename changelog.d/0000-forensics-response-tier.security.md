- **Stored responses from Forensics-tier plugins are now served only to callers holding `Forensics:Read`.** The filter applies on every REST, MCP and dashboard path that reads stored responses, and other readers see those rows as absent, with counts, caps and filter options computed over the rows they may read. Callers that held only `Response:Read` (the Viewer, Operator, PlatformEngineer and ITServiceOwner roles, and every non-administrator session while RBAC is off) no longer receive them. A read that serves such rows also writes a `response.forensics.read` audit row. See "Behaviour change: stored responses of Forensics-tier plugins need `Forensics:Read`" in the upgrade guide.
