- The pre-auth body cap and the MFA step-up chokepoint now run from a wrapper the route sink puts around each handler it registers, after the request body is read, instead of from an httplib pre-request handler; `server.cpp` installs the stage and the route sink runs it, so its position no longer depends on the cpp-httplib version (httplib 0.47 and later run a pre-request handler before the body is read). The route sink now fails closed: registering a route on a server with no stage installed refuses to start the server, and only the plaintext redirect listener is exempt. No change in behaviour on the shipped cpp-httplib, no operator action.
