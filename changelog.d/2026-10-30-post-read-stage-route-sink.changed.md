- The pre-auth body cap and the MFA step-up chokepoint now run as a handler wrapper installed by `HttplibRouteSink` after the request body is read, instead of as an httplib pre-request handler, so their position in the request no longer depends on the cpp-httplib version (httplib 0.47 and later run that handler before the body is read). `HttplibRouteSink` now fails closed: registering a route on a server with no stage installed throws, and only the plaintext redirect listener is exempt.
