- **Breaking - the Echo retention-paused list names its row count `hourly_rows`.** Each row of the MCP tool `list_echo_retention_paused` and of `GET /api/v1/echo/retention-paused` (the two share one response) carried the count under `live_rows`. Echo keeps roll-up tiers only, so the count is the number of rows in the source's hourly roll-up tier, never raw capture rows, and the field is now `hourly_rows` (`-1` when the agent did not report it). The `live_rows` field is gone and there is no alias; clients that read it must read `hourly_rows`. The tool description and the response schemas say the same.
