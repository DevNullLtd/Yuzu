- **The agent's log-error diagnostic can no longer stall its logging worker or hang shutdown when stderr is blocked (#5023).** When a log sink failed (a full disk, no free file descriptors, a broken pipe) at the same moment the agent's stderr was blocked (for example a full pipe to a stalled log collector), the single logging worker thread wrote its diagnostic line to stderr itself and stopped delivering log lines for as long as stderr stayed blocked. That line is now written by a short-lived helper thread, at most one at a time, using a plain write that holds no C-library lock (so a blocked helper cannot hang a normal shutdown); while one is stuck, further diagnostic lines are dropped and counted instead of blocking anything. This closes the diagnostic's own write only: when stdout or stderr is itself one of the agent's log sinks (a stdout sink when there is no `--log-file`, and a stderr sink beside the file sink with `--log-file` outside a Windows service), a blocked stream still stalls the logging worker in that sink's own write, as before. No flag or format change.
