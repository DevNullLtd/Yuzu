- **Sync now on the Software page.** A new `POST /api/v1/hardware/sync` asks one device, a management group, a scope expression or the whole fleet to re-send its installed-software inventory now. It needs a global `Execution:Execute` grant (an operator limited to management groups is refused), contacts only agents attached to the server process that handles the request (`skipped_offline` counts devices that server did not reach: no live session there, including a device attached to another server, or a refused send; a device that is offline everywhere is not enumerated for fleet and scope runs, so the counts describe what that server could reach, not the whole fleet), skips agents older than 0.13.1, refuses more than 500 reachable devices, allows one multi-device run per operator per 60 seconds and one in flight per server process, and writes the `inventory.sync.request` audit row before anything is sent. The Software page gets a Sync now button and dialog for the three scopes.
- **Colour schemes.** Settings > General > Appearance now offers Slate, Navy and Jade (dark) and Light, Light Baby Pink and Light Hot Pink (light). The choice is stored in this browser and applied before the page paints.
