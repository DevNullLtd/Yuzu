- **One exclusive-create atomic file write for every agent-side state file.** `asset_tags`, `filesystem` (`write`/`replace`) and `tags` now stage every write through one shared primitive (`agents/shared/atomic_file_write.hpp`): a random-suffixed sibling temp created exclusively (POSIX `O_CREAT|O_EXCL|O_NOFOLLOW`, Windows `std::ios::noreplace`), fsync'd before the rename, with the POSIX mode re-tightened on the still-open descriptor for owner-only state (ordinary files keep their `0666 & ~umask` creation mode); the agent's own certificate and key writer uses the same primitive. `tags.json` was previously written in place (a crash could truncate it) and `filesystem`'s temp name was fixed and predictable. `asset_tags status` gains `persist_failures` and `last_persist_error`, and a `sync` whose state file could not be restricted to owner-only or whose directory could not be fsync'd now reports `CONSTRAINED` (#4723, #4725, #4726, #4727, #4728).
