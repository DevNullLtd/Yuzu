- **Gateway: the per-agent owner keeps the agent's hostname, not its whole AgentInfo.** The owner process read only the hostname of the AgentInfo it kept for the life of the session, about 26 KB of live heap for an agent with 69 plugins. It now keeps the hostname alone. The saving scales with the size of the agent's AgentInfo (its plugins and their descriptions and capabilities): measured at 3,000 agents with 69 plugins each, live memory per agent fell from 122.4 to 99.5 KiB, and at 6 plugins it is about 2 KiB per agent (measured in a scratch module). ListAgents, GetAgent and QueryInventory answers are unchanged. Hot code loading stays unsupported: upgrade the gateway by restarting it.
