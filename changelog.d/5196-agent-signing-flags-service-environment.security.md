- **On Windows, set the agent's update-signing options in the service's `Environment` registry value, not in its binary path.** Every run of the agent installer, including a reinstall or an upgrade pushed through SCCM, Intune or GPO, rewrites the `YuzuAgent` service's binary path in full. It drops `--update-trust-bundle` and `--update-require-signature` if you added them there, and nothing reports it: OTA updates are no longer signature-checked. The service's `Environment` value (`HKLM\SYSTEM\CurrentControlSet\Services\YuzuAgent`, `REG_MULTI_SZ`) is read each time the service starts and is left in place by installer runs; *Signing update binaries* in `docs/user-manual/server-admin.md` gives the commands. Check endpoints where you enabled signing with `sc qc YuzuAgent`. If the flags are missing, move them into `Environment` and restart the service. (#5196)
