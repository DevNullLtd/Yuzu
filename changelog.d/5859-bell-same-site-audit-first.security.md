- **Header bell hardened.** `POST /api/notifications/{id}/read` and `/dismiss` now refuse a browser (session-cookie) call without a same-site `Origin` or `Referer` (`403`, audit `csrf.denied`), write a `notification.mark_read` / `notification.dismiss` row with result `attempted` before changing anything and refuse with `503` (`Sec-Audit-Failed: true`) when it cannot be written, and `GET /api/notifications` now answers `503` instead of an empty list when the database read fails or times out.
