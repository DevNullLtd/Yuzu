- **OIDC name lookup counter and pool capacity gauge.** `yuzu_server_oidc_resolver_lookups_total{outcome}` counts each name lookup made through the OIDC resolver pool once, by `outcome` (`ok`, `not_found`, `temporary`, `timeout`, `busy`; all five present at `0` from boot), and `yuzu_server_oidc_resolver_pool_capacity` publishes the pool's slot count beside `yuzu_server_oidc_resolver_in_flight`. Both are published every 15 s. The capacity reads 16 on every build; the in-flight gauge and the counter are fed only on POSIX builds, because the Windows OIDC path does not use the pool. See `docs/user-manual/metrics.md`.
