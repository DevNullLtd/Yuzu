- **Firewall containment actions are protective.** The firewall plugin's four containment actions (`quarantine`, `release`, `quarantine_status`, `quarantine_allow`) join the closed protective-action set, so a kill switch, a per-OS withhold or a degraded plugin-config read can no longer refuse the way out of a containment (owner decision). The iptables leg now reports a host as enforcing only while the generation chain it jumps to still holds the terminal DROP. The legacy `quarantine` plugin stays in this change; its removal is a separate follow-up that lands after this one (#7530).
