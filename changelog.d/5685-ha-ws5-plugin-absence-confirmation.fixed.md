- **A restarted agent is no longer judged by its previous session's plugin list on a second core replica (HA WS-5 follow-up; a second replica is still NOT supported, the safe-to-scale gate is not lifted).** A cross-replica `plugin_not_found` is now withheld only while the agent's routable route-directory row still names the session that published the plugin list, checked at dispatch time, so an agent that re-registers with a changed plugin set is dispatched to at once instead of until its first heartbeat. An agent with no route row (a direct-connect agent), an unroutable row or an unreadable directory is not reported `plugin_not_found` by a replica that does not hold its session: it is dispatched to and the agent answers for itself, so cross-replica `plugin_not_found` applies to gateway-fronted agents only. This costs one route-directory query per dispatch over the agents a published list says lack the plugin, and only on a replica whose presence holds agents it has no session for; at most two such queries run at once (a dispatch past that withholds nothing) and each query's statement is bounded to 2 seconds; a new counter `yuzu_server_plugin_absence_confirm_total{outcome}` (`withheld`, `not_confirmed`, `degraded`, `shed`, `unwired`) shows how it resolves (#5685).
