- **Server and agent daemon no longer break on malformed agent-supplied data.** A compliance-check response with wrong JSON types or invalid UTF-8 now maps that one device to the `error` verdict instead of aborting the whole policy collect pass; the Hardware action-result fragment refuses to recurse into deeply nested agent JSON and renders it as text; the shared `/events` SSE framing treats a bare CR like LF so agent output or a hostname cannot forge event fields; the agent daemon scrubs plugin output to well-formed UTF-8 before it reaches the wire (and `yuzu::util::sanitize_utf8` now rejects overlong, surrogate and out-of-range sequences); and Echo scrubs process names/command lines at collection and serialises its baselines with a replacing error handler, so a hostile process name can no longer disable process/network capture.
