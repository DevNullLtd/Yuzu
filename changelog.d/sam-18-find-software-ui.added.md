- **The Software page has a Find software panel.** Type an application or component name to see how many installs (or component instances) and devices carry it, on which devices, with what version, install location or path, install type and status, when a report last confirmed it and when the device last synced (amber after 48 hours). The panel runs the same model as the REST lookups `GET /api/v1/inventory/software` and `GET /api/v1/inventory/software/components`, so the count equals their `totals` and the rows are theirs; it shows the REST call it corresponds to, an Export CSV link, an optional exact version or from/to range, and Applications, Java, Python and Node chips. Component searches show the devices not confirmed by their last report apart, with a link to list only those. An account scoped to management groups gets the rows on its own devices and no fleet count, and a store that does not answer shows a retry banner instead of an empty table. The per-device Installed software tab gains Install type and Location columns.
