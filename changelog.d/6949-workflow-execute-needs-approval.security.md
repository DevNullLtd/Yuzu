- **A supervised-tier MCP token can no longer run a workflow without an approval ticket.** `Workflow:Execute` joined the supervised tier's approval-gated operations, the same rule every other fleet execution at that tier already follows, so `POST /api/workflows/{id}/execute` now refuses such a token with `403` (approval required on this transport). Before this change the token ran the workflow with no human in the loop. No MCP tool for workflow execution exists yet, so a supervised-tier token has no ticket path to run a workflow until the `execute_workflow` tool ships (#2146); a session or a non-MCP API token is unaffected.
