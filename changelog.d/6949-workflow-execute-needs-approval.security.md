- **A supervised-tier MCP token can no longer run a workflow without an approval ticket.** `Workflow:Execute` joined the supervised tier's approval-gated operations, the same rule every other fleet execution at that tier already follows, so `POST /api/workflows/{id}/execute` now refuses such a token with `403` (approval required on this transport). Before this change the token ran the workflow with no human in the loop. A supervised-tier token runs a workflow through the MCP `execute_workflow` tool instead: the first call returns an approval ticket, and the same call is repeated with the `approval_id` once an administrator approves (the tool requires an `idempotency_key`); a session or a non-MCP API token is unaffected.
