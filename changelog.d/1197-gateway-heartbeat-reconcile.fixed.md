- **The gateway now re-registers the agents a restarted server does not know (#1197).** After a server-only restart, the gateway reads the unknown sessions from the `BatchHeartbeat` response and replays exactly the ones it still holds, so those agents are known to the server again without operator action: within one heartbeat interval, one flush and the drip position, plus the remaining circuit breaker backoff (up to 300 s) if the outage opened it. Restart the gateway to deploy; no wire change. A gateway restart disconnects every agent that node holds, and released agents v0.13.0 and v0.14.0-rc6 with default settings did not re-register after a rejection in testing (cause inferred: #2182, fixed by #5183, in no release yet): upgrade the agents to a build with that fix first, or restart the agent service on such an agent. `--no-auto-update` avoids the wedge but also disables the OTA update channel. New counters: `yuzu_gw_registration_replay_triggered_total`, `yuzu_gw_heartbeat_unknown_truncated_total`, `yuzu_gw_heartbeat_verdict_dropped_total`. One core replica only. Refs #1197.
