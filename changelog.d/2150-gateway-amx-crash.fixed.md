- **The gateway container starts on recent Intel CPUs again.** On AMX-capable Intel hosts (Sapphire Rapids and newer, including AWS c7i, m7i and r7i instances), the `yuzu-gateway` image crashed at startup with `sys_sigaltstack(): Internal error: Failed to set alternate signal stack` and kept restarting. Every 0.14.0 release candidate up to rc4 was affected. The image ran Alpine 3.24 (musl 1.2.6), which rejects the signal stack size Erlang/OTP 28 asks for on those CPUs, while it was built on Alpine 3.23. The runtime is back on Alpine 3.23, matching the build, and the image build now fails if the two drift apart again. The chiselled gateway image (`yuzu-gateway-chisel`) uses glibc, which does not make that check. (#2150)
