- **Behaviour change: OIDC name lookups refuse a name for 3 s after a refused or timed-out lookup.** A name whose lookup was refused or timed out is not looked up again for 3 seconds: a lookup for it fails at once with "the host name lookup was not started", takes no pool slot, and is counted as `busy` in `yuzu_server_oidc_resolver_lookups_total`. At most 32 names are remembered, a refusal served from that memory does not extend the 3 seconds, and a success or a not-found answer is never remembered. A discovery refused that way arms no 30 s window, and the NAT64 probe is not held back by it. There are no new flags. Windows builds are unchanged. See `docs/user-manual/upgrading.md`.
