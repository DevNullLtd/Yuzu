- **An Echo database closed at run time after a failed rollback is now reported as storage offline with reason `rollback_wedged`.** Such an agent stops all Echo collection and retention until it restarts, and until now nothing outside `echo status` said so. The agent now publishes the `yuzu.plugin.echo.storage_offline` heartbeat tag with the value `rollback_wedged` at its next slow collect tick, `echo status` ends with `storage_state|offline|rollback_wedged`, the `yuzu_fleet_echo_storage_offline{reason}` gauge gains a `rollback_wedged` series, and the existing `YuzuEchoStorageOffline` alert and runbook cover it. This reason is not retried: only an agent restart recovers it.
