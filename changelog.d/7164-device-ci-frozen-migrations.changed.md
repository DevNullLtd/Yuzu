- Device-CI store: in a development or UAT database that ran an earlier build of the unreleased device-CI v2 or v3 migrations, the server now refuses to start, logging the table or column it is missing, instead of starting and answering 503 or a retryable error on every device record read. Migration v2 is now fixed text rather than generated from the section list, so adding a kind or changing its columns needs its own migration. See the upgrade notes for the reset.
