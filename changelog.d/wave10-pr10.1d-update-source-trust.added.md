- **New read-only `update_source_trust` agent plugin — whether the host's software-update sources are signed and trusted (Linux apt in this release; the rpm/dnf, macOS and Windows legs are not read yet).** The single `sources` action reports facts only and enforces nothing. On Linux it reads the apt sources (one-line `sources.list` and deb822 `.sources` files), each source's `signed-by` keyring or `trusted` flag, and the keyrings under `/etc/apt/trusted.gpg.d`; a host whose `/etc/yum.repos.d` has entries reports a constrained status with `linux:rpm_repo:planned`, and the macOS and Windows legs report one `unsupported` status row. Every read is a bounded filesystem read that refuses a symlinked file, with no subprocess (no `apt` or `dnf` is ever run), and a failed or partial read reports a constrained status with a token instead of an empty result.
