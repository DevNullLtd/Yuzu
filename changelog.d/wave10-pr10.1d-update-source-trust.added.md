- **New read-only `update_source_trust` agent plugin — whether the host's software-update sources are signed and trusted (Linux and macOS; Windows follows in a separate PR).** The single `sources` action reports facts only and enforces nothing. On Linux it reads the apt sources (one-line `sources.list` and deb822 `.sources` files), each source's `signed-by` keyring or `trusted` flag, the keyrings under `/etc/apt/trusted.gpg.d`, and the rpm/dnf `.repo` files' `gpgcheck` and `gpgkey` settings; on macOS it reads the SoftwareUpdate preference plists, both the local one and the Managed Preferences one. Every read is a bounded, no-follow filesystem read with no subprocess (no `apt`, `dnf` or `softwareupdate` is ever run), and a failed or partial read reports a constrained status with a token instead of an empty result.
