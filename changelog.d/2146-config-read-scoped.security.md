- **Breaking: `GET /api/config`, `GET /api/v1/config` and `get_runtime_config` show only the overrides the caller could write.** An MCP-tier token or a non-administrator holding `Infrastructure:Read` no longer receives `oidc_admin_group` or the other administrator-only overrides (the `oidc_*` keys, `plugin_signing_required`, the DEX alert keys and `audit_retention_days`), and an elevated-only session no longer receives the `oidc_*` keys. An administrator account's `GET /api/config` body is what it was, apart from the `log_level` spelling. The v1 route and the MCP tool also list the withheld keys in `withheld_keys`, so a client can tell "not shown to you" from "not set". Who is affected: a script or backup that reads `GET /api/config` with an MCP-tier or non-administrator token and expects the administrator-only keys. What to do: read with an administrator API token that is not MCP-tier; see the Upgrading guide.
