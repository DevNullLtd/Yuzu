- **The Guardian heartbeat reconcile now delivers to an agent whose session on this replica cannot deliver (HA WS-5, #5685).** A replica that holds a session for an agent but has no delivery path of its own (a session adopted from a gateway replay before its CONNECTED reaches that replica) used to count the push as `undelivered` on `yuzu_server_system_reserved_push_total` and nothing else, leaving the agent unreconciled. It now reads the agent's route once and queues the push for the cluster that owns it, only when the route is routable and names this replica's session. A degraded route read sends nothing and is an `ABORTED` reconcile counted `result="degraded"`. `yuzu_server_guardian_reconciles_total` gains `sent_remote` and `undelivered` (both new series), and a remote push's audit row ends `via the route directory`. The server is still one supported replica; two replicas can each push one agent (convergent, per-replica budget and claim), and an agent with no session on a replica still reports `no_session` until the gateway's replay lands there.
