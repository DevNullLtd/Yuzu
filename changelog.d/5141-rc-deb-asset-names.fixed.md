- **Pre-release `.deb` downloads now verify against `SHA256SUMS`.** Release candidates named their Debian packages with Debian's `~` separator (`yuzu-agent_0.14.0~rc2_amd64.deb`), which GitHub rewrites to `.` when storing the asset, so `sha256sum -c SHA256SUMS` and the SLSA provenance never matched a downloaded RC `.deb`. RC `.deb` files are now named with the tag's version (`yuzu-agent_0.14.0-rc3_amd64.deb`); the package's own version is still `0.14.0~rc3`, so upgrades from an RC to the final release are unchanged. Stable releases are unaffected. (#5141)
