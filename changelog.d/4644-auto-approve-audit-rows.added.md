- **Auto-approve rule changes are audited.** Adding a rule, changing the match mode, toggling a rule and deleting a rule from `Settings > Auto-Approve` each write a `settings.auto_approve.rule_added`, `mode_changed`, `rule_toggled` or `rule_removed` row naming the rule type and value (an enrolment-authorisation change used to leave no audit evidence). A rejected subnet and an index that matches no rule are recorded as `result=denied`. Set-and-proceed, like the other dashboard settings mutations. See [Audit Log](docs/user-manual/audit-log.md).
