- The route catalog returned by `GET /api/v1/discover/routes` and the MCP `discover_routes` tool now carries an optional `unavailable` string on operations the OpenAPI document marks `x-yuzu-unavailable`. Those 14 operations (License Management, Device Tokens and Software Deployment) are registered in the document but not served by the server today, so a client that filtered on the catalog alone previously listed them as callable.
