- **File search core for the agent (no operator-visible change yet).** Adds the pure building blocks of an on-demand file search: a sorted, depth-first, resumable directory walk beside the existing component walk; a mount-table parser and a local filesystem allow-list; a leaf-name pattern matcher (`*` and `?` only: `[` and `]` are literal, unlike the `filesystem` plugin's `search_dir`); a resume-cursor decoder that refuses a malformed token without touching the filesystem; a coverage report that lists the volumes and directories the walk could not search (symbolic links are skipped and counted, not listed); a pacing governor; and a reversible name encoding for result rows. No plugin, action or setting uses them yet, and the existing component inventory walk, network-mount checks and `search_dir` are unchanged.
