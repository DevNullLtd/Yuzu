- **File search core for the agent (no operator-visible change yet).** Adds the pure building blocks of the on-demand file search: a sorted, depth-first, resumable directory walk beside the existing component walk; a mount-table reader and a local filesystem allow-list; a leaf-name pattern matcher (`*` and `?` only); a resume cursor that is validated before any filesystem call; a coverage report that says which volumes and subtrees were not searched; a pacing governor; and a reversible name encoding for result rows. No plugin, action or setting ships in this change, and the existing component inventory walk and network-mount checks are unchanged.
