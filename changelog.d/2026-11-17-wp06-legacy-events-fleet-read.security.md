- **The legacy `GET /events` live stream is gated on unrestricted `Response:Read` and `Execution:Read`.** It carried every non-Forensics command output row, command status and agent / pending-agent id for the whole fleet to any signed-in principal. It now uses the same admit-then-filter gate as `GET /api/v1/events`; because the legacy bus cannot be filtered per device, a caller whose read authority is confined to a management group or service, and every engine principal, is refused `403` (RBAC-off humans are unchanged). The dashboard console's live panel is unavailable to a scoped role.
