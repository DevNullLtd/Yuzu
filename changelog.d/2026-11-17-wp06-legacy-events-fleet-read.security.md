- **The legacy `GET /events` live stream needs unrestricted `Response:Read` and `Execution:Read`.** It carries every non-Forensics command output row, command status and agent / pending-agent id for the whole fleet and cannot be filtered per device, so it uses the same admit-then-filter gate as `GET /api/v1/events` and refuses a caller whose read authority is confined to a management group or service (`403`, audited as `events.stream.access_denied`); an engine principal is admitted only on an explicit RBAC grant. A stream already open is not closed when the grant is later removed (#7815). The dashboard console's live panel is unavailable to a scoped role.
