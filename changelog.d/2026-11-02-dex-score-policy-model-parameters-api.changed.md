- **`GET`, `PUT` and `DELETE /api/v1/dex/score-policy` carry the scoring model parameters.** `PUT` accepts a version 2 document with a `model` block (the per-device event cap, the regression start and full-weight ratios, each also settable in a per-application override, and the global interval confidence level), `GET` and a `dry_run` answer return them with their defaults filled in, and the OpenAPI document types the stored document (`DexScorePolicyDocument`) with each parameter's range and default. A document that uses no model parameter is stored as version 1 as before; a `model` in a version 1 document is refused, and the refusal of the Apps projection now names `model` among the keys to send. Do not set a model parameter during a rolling upgrade (see Upgrading).
