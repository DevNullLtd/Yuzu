- **MCP approval tickets bind a digest of secret arguments.** The ticket's bound subject replaces every `secret`, `grant_secret`, `grant_id` and `client_secret` value, at any depth (including inside `params` and bundle `steps`), with a `<redacted:sha256:...>` marker before the ticket is minted, so the approvals reads never return them and a re-call with a different secret does not match the ticket. Arguments nested deeper than 64 levels are refused `-32602` (not retryable). A credential passed as text inside a string-valued argument is not parsed; no approval-gated tool takes one today.
