- **component_inventory**: new `python` and `node` actions (instructions `crossplatform.components.python` and `crossplatform.components.node`) list installed Python distributions and Node packages (name, version and where they live) on Linux and macOS, reading only metadata files under fixed machine-wide roots and never running anything. Both ship enabled and are dispatched by an operator only (not part of the daily report); each run is one live read of up to 45 seconds and 400,000 directory entries, and either action can be switched off with the plugin kill switch. Windows answers planned.
