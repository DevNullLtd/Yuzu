- **BREAKING: `/metrics` no longer trusts a loopback peer by default.** A reverse proxy, sidecar or tunnel on the server host made remote callers look like `127.0.0.1` and skipped authentication. The exemption is now the opt-in `--metrics-trust-loopback` (`YUZU_METRICS_TRUST_LOOPBACK`, default off; a loopback request carrying a forwarding header is still treated as remote). A host-local scraper must send a bearer token, or the server must run with the flag or `--metrics-no-auth` (which every shipped UAT launcher already passes). Set the flag only when nothing on the host proxies to the server, and block `/metrics` on any same-host proxy.
