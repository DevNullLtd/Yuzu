- **Bulk device-CI read: `GET /api/v1/hardware/ci` and the MCP tool `list_hardware_ci_records`.** Pages through the stored hardware CI records of every device (the scalar CI block plus the stored `content_hash` and `blob_version`, no sections), 100 per page by default and 1000 at most, in `agent_id` order, for a daily pull into an external CMDB without one call per device. It reads the stored CI table, not the 30-day roster, so a device offline for longer still appears while its record exists. Read-only; needs `Inventory:Read`; each served page is audited fail-closed as `inventory.devices.ci`. A caller with global read pages through any number of devices; a caller confined to a scope of more than 10000 devices is refused with a clear error unless it passes `agent_id`.
