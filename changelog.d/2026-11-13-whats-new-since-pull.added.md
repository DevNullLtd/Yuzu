- **`scripts/whats-new.py` shows what a `git pull` of `dev` changed.** It lists version bumps first (project version, plugin ABI, vcpkg baseline and dependency constraints, gateway packages, latest released changelog version), then the surfaces that may need a rebuild, then `build(deps)`/`chore(deps)` dependency bumps (Docker images listed, the rest counted), then the `changelog.d/` fragments the range adds, from your last pull (read from the `HEAD` reflog) or from `--since <ref|date>`. Read-only; repository text is printed with control characters replaced. See `changelog.d/README.md` "Reading unreleased changes".
