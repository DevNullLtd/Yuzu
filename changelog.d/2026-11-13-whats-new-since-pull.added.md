- **`scripts/whats-new.py` shows what a `git pull` of `dev` changed.** It lists version bumps first (project version, plugin ABI, vcpkg baseline and dependency constraints, gateway packages, latest released changelog version), then the surfaces that may need a rebuild, then `build(deps)`/`chore(deps)` dependency bumps (Docker images listed, the rest counted), then the `changelog.d/` fragments the range adds, from your last pull (read from the reflog of the branch you are on) or from `--since <ref|date>`. Read-only (in a partial clone, git itself may fetch objects the range needs); repository text is printed with control and invisible characters replaced. See `changelog.d/README.md` "Reading unreleased changes".
