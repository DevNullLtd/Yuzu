- **`scripts/whats-new.py` shows what a `git pull` of `dev` changed.** It lists version bumps first (project version, plugin ABI, vcpkg baseline and dependency constraints, gateway packages), then the surfaces that need a rebuild, then Dependabot bumps (Docker images listed, CI/tooling counted), then the `changelog.d/` fragments added since the last pull (`ORIG_HEAD`) or since `--since <ref|date>`, grouped by section. Read-only; see `changelog.d/README.md` "Reading unreleased changes".
