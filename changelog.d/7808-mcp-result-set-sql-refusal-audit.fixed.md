- **The MCP result-set tools now audit refused echo SQL like the REST routes (#7808).** `create_result_set_from_echo_query`, `create_result_set_from_instruction_result` and `reevaluate_result_set` wrote no audit row when they refused a missing or oversized `sql`, or a query over a raw capture table (`RESULT_SET_REEVAL_STALE_SOURCE`). Each refusal now writes a `result_set.create` row with `result=denied` and `reason=sql_missing`, `sql_too_large` or `stale_source` plus `source_kind` (never the SQL text), with the stored set's id as `target_id` on re-evaluate. The refusal's code and message are unchanged; when the row could not be written, the error now carries `error.data` `{"audit_persisted":false}`, which the NUL-byte refusal also does.
