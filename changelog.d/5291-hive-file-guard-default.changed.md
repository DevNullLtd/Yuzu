- The offline user-hive file check is now applied by default for every plugin that mounts a logged-out profile's NTUSER.DAT (autoruns, installed_apps, license_scan, registry, tar); privacy_permissions already enforced its own equivalent check and is unaffected. A profile whose hive file does not pass the check is reported as an unreadable source rather than read: autoruns and installed_apps name the check's own hive_* reason per profile, license_scan reports the aggregate reason hive_file_refused on its per_user_hives row (per-profile detail in the agent log), registry returns its existing hive-file-refused error, and TAR's mapped-drive history retries individually every profile whose hive was not read (7 attempts in total, 24 h apart).
