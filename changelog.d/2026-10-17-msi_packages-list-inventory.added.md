- **`msi_packages` gains a read-only `list_inventory` action for the daily installed-software inventory (Windows).** It lists machine-context Windows Installer products only — product code, name, version and publisher through MsiEnumProductsExW/MsiGetProductInfoExW — so a product installed for one user is never reported by this action; the daily sync collects the rows as ecosystem `msi`, kind `pkg`, with `package_id` set to the product code. An enumeration that does not complete is a constrained status (the cycle is skipped, nothing is deleted), and a product whose name, version or publisher cannot be read keeps its row with that field empty. Install location and uninstall string stay out of the inventory (the reserved slots, #5186). The existing `list` and `product_codes` actions are unchanged; macOS and Linux report the action unsupported.
