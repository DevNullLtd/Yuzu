- **Echo rename migration fails closed on a definition-id collision.** When a legacy `crossplatform.tar.*` definition id cannot be renamed because the Echo-named id already exists, the migration aborts, the instruction store does not open and server startup refuses, instead of leaving dependent stores pointing at the wrong definition.
- **Echo rename migration leaves archive-tool text alone.** The lowercase `tar` rewrite in an operator-edited built-in definition no longer touches archive-tool commands, file names or pipes; the feature name and `tar|snapshot` still rewrite.
- **Agent records an adoption marker before adopting a legacy `tar.db`.** A resume refuses when an `echo.db` log is present without a marker that matches `tar.db` (an older agent may have written to it in between), naming both files and moving nothing.
- **Gateway re-announce refreshes the legacy plugin-name flag.** A known session that re-announces with a changed plugin list no longer leaves the directory row rewriting Echo commands to the old name.
- **macOS nstat closing-state opens are stored once per hour.** A flow first reported already closing is one row per process, remote address and remote port per hour, sharing the poll path's set, so the subscription dump at each restart no longer stores one row per socket.
- **Bounded agent reads and per-tick bookkeeping.** The `/proc/<pid>/cmdline` read stops at 256 KiB, the login-record readers close their session on every exit path, and the hourly de-duplication sets no longer copy 20,000 keys every tick.
- **Byte-budget wording.** The capability catalogue, the retention-tier comment and the Settings page now state what a device over its byte budget removes.
