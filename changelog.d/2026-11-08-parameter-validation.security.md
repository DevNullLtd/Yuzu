- **Parameter validation.** A NUL byte in text bound into a database statement is now refused instead of being cut at that byte. At the edges this means: a gateway stream-status notification with a NUL in an identifier is rejected; the asynchronous result-set producers (REST and MCP) and the direct result-set create refuse a NUL in the name, the parameters or the parent set id before anything is dispatched; a directory-sync record with a NUL in a key field is skipped and counted, a NUL in a display field is replaced and the record kept, and a snapshot whose records would all be skipped is refused and leaves the roster unchanged; and a schedule create refuses a NUL in a text field with `400`. Where the surface allows it, invalid input (a control byte, invalid UTF-8) is answered with a client error rather than a server fault, including on the management-group member and role routes and MCP tools, which now also answer `404` for a group that does not exist. Operations that refuse a write now report that outcome accurately, with no success audit row and no success response for a write that did not happen, across management-group member and role changes, OTA package upload and removal, schedule create, enable, disable and delete, and execution status updates. An OTA upload whose registry write fails restores the previously published binary and signature sidecar, and the Entra directory sync response and audit row report the counts that sync applied.
