- **Parameter validation.** A NUL byte in text bound into a database statement is now refused instead of being cut at that byte. At the edges this means: a gateway stream-status notification with a NUL in an identifier is rejected; the asynchronous result-set producers (REST and MCP) refuse a NUL in the name, the parameters or the parent set id before anything is dispatched; and a directory-sync record with a NUL in a key field is skipped and counted, while a NUL in a display field is replaced and the record kept. Where the surface allows it, invalid input is answered with a client error rather than a server fault. Operations that refuse a write now report that outcome accurately, with no success audit row and no success response for a write that did not happen, across management-group member and role changes, OTA package upload and removal, schedule enable, disable and delete, and execution status updates.
