- **The Windows agent installer now runs on endpoints that enforce WDAC or AppLocker script rules.** On those endpoints PowerShell runs in Constrained Language Mode, which refused the .NET method calls the installer's trust-anchor permission check used. The check could not complete, so every agent install from 0.14.0-rc1 to rc5 stopped with exit code 7. The check now reads and compares the security descriptor text, which Constrained Language Mode allows. Verified on Windows Server 2022. (#5196)
