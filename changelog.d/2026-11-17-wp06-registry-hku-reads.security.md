- **`registry.get_value`, `key_exists`, `enumerate_keys` and `enumerate_values` refuse a per-user hive under `HKU`.** `hive=HKU` with a user or Entra SID read a logged-on user's data without the administrator-or-approval gate that `get_user_value` carries. They now answer `error|per_user_hive_requires_get_user_value` for any first key component that is not machine scope (`.DEFAULT`, `S-1-5-18/19/20`, each also `_Classes`); use `get_user_value`. Windows only.
