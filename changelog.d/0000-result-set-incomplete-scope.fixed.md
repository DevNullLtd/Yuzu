- **A result set that is not ready or is incomplete is no longer used under NOT.** A `from_result_set:<id>` scope now aborts (`result_set_unusable`) when the set is still pending or has failed, and when the set is incomplete (an agent answered with an error, or never answered before the set was filled at the timeout) and is referenced where a missing member would match, such as under `NOT`. A positive reference to an incomplete set still resolves. Result sets record the number of unanswered agents in a new `agents_unanswered` column (schema version 5); sets filled earlier read 0 and are treated as complete.
