- **`component_inventory`: the `scan` and `native` actions now run on Windows.** Both read the `Program Files` and `Program Files (x86)` trees on fixed local drives through a filesystem binding that never follows a reparse point (a junction, a symbolic link or a mount point); `native` lists PE `.dll` files versioned from their fixed file version. The Windows leg is declared `supported` on the measured scope (one host, Windows 11 build 26200, an elevated administrator session) and answers `constrained` when a directory is refused or a bound is reached.
