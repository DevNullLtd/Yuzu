- **A Guardian policy push can no longer disarm a rule through a degraded scope read, and an agent no longer applies an older full push.** The REST, dashboard and MCP policy-push fan-out (also used by Baseline deploy and delete) now resolves the target scope and every rule's scope before it sends anything; a degraded tag or property store read aborts the whole push with `503` and sends nothing, where it used to omit the scoped rule from every agent's full push and record the new generation as delivered. On the agent, a `full_sync` push labelled with a policy generation below the one the agent holds is refused with a warning and changes nothing; before, the older rule set was applied while the agent kept reporting the higher generation. A push at the held generation is still applied. After a server-side loss of the generation counter, agents that hold a higher generation refuse full pushes until the server's counter exceeds theirs (see Guaranteed State).
