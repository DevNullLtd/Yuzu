- **`pkg_inventory.packages` reads Homebrew install receipts and user-owned Homebrew prefixes on macOS, without running Homebrew.** A Homebrew package row is now eleven fields; the first five are unchanged and the rest carry the formula's install time, tap and whether it was requested (from its `INSTALL_RECEIPT.json`, each `-` when unknown and each the installing account's own claim), the scope (`machine` or `user`), the owner (the home directory's name, `-` on a machine row) and the prefix (`/opt/homebrew`, `/usr/local`, `~/homebrew` or `~/.homebrew`). A Homebrew a user installed in their own home is read only when it is owned by the home's owner, and a failed read of one makes the answer `constrained` with a named token. The installed-software sync maps a machine row's install time and prefix onto its existing `install_date` and `install_location` columns and never collects a `user` row, so every Mac with Homebrew sends one full delta after the upgrade.
