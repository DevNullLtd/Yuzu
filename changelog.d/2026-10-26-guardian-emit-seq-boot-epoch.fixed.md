- **The agent now stamps every Guardian event with an ordering pair so a backward clock step can no longer let an older verdict outrank a newer one.** `GuaranteedStateEvent` gains `boot_epoch` and `emit_seq` (fields 24 and 25), assigned when the agent decides the event's queue order, on both the legacy and the Spark emit paths, and compared as a pair. `boot_epoch` is claimed once at agent boot from a persisted counter and the boot time; `emit_seq` increases within a boot. Events replayed from the lifecycle journal, and events from a boot whose epoch could not be claimed, carry no pair and still order by timestamp. The server does not compare the pair yet, so server behaviour is unchanged until that change lands. An equal epoch is possible only if the agent's data directory is wiped and it restarts within the same second.
