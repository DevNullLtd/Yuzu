- **New critical alert `YuzuRbacBreakerOpen` (#3526).** `docs/prometheus/yuzu-alerts.yml` now ships a per-replica rule that fires when `yuzu_server_rbac_breaker_open` has stayed at `1` on a replica for 5 minutes, meaning that replica's authorization reads keep failing and its fail-fast breaker has not closed. It complements `YuzuRbacReadDegraded`, which is a rate summed across replicas. Load the updated rule file if you maintain your own copy of the shipped alerts. See [Upgrading](docs/user-manual/upgrading.md).
