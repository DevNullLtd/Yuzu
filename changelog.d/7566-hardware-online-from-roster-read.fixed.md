- **The Hardware list no longer reads devices connected to another server as Offline when the presence read fails.** Online was taken from the registry's cached live-presence read, a second read of the same table that could fail or be refused above 100,000 live agents; when it did, every device connected to another replica read Offline with no warning, and the Online and Offline tiles, the status filter and the status sort followed it. The roster read now says which rows are connected in the same statement (a recorded session seen within the server's session timeout, judged on the database clock, the same test the presence read and the Home figure use), and a device is Online if it holds a session on the serving replica or that test passes. There is no second read to fail, so there is no flag to show. A device that drops without saying goodbye still reads Online until the window passes. (#7566)
