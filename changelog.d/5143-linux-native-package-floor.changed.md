- **The minimum Linux distribution for the native packages is now documented.** The `.deb`, `.rpm` and tarball binaries need glibc 2.38; the server also needs GCC 15's libstdc++ and the agent GCC 14's. In practice the server runs on Ubuntu 26.04 and Fedora 42, the agent also on Ubuntu 24.04, and none runs on Ubuntu 22.04, Debian 12 or RHEL/Rocky 9. The gateway `.rpm` does not start on RHEL-family systems (#5171). The container images are not affected. See *Supported Platforms* in the user manual. Building to an older baseline is tracked in #5143. (#5143)
