- **`registry` 2.0.0: typed, verified writes on a link-checked handle.** `set_value` now writes all six value types (`REG_SZ`, `REG_EXPAND_SZ`, `REG_BINARY`, `REG_DWORD`, `REG_MULTI_SZ`, `REG_QWORD`) from text or exact `data_hex` bytes, captures the previous value, reads the new one back on the same handle and fails on any difference (`verify_mismatch`). Every mutation runs on a checked handle: on `HKLM` and `HKU` one open whose canonical kernel name is compared with the requested path (a registry symbolic link anywhere in the path changes that name and sends the call to the reference component walk), on `HKCU` and `HKCR`, for a missing key and whenever the open cannot decide, the walk itself, which refuses a link (`key_is_link`), creates missing components, refuses `concurrent_change` and hands over a handle only when its canonical kernel name is the requested path, so a link completed after its probe cannot redirect it (a creating write whose walk does not hand its leaf over, or that raises an exception before its verified write ends, deletes every key it made, by handle, leaf first, and keeps any key that now holds a value or key another party put there; the audit line's `created=` reports every key left). Keys are deleted by handle with `NtDeleteKey`, so a swapped path cannot redirect a write or a delete; `delete_key` still removes only a key with no subkeys and now reports `counted_keys`, `counted_values`, `dry_run` and `capped` (the count stops at 10,000 nodes: the key plus up to 9,999 values). Every mutating action emits one `audit|` line with the old and new values (hex of the raw bytes, capped at 256 bytes; the owner (Alex, 2026-10-20) accepted that these values can contain secrets and masking is a planned later change, so the rows are readable by `AuditLog:Read` and `Response:Read` holders, the legacy `/events` stream and, for `data_hex`, `executions.parameter_values`), which the server records as a `registry.write` row when the agent stamps the action; an action that ends in an exception leaves a fixed failed audit line, so that row exists too; the line grammar and the producer contract are published in the plugin README. The macOS and Linux legs are declared as planned stubs.
