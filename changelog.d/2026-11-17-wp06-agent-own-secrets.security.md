- **The filesystem plugin refuses the agent's own secrets.** `filesystem.read`, `search`, `get_acl`, `file_hash`, `exists`, `list_dir` and the writes, and every entry a `search_dir` or `find_by_hash` walk visits, refuse the agent's data directory (the default one when none is configured), certificate directory, log file, TLS CA, client certificate and key, enrollment token file, plugin allowlist, plugin trust bundle and update trust bundle, and on Linux the agent's own `/proc/<pid>/` tree and the `environ`, `mem`, `maps`, `cmdline`, `fd` and `auxv` files of any process. The decision is by file identity (a hard link, `..` path or case alias is the same object). It is a best-effort guard against a writer who controls a parent directory, and auto-discovered certificates outside the certificate and data directories are not covered.
