- **The filesystem plugin refuses the agent's own data directory, certificate directory, log file and TLS key/certificate/CA paths, and the agent no longer logs its session id.** These bytes were reachable through `filesystem.read` / `search` / `get_acl` / `file_hash` with only `FileRetrieval:Read`, while the same log is `PluginSecret` through `agent_logging.get_log`. The registration log line now carries a short fingerprint (`session=<8 hex>`; a gateway-issued id keeps its `gw-session~` prefix) instead of the credential.
