- **Gateway: a request that cannot be encoded no longer counts against the upstream circuit breaker.** A registration request carrying text that is not valid UTF-8, or a configured `cluster_id` with non-ASCII characters that was converted without the unicode conversion, failed in the gateway's own encoder, and that local failure was counted as an upstream failure: enough of them opened the breaker and refused registration and inventory for every agent until its backoff ended. A local encoding failure now leaves the breaker unchanged, a held notification that cannot be encoded no longer blocks the queue (as the half open probe it is evicted with a warning; with the breaker closed an ordinary worker loses it), and the gateway converts `cluster_id` with the unicode conversion and refuses to start when the name cannot be represented as UTF-8. `circuit_breaker_reset_timeout_ms` and `circuit_breaker_max_reset_timeout_ms` are now range-checked (1 to 3600000 ms, invalid values take the default with a warning). Refs #4632
