- **Gateway: a request that the gateway rejects locally can no longer open the upstream circuit breaker.** A request that the gateway's own validation or encoder rejected, or a server status that means the request itself was wrong (such as `INVALID_ARGUMENT`), could be counted as an upstream failure and open the circuit breaker until its backoff ended. Earlier gateway builds are affected and an upgrade is recommended (gateway restart required). The gateway now refuses an agent id outside 1 to 256 bytes at the edge, treats a failure inside its own request encoder as local (the request never reached the server, so it is not an upstream failure), and no longer counts server statuses that mean the request itself was wrong against the breaker; local encoder failures are counted in `yuzu_gw_upstream_rpc_errors_total` with `code="encode"` (the new alert `YuzuGatewayUpstreamEncodeErrors` fires at about ten of them in 10 minutes), and an agent id refused at the edge in `yuzu_gw_register_refused_total`. A held notification that cannot be encoded no longer blocks the queue (as the half open probe it is evicted with a warning). Refs #4632
