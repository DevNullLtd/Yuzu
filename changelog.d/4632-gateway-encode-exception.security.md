- **Gateway: registration validation hardened so a malformed `Register` can no longer open the upstream circuit breaker.** Earlier gateway builds are affected and an upgrade is recommended (gateway restart required). The gateway now refuses an empty or over-256-byte agent id at the edge, treats a failure inside its own request encoder as local (the request never reached the server, so it is not an upstream failure), and no longer counts server statuses that mean the request itself was wrong (such as `INVALID_ARGUMENT`) against the breaker; local encoder failures are counted in `yuzu_gw_upstream_rpc_errors_total` with `code="encode"`, and an agent id refused at the edge in `yuzu_gw_register_refused_total`. Before, enough such registrations could stop registration and inventory for every agent until the backoff ended. A held notification that cannot be encoded no longer blocks the queue (as the half open probe it is evicted with a warning). Refs #4632
