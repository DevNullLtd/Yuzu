- **Software normalisation curation REST routes: list the queue, curate a title, reject an entry, replace the alias pack.** `GET /api/v1/inventory/software/normalization/status` and `.../queue` (most-installed first, keyset pagination) need a global `Inventory:Read`; `POST .../aliases`, `.../queue/{key}/reject` and `.../pack` need a global `Inventory:Write`. A confined caller and a service-scoped token are refused with `403`. A curated alias binds exactly one edition, and a curated alias or a replaced pack marks every title for re-resolution in the same transaction, so the next normalisation passes pick the fleet up again. Each write is audited as `inventory.software.curation.alias`, `.reject` or `.pack` before it is applied, and an audit row that cannot be stored refuses the request with `503` and `Sec-Audit-Failed`. REST only; the MCP tool and the page for this are not part of this change. The OpenAPI document gains five operations.
