- **Dashboard History lists only sends the server dispatched, and does not replay masked commands.** `POST /api/dashboard/execute` answers `200` for a refusal (a Destructive target without a named agent, a send that reaches no agent) as well as for a send, so History logged refused sends as sent. A dispatched send now carries an `X-Yuzu-Dispatched: <agent count>` response header and History adds a row only when it is present. A History entry whose command had secret values masked is no longer put back in the command box and re-sent with the placeholder as the value; clicking it asks for the command to be typed again.
