- **Guard edit and delete on the Guardian Guard page.** Users with `GuaranteedState:Write` / `:Delete` can edit a Guard's name, severity and enabled state (Mode is shown read-only; last write wins) and delete a Guard by typing its name, from the dashboard. Both need an MFA step-up, are refused for service-scoped API tokens and cross-origin requests, and use the same audit verbs as the REST and MCP routes (`guaranteed_state.rule.update` / `.rule.delete`). Deleting does not unarm agents that are already enforcing the Guard until the next push.
