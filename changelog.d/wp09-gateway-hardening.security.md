- Gateway: the Erlang distribution cookie no longer has a published fallback in `vm.args.src`; the container entrypoint and the systemd unit refuse an unset, default or short cookie before the VM starts, and `YUZU_GW_ALLOW_DEFAULT_COOKIE=1` now yields a random per-boot cookie (single node, loopback-bound) instead of a known one. A Register the server rejects (`accepted=false`, or no session id) no longer leaves a pending registration, and Subscribe refuses an empty `x-yuzu-session-id`. The proto drift script no longer re-creates its scratch directory by name. Distribution remains unencrypted TCP (documented; TLS distribution is a follow-up decision).
