- **The Windows agent installer no longer aborts when started from PowerShell 7.** The installer checks the update trust-anchor directory's permissions with Windows PowerShell. Windows PowerShell inherited PowerShell 7's module path from whatever launched the installer, found module copies it cannot load, failed the check, and stopped the install with "the permissions could not be read" (0.14.0-rc3). The same applied to the boot process-capture AutoLogger setup, which skipped itself silently, and to the server installer's configuration step. Each now uses Windows PowerShell's own modules.
