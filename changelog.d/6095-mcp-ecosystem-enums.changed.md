- **The `ecosystem` enums served by the MCP tools now follow the software catalogue's order (#6095).** The set is the same twelve values (plus the empty string on the three crypto tools); the members are now listed `windows`, `optional_feature`, `msi`, `macos`, `macos_pkgutil`, `brew`, `rpm`, `deb`, `apk`, `pacman`, `snap`, `flatpak` (they began `rpm`, `deb`), so clients that derive constants from array position will see them shift and should compare them as sets. This covers `query_software_catalogue`, `get_software_versions`, `get_crypto_libraries`, `list_crypto_library_devices` and `export_crypto_cbom`, plus the `ecosystem (a|b|c)` sentence in `query_installed_software`'s description; all are now generated from `kEcosystemFamilies`, and a tool text that still carries a token after expansion refuses to boot.
