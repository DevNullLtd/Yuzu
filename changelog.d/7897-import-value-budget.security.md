- **Request bodies on the JSON-carrying route classes now have a JSON value budget, and `POST /api/export/json-to-csv` is capped at 16 MiB (#2146).** A size cap does not bound a parse tree: a 16 MiB body of `[],[],...` built a tree of 258 to 429 MiB per request, and eight concurrent ones by an authenticated caller were enough to get a process killed for exceeding a 2 GB memory limit. The post-read body-cap stage (`run_post_read_stage`) now counts the structural values (`[`, `{` and `,` outside a string literal) of the raw body against a per-class `max_json_values` in `kBodyCapTable` before any handler parses it, and answers `413` over the budget (`yuzu_body_cap_rejected_total{reason="over_json_values_post_read"}`): 100,000 on the catch-all, 200,000 on the MCP `/mcp/` envelope and `POST /api/v1/result-sets`, 30,000 on `POST /api/v1/commands` and the workflow execute subtree, 5,000 on `POST /api/v1/bundles`, 50,000 on guardian rule authoring, 600,000 on `POST /api/nvd/match`. On REST the definition import, create and update routes answer the same `413` from that stage; the `400 ... too many values` remains for the MCP `import_definition`, for each JSON-encoded string field the import re-parses (`parameter_schema`, `result_schema`, `visualization_spec`, `response_templates_spec`) and for a direct store call; the scan keys on the route class, not on `Content-Type`, so a non-JSON body over 100,000 `[`, `{` or `,` characters on a scanned class is also refused; the JSON form of `POST /api/workflows` and `POST /api/product-packs` is limited to 1,000 values. No real request is near these limits (a definition is a few hundred values; the largest legitimate bodies are 100,000 `device_ids`). The upload commit (`POST /api/v1/uploads/{id}/commit`) has its own 4 KiB body-cap class (its JSON body was parsed under the 8 MiB chunk cap). **Breaking:** `POST /api/export/json-to-csv` is capped at 16 MiB and 1,000,000 values (it was 100 MiB), and its CSV output at 16 MiB (`413`); split a larger export into several requests. Prometheus scrapers keyed on `path_class="upload_session"` no longer see commit rejections: they are `path_class="upload_commit"`.
