- **New critical alert `YuzuGatewayMgmtIdentityOutage` (#6016, release N+1).** It fires after one minute when a gateway refuses the server's certificate for want of the identity (`no_uri_san`, `identity_mismatch`) and admitted nothing by any method in the same five minutes, which is a total command outage under the shipped `identity` config (an own-certificate server on the pin-less config, or a built-in certificate not yet re-issued). `YuzuGatewayMgmtAuthRejected` (warning) still fires for the same cause; there is no inhibit rule, so expect the pair. A refusal amid normal admissions, any other reason, and `pin_mismatch` (which has its own critical alert) do not raise it. See "Alerts" in the gateway guide.
