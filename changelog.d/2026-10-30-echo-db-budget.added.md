- **Echo holds `echo.db` to a configurable byte budget.** The new `db_budget_bytes` setting (set with `echo.configure`; whole bytes, minimum 32 MiB, default 250 MiB) caps used database pages plus the write-ahead log. `echo.status` reports `db_budget_bytes`, `budget_over_bytes` (`unknown` when the size or the setting cannot be read), `budget_evicted_raw_rows_total`, `budget_evicted_hourly_rows_total`, `db_auto_vacuum` (`incremental`, `none` or `deferred`), `module_dedup_overflow_total` and `tcp_closing_dedup_overflow_total`, and a `retention_guard|__budget__|<n>` line when the retention clock guard refused a pass's clock and the budget pass was skipped. Windows module signing now looks an image with no embedded signature up in the system catalogs before it reads `unsigned`.
