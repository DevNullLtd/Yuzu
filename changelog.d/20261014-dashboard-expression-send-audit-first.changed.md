- **Expression-targeted Send fails closed.** A Dashboard send that targets a scope expression now stores an `attempted` audit row before it dispatches, and answers `503` (`audit_unavailable`, `Sec-Audit-Failed: true`) with nothing sent when the row cannot be stored; a send that reaches no agent records a `failure` row. The Send button is held until the confirmation dialog has loaded, so a missing script can no longer leave a one-click fleet send, and the masked parameter list comes from the server's own classification instead of a copy in the script.
