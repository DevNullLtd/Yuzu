- **Ctrl+K no longer navigates away while you are typing on the Instructions, Settings, Compliance, Guardian and Help pages, and Sign out now works on Help.** These five pages bound their own Ctrl+K handler that went to the dashboard command palette unconditionally, so it bypassed the app shell's check for a focused text field and could discard unsaved text (for example in the Instructions YAML editor or the Guardian search box); the shell's handler now owns the shortcut on every page, and Ctrl+K from a focused text field leaves the page alone. The Help page did not load htmx, so its Sign out button did nothing; it now signs out like every other page. Separately, the Guardian restyle changed the mode pill colours without a note at the time: Enforce is now the info blue and Observe is the muted grey (the Observe pill rule was removed).
