- **The bundled Compose stacks no longer start Grafana with the `admin`/`admin` login (#4817, #661).** `deploy/docker/docker-compose.yml`, `deploy/docker/docker-compose.uat.yml`, `deploy/docker/docker-compose.full-uat.yml` and `docker-compose.uat.yml` set `GF_SECURITY_ADMIN_PASSWORD=admin` and published Grafana on port 3000 on every interface, so anyone who could reach the host had full Grafana admin, including adding data sources that make Grafana request arbitrary internal URLs. These files now require `YUZU_GRAFANA_ADMIN_PASSWORD`, and **Compose refuses to run any command against them, `down` and `ps` included, until it is set** (for example `export YUZU_GRAFANA_ADMIN_PASSWORD="$(openssl rand -hex 16)"`, or a line in a `.env` file next to the compose file). `scripts/docker-start-UAT.sh` and `scripts/win-start-UAT.sh` use an exported value or generate a random one, keep it in `.uat/grafana-admin-password` (mode 0600), load it again for `stop` and `status`, print it in place of `admin/admin`, and refuse the value `admin`. The Compose Wizard no longer defaults the field to `admin`, refuses an empty value or `admin`, and writes the password only to the generated `.env`; the compose it generates requires it. **Existing installs keep their old password:** Grafana applies this setting only when it first creates its database, so on a stack that has already run, change it with `docker compose exec grafana grafana cli admin reset-admin-password '<new password>'` (the UAT launchers' `start` runs `down -v`, which resets it). The reference composes (`docker-compose.reference.yml`, `docker-compose.reference-gateway.yml`) run no Grafana and are unchanged. A new check, `tests/test_compose_default_credentials.py`, fails if a tracked compose runs Grafana without a required password. Out of scope and tracked separately: ClickHouse's default credentials and all-interface exposure in the same files (#420), the fixed Yuzu dashboard password hash in `docker-compose.uat.yml` (#417) and `deploy/config/uat/yuzu-server.cfg` (#4790), the ClickHouse password the Compose Wizard still writes into the generated compose (#3876), and the native Grafana that `scripts/start-stack.sh` starts with its built-in `admin`/`admin` login (#7053).
