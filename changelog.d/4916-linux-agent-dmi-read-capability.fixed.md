- **Packaged Linux agents now report the system serial number and UUID.** The `.deb`/`.rpm` agent unit grants `CAP_DAC_READ_SEARCH` as its only capability (`NoNewPrivileges` is kept), so the root-only DMI files no longer read `unknown`. The capability lets every plugin in the agent read any file on the host (read-only), and `mgmt_posture` and `remote_access_audit` now return data they previously refused. Scripts and other programs the agent starts do not inherit it, because the agent clears its inheritable and ambient capability sets at start. The unit also rebuilds a copy of the firmware tables in `/var/lib/yuzu-agent/dmi/` at each start. A slice of #4916. Opt-out drop-ins and a verify command are in `docs/user-manual/upgrading.md`.
