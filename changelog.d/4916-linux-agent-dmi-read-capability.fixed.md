- **Packaged Linux agents now report the system serial number and UUID.** The `.deb`/`.rpm` agent unit grants the agent `CAP_DAC_READ_SEARCH` (as its only capability, with `NoNewPrivileges` kept), so the root-only DMI files under `/sys/class/dmi/id` no longer read `unknown`. The unit also rebuilds a copy of the firmware tables in `/var/lib/yuzu-agent/dmi/` at each start. On a `.deb` install the grant takes effect at the next agent restart. A slice of #4916.
