- **Workflow runs on the Workflows page.** Each workflow now shows its Last run and Result, a Latest run panel (status, duration, device count and one row per step) and a Recent runs list, behind the same fleet-read scope as `GET /api/v1/workflow-executions`. Backed by the new `GET /fragments/workflow-runs` and `GET /fragments/workflow-runs/{id}` fragments. A run outside your device scope looks the same as a run that does not exist.
