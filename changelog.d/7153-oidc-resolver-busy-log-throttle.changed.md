- **Behaviour change: four OIDC name-lookup warnings are each written at most once per 60 s per key.** They are the "lookup pool is full" warning, the NAT64 "prefix lookup was not started" warning, the refused-recent warning (a name refused from memory, and an admission check that did not complete, share one key) and the refused-name-limit warning (a name at its limit of 8, and a full table of 64 names, share one key). Later occurrences in a window are written at debug level, so at the default log level only the first occurrence per key is written, a count of those warning lines no longer counts refusals, and another name's refusal in the same window can be hidden; `yuzu_server_oidc_resolver_lookups_total{outcome="busy"}` has the full count, and an operator who needs every occurrence in the log runs the server at debug level. The timeout warning is unchanged, and the failing request's own error is unchanged. See `docs/user-manual/upgrading.md`.
