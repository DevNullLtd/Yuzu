- **Behaviour change: the OIDC "lookup pool is full" and NAT64 "prefix lookup was not started" warnings are each written at most once per 60 s.** Later occurrences in that window are written at debug level, so a count of those warning lines in the server log no longer counts refusals; `yuzu_server_oidc_resolver_lookups_total{outcome="busy"}` has the full count, and an operator who needs every occurrence in the log runs the server at debug level. The timeout warning is unchanged, and the failing request's own error is unchanged. See `docs/user-manual/upgrading.md`.
