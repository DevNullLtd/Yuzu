- Agent plugins no longer let endpoint-controlled text forge result rows: `filesystem` (`list_dir`, `search_dir`, Windows `get_version_info`), `installed_apps` (`query`, `list_per_user`), `processes` (`query`), `procfetch` (every OS leg) and `wmi` (`query`, `get_instance`) now neutralise `|`, CR and LF in every file-name, registry, process and WMI field before it is written to a pipe-delimited row, as their sibling actions already did. `procfetch` and `wmi` rows now fold a literal backslash to `/` (the shared escaper's lossy contract, #5208). The Linux, Windows and macOS `network_config` `proxy` action now replaces any `user:password@` userinfo in the reported proxy value with `REDACTED@`, so proxy credentials no longer leave the endpoint; the redaction logic is hoisted from `update_source_trust` into `agents/shared/uri_userinfo_redact.hpp`.
