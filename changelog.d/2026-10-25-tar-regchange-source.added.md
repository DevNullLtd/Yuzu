- **TAR `registry` source (`$Registry_Live`, Windows, on by default).** TAR now records changes to a curated set of registry keys (Run and RunOnce, Services, Image File Execution Options, AppInit_DLLs, Winlogon, LSA, Policies and Defender under HKLM, and the Run, RunOnce, Policies and Winlogon keys of every loaded user hive): each added, changed or removed value with its old and new data, and each removed key. A key watch finds what changed and a baseline diff gives the old and new data; the process that made a change is not recorded yet (`actor_pid` is 0), which follows in a later release. Values are stored unmasked and are readable through `tar.sql`. Retention is 500 000 rows; opt out with `tar.configure registry_enabled=false`. Device pages show the new source under a `System` category.
