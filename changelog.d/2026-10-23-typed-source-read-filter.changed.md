- **Generic inventory reads exclude the typed daily-sync sources.** `InventoryStore` reads (`query_inventory`, `get_agent_inventory`, the table list and the inventory-query result-set source) now leave out `installed_software`, `app_perf`, `device_ci`, `software_licensing`, `app_usage` and the reserved `certificate_inventory` in SQL. A stray typed row from a mixed-version window or a failed boot purge can no longer be read under `Infrastructure:Read` or `Inventory:Read`. The gateway skip, the boot purge and the read filter now share one list, `kTypedInventorySources` (ADR-0070 D12, slice-2 PR 2a-1).
