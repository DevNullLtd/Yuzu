- **Two sample alert rules for Echo.** `YuzuEchoDbCorruptionDetected` fires when the count of agents with a quarantined Echo database rises over an hour (a lower bound on new quarantines, not an event count), and `YuzuPluginInitFailed` fires when agents report a plugin that failed init for 15 minutes, with the Echo remedies in its description. Both ship with promtool cases and negative controls. No alert covers the on-demand `echo.status` registry keys yet; that needs a fleet gauge and is recorded as a deferred follow-up.
