- **`[pg_reachability]` unit tests no longer depend on an inherited `PGCONNECT_TIMEOUT`.** libpq applies that variable to every connection, and the reachability probe lets it override its own 3 s test deadline, so exporting it (as the CI sweep script already does for itself) made the host-list cases fail. A Catch2 listener in `test_pg_reachability_probe.cpp` now unsets it for the duration of each `[pg_reachability]`-tagged case and restores it afterwards. Test-only; no server behaviour changes.
