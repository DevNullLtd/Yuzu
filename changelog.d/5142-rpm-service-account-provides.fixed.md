- **The server and agent RPMs no longer fail to install with "nothing provides user(yuzu)".** Because the packages own directories as their service account, current `rpmbuild` adds `Requires: user(yuzu)`/`group(yuzu)` (server) and `user(yuzu-agent)`/`group(yuzu-agent)` (agent), which nothing provided, so `dnf install` refused them on Fedora, RHEL and Rocky. Each package now ships a `sysusers.d` entry for its account, which provides that requirement and lets rpm create the account; the existing pre-install account creation still covers older rpm. Separately, the Linux binaries still need a newer glibc/libstdc++ than RHEL/Rocky 9 ship (#5143). (#5142)
