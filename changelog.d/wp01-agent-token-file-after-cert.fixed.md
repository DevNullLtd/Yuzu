- **The agent keeps its enrollment token file until its client certificate is on disk.** While a certificate is being provisioned (a CSR is pending) the token is now removed only after the issued leaf has been persisted, or when provisioning is abandoned, instead of on the first accepted registration. If the agent stopped between the two, the old order left it with a live server-side leaf, no certificate and no token, which the server's re-registration proof check refuses until an operator issues a fresh single-use token.
