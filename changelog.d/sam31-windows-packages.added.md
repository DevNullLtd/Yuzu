- **Windows package managers and Store apps are now collected into installed software.** The `pkg_inventory` plugin's Windows legs read the Appx package roster that is registered for all users (Store apps and the inbox apps; per-user packages and the deprovisioned list are not collected), the Chocolatey packages installed under `C:\ProgramData\chocolatey\lib`, and the presence of Chocolatey and of winget (through the App Installer package), with no process spawned and no file hashed. The daily sync maps them into `installed_software` under three new ecosystems, `appx`, `chocolatey` and `winget`; the ecosystem filter values published by the REST API and MCP gain these three at the end of the list, and a client that validates `ecosystem` against a fixed list (the MCP `get_crypto_libraries` tool refuses an unknown value) must add them. Chocolatey's own version and a Chocolatey package whose nuspec cannot be read are reported with an empty version.
