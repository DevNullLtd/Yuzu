- **`runtimes.jvm`: Linux Java homes now report JDK or JRE on every distribution.** Debian, Ubuntu and openSUSE OpenJDK `release` files carry no `IMAGE_TYPE`, so those homes used to report flavour `unmodelled`. When the `release` file has no `IMAGE_TYPE` (or there is no `release` file at all), the Linux leg now reads the flavour from the home's `bin` directory: `jdk` when `bin/javac` is there, `jre` when only a java binary is. Only the directory entry is looked at: nothing is run, no symlink is followed and no module list is read. A home whose `bin` cannot be read, or is a symlink, stays `unmodelled` and records the usual constraint token. When the file has an `IMAGE_TYPE` it still decides. The vendor is still the `release` file's `IMPLEMENTOR` as written (openSUSE writes `N/A`), and the macOS and Windows legs are unchanged.
