- **Breaking for build scripts: the server is now a Meson feature option, `-Dserver` (`auto` | `enabled` | `disabled`), and Windows and macOS builds install the agent's dependencies only (ADR-0035).** `auto` (the default) builds `yuzu-server` on a Linux target and skips it on any other; `-Dserver=enabled` on a non-Linux target is a configure error. The boolean `-Dbuild_server` is deprecated but still honoured as an extra off-switch, and is removed in a later release. `scripts/setup.sh` on a Windows or macOS host (no cross file) now installs the agent-only vcpkg profile (no libpq, xmlsec or drogon, but with Catch2), so a server build there is no longer possible. The Windows agent archive (`yuzu-agent-windows-x64.zip`) no longer contains the server's DLLs (`libpq`, `libecpg`, `libpgtypes`, `drogon`, `trantor`, `jsoncpp`, `libxmlsec1`) and the release job refuses an archive that does. A build directory that stored `-Dbuild_server` needs `rm -rf <dir>` and a fresh configure when the option is removed; `--wipe` replays stored options and does not help.
