- **`file_search` now ships on, on Linux, macOS and Windows.** The server no longer seeds a default-off kill switch for the plugin, so a fresh deployment dispatches the action (still `FileRetrieval` with `AdminOrApproval`, still not single-target, and what it stores is still readable only with a global `Forensics:Read`). An operator can turn it off with `PUT /api/v1/plugin-config/file_search/kill-switch` and `enabled` set to `false`. An existing kill-switch row is not changed by the upgrade: a deployment where the plugin was switched off keeps it off.
