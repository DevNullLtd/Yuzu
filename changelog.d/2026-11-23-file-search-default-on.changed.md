- **`file_search` now ships on, on Linux, macOS and Windows.** The server no longer seeds a default-off kill switch for the plugin, so a fresh deployment dispatches the action (still `FileRetrieval` with `AdminOrApproval`, still not single-target, and what it stores is still readable only with a global `Forensics:Read`). An operator can turn it off with `PUT /api/v1/plugin-config/file_search/kill-switch` and `enabled` set to `false`, or for the Windows leg only with `?os=windows` on the same request. The server no longer writes this row; a row already present is left as it is. `file_search` has not been in a release (v0.15.0 holds no `agents/plugins/file_search` file), so no released default changes; this entry and the Windows-leg entry replace what the earlier unreleased entry says about the plugin starting off and its Windows leg being planned.
