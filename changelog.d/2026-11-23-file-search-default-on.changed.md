- **`file_search` ships on, on Linux, macOS and Windows.** The server seeds no kill switch for the plugin, so a fresh deployment dispatches the action (`FileRetrieval` with `AdminOrApproval`, not single-target, and what it stores is readable only with a global `Forensics:Read`). An operator can turn it off with `PUT /api/v1/plugin-config/file_search/kill-switch` and `enabled` set to `false`, or for the Windows leg only with `?os=windows` on the same request. The server never writes this row; it exists only when an operator sets it.
