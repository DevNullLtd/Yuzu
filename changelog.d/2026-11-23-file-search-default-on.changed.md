- **`file_search` ships on, on Linux, macOS and Windows.** The server seeds no kill switch for the plugin, so a fresh deployment dispatches the action (`FileRetrieval` with `AdminOrApproval`, not single-target, and what it stores is readable only with a global `Forensics:Read`). An operator turns it off with `PUT /api/v1/plugin-config/file_search/kill-switch?action=search` and `enabled` set to `false`, or for the Windows leg only with `?action=search&os=windows`; the action-level row is used because an action-level ON row overrides a plugin-level OFF. The server never writes this row; it exists only when an operator sets it.
