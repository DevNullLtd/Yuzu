- **Breaking — `filesystem.replace` with `regex=true` refuses a file over 64 KiB (previously up to 100 MiB), and `ioc.check` refuses more than 100 `domains` in one command (previously unlimited).** `filesystem.search` with `regex=true` now skips any line over 64 KiB and reports it as a `skipped|<line>|line exceeds regex limit (65536 bytes)` row instead of searching it, so a consumer that counts matches must also read `skipped|` rows. A refused regex replace answers `error|regex replace refused: file exceeds 65536 bytes (use a literal search)` with rc 1 and changes nothing; a refused `ioc.check` answers one `error|domains|false|Too many domains (N, max 100)` row with rc 1 and checks nothing. Literal (non-regex) replace and search are unchanged. See "Upgrading" for what to change in callers.
