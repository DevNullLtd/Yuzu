- **Spark detached-call lane admission is now compare-and-swap based.** The `SparkDetachedLane` shared admission primitive now admits with a compare-and-swap instead of increment-then-check-then-rollback, so its active-worker gauge never reads above the configured cap and a concurrent launch landing in a rejected launch's rollback window is no longer spuriously rejected. No watch is armed through Spark until Spark detection is turned on, which it is not in production agents; the gauge feeds test debug counters only. (#4660)
