- **CI: the vcpkg sentinel no longer strands sanitizer trees on self-hosted runners.** The sentinel wiped the workspace-wide vcpkg registry when one triplet's key changed but left the other triplets' install trees, so the next ASan/TSan `vcpkg install` failed with `protoc: File exists` and the smoke test then failed on a missing `CLI11`. It now wipes any `vcpkg_installed/<triplet>/` tree that the registry does not list, on every run.
