- **Breaking - gateway heartbeat admission is bound to the connection of the session's Subscribe stream (gateway restart required).** The Erlang gateway admits an agent `Heartbeat` only on the HTTP/2 connection that opened the session's `Subscribe` stream; any other heartbeat gets `NOT_FOUND`, is counted in the new `yuzu_gw_heartbeat_rejected_total{reason}` and `yuzu_gw_heartbeat_session_mismatch_total{event="security"}`, and is not forwarded. Agents must reach the gateway directly or through L4 / TLS passthrough; HTTP/2-terminating proxies are unsupported. Deployments that use this gateway need agents 0.13.0 or newer (the 0.13.0 release candidates lack the recovery): upgrade agents first, then the gateway. Agents that do not connect through the gateway are not affected. `/readyz` now reports `sessions_index`. Refs #1197, #3869.
