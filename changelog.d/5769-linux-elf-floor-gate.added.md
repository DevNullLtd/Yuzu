- **Linux ELF floor gate (report-only).** `scripts/ci/check-elf-floor.sh` measures the versioned-symbol requirements of every ELF in the Linux release staging directory against the committed floor files `deploy/packaging/linux-floor-{agent,server}.json` (agent: glibc 2.28; server and gateway: glibc 2.34): glibc, libstdc++, libstdc++ ABI, systemd, libblkid and OpenSSL tags are compared with the floor, other families (for example `GCC_*` from libgcc) are only reported, and forbidden symbols (`EVP_sm4_*`) and non-`$ORIGIN` `RUNPATH` entries are flagged. The release workflow runs it report-only on the Linux x64 staging directory and uploads the report, and `deploy/packaging/linux-floor-baseline.json` records the measured gap of the v0.14.1 artifacts; nothing fails because of it yet (ADR-2003 (Proposed, PR #5631), slice S0). This changes no shipped package and no minimum supported distribution: the floor files state a target, and the packages still require glibc 2.38 until the build moves to the floor in a later slice (#5143 and #5171 remain open). Pre-release QA also gains non-gating `rockylinux:8` and `amazonlinux:2023` `.rpm` install legs, expected to fail until then.
