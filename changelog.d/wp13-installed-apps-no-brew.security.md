- **macOS `installed_apps.list_per_user` does not execute Homebrew's `brew` as root.** The macOS agent runs as root and a Homebrew prefix is owned by the installing user, so running `brew` ran a user-controlled script as root. The action lists system apps only; Homebrew formulae and casks are in `pkg_inventory.packages`. There are no `user_app|brew|...` rows.
