- **Gateway: a slow server is now defined, exported as metrics and alerted on.** The gateway measures the share of time its path to the server is backed up (the upstream process inside an RPC with work waiting, or all stream-status notification or Guardian forward slots held) and exports it as `yuzu_gw_upstream_backpressure_seconds_total` (whose `rate()` is the duty cycle), `yuzu_gw_upstream_lane_saturated_seconds_total{lane}`, `yuzu_gw_upstream_backpressure_duty_cycle` (last 60 s) and `yuzu_gw_upstream_slow` (1 at a duty cycle of 0.5 or more). The new warning alert `YuzuGatewayUpstreamSlow` fires when the flag has been 1 for 5 minutes. Behaviour is unchanged: the breaker still counts only failed calls, and `/readyz` still calls the upstream process (#5680, #5681). See "Slow server" in the gateway manual.
