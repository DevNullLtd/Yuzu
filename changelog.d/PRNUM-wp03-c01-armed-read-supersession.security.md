- **A break-glass sign-in is refused at the MFA step's second arm check when the account was seen disarmed during that check's own read.** Under `--auth-mode=sso-only`, the check before the session is created now refuses an "armed" answer when this server recorded a "not armed" read that ended at or after the check's own read started, as the cache and the first check already did. Such a login answers the generic `401`, is audited as `auth.login` `failure` with `reason=break_glass_disarmed_before_mint`, and counts in `yuzu_auth_break_glass_pending_refused_total{reason="disarmed",stage="pre_mint"}`. A recovery code checked by that login is already spent. Follow-up to #8626 (review finding C-01).
