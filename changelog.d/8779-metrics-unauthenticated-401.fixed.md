- An unauthenticated or wrong-token `GET /metrics` is answered `401` with the JSON error body, the same answer as `/api/`, `/events` and `/mcp/`, so a Prometheus scrape without a valid token reads as a failed scrape (`up == 0`) and is not redirected to the sign-in page. A direct loopback peer is exempt only under `--metrics-trust-loopback`, and `--metrics-no-auth` admits any source. (#8732)
