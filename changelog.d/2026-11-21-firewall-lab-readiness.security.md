- **The root-owned firewall helper gains a read-only `snapshot` word.** `yuzu-fw-helper snapshot` prints the host's nftables and iptables listings (`nft -a list ruleset`, `iptables -S`, `ip6tables -S`, each under its own header, at most 1 MiB) and changes nothing, so the agent account can now read the host's nftables ruleset (`nft -a list ruleset`, rule handles included) through the sudo grant it already has; the `iptables -S` and `ip6tables -S` reads go through the same grant. No new sudoers line is needed: the line names the helper with no argument, and the word takes no argument of its own. `snapshot` is accepted only on a host provisioned with this build's `scripts/install-agent-user.sh`; `--check` reports a helper that differs from the installer's text. No plugin action calls it; it exists for the live containment harness.
