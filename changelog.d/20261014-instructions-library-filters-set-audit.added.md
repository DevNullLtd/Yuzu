- **The Instructions library lists more than the first 100 definitions honestly, and instruction set create and delete are audited.** `GET /fragments/instructions` accepts `name`, `plugin`, `type` and `limit` (default 100, maximum 500) and shows "Showing the first N. Narrow the filter." when the list is cut; a store failure reads "This is not an empty library." instead of an empty table. When the caller holds `InstructionDefinition:Read` the table gains a "Needs approval" column, and when the caller holds `InstructionSet:Read` it gains a read-only sets panel with member counts; otherwise the call is unchanged apart from the sets panel's denied note. `POST /api/instruction-sets` now writes `instruction_set.create` rows for success, store failure, conflict and rejected input, and `DELETE /api/instruction-sets/{id}` writes an `instruction_set.delete` success row (a failed audit write sets `Sec-Audit-Failed`).
