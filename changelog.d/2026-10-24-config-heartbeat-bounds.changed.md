- **`heartbeat_timeout` is limited to 30 to 86400 seconds** on every write surface (`PUT /api/config/{key}`, `PUT /api/v1/config/{key}` and `set_runtime_config`). The upper bound is new: a larger value left dead agents reading online. The configuration read now reports `log_level` as `warn`, the spelling the write accepts, instead of `warning`, and a value of `-0` for an integer key is refused.
