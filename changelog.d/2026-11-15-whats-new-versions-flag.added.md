- **`scripts/whats-new.py` gains `--versions`, a `**Breaking` count in the header and a `[released X.Y.Z]` marker, and is linked from `README.md` and `docs/user-manual/upgrading.md`.** `--versions` prints only the version bumps, the rebuild / redeploy notes and the Docker image bumps. The header shows a `Breaking` line when the range adds entries that start `**Breaking`, and the changelog heading counts how many entries are breaking and how many a release inside the range already moved into `CHANGELOG.md`; those entries end `[released X.Y.Z]`. The Windows launcher form (`py -3 scripts\whats-new.py`) is documented in `changelog.d/README.md` and `docs/build-guide.md`. No change to the default output beyond the count and the markers.
