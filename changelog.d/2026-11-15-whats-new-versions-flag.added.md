- **`scripts/whats-new.py` gains `--versions`, a `**Breaking` count and a `[released X.Y.Z]` marker, and is linked from `README.md` and `docs/user-manual/upgrading.md`.** `--versions` prints the header, the version bumps, the rebuild / redeploy notes and the Docker image bumps, and still prints a `!` line for any fragment it could not read or list. The header adds a `Breaking` line when the range adds entries that start `**Breaking`, and the changelog heading counts the breaking entries and the ones a release in the range already moved into `CHANGELOG.md`. Those end `[released X.Y.Z]`, or `[released]` when the version cannot be told; an entry with no marker was not moved by a release in the range. The Windows launcher form (`py -3 scripts\whats-new.py`) is documented in `changelog.d/README.md` and `docs/build-guide.md`. Abbreviated flags such as `--version` are no longer accepted.
