- **Gateway holds stream-status notifications instead of dropping them.** When the 10-notification in-flight limit was reached or the upstream circuit breaker was open, the gateway dropped `CONNECTED` and `DISCONNECTED` notifications, which could leave agents acknowledged by the server but not dispatchable until they reconnected. They are now held in memory only, in a bounded store keyed by agent, session and stream home (a notification lost after admission is not retried), replaced in place by newer events for the same key, and sent first in first out. While the breaker is half open one held notification is sent as the probe; probe delivery is at least once. An agent-supplied peer address is now sanitised and capped before it is held. New gauges `yuzu_gw_upstream_notify_pending` and `yuzu_gw_upstream_notify_inflight`, counter `yuzu_gw_upstream_notify_coalesced_total`, and setting `notify_pending_max` (default 10000); `yuzu_gw_upstream_notify_dropped_total` now counts only `at_capacity`. Refs #4632
