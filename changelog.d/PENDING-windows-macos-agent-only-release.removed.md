- **Breaking: the Windows server installer (`YuzuServerSetup-*.exe`) is discontinued, and the Windows and macOS release archives now hold the agent only and are renamed.** The server is supported on Linux only (ADR-0035): run it from the container image or the Linux `.deb`/`.rpm` packages. The archives are now `yuzu-agent-windows-x64.zip` and `yuzu-agent-macos-arm64.tar.gz` (previously `yuzu-windows-x64.zip` and `yuzu-macos-arm64.tar.gz`, which also held `yuzu-server`), with matching SBOM names, and the top-level directory inside each archive is renamed the same way; update any script that downloads or unpacks them by name. To move an existing Windows or macOS server to Linux, back up its database and its CA directory together before removing anything, then follow "Moving a Windows or macOS server to Linux" in the server administration guide, which also lists the leftover files that hold secrets. Known limitation: the Windows agent archive still contains unused server-side DLLs (`libpq.dll` among them) until a later release trims the Windows build, and the Windows and macOS SBOMs, which are generated from the whole build workspace, list PostgreSQL client libraries the agent does not use.
