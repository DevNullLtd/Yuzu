- **Breaking: the Windows server installer (`YuzuServerSetup-*.exe`) is discontinued, and the Windows and macOS release archives now hold the agent only and are renamed.** The server is supported on Linux only (ADR-0035): run it from the container image or the Linux `.deb`/`.rpm` packages. The archives are now `yuzu-agent-windows-x64.zip` and `yuzu-agent-macos-arm64.tar.gz` (previously `yuzu-windows-x64.zip` and `yuzu-macos-arm64.tar.gz`, which also held `yuzu-server`), with matching SBOM names, and the top-level directory inside each archive is renamed the same way; update any script that downloads or unpacks them by name. To move an existing Windows or macOS server to Linux, deploy a new Linux server, enroll the agents with it and retire the old one as "Moving a Windows or macOS server to Linux" in the server administration guide describes: the old server's data cannot be carried over, and the guide lists the leftover files that hold secrets. Known limitations: the Windows agent archive still contains server-side DLLs (`libpq.dll`, `drogon.dll`, `trantor.dll`, `libxmlsec1`) that the agent never loads, until a later release trims the Windows build; and the Windows and macOS SBOMs, generated from the whole build workspace, list thousands of components the archive does not ship, the server's dependencies among them.
