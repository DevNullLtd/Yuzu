- **Breaking: the Windows server installer (`YuzuServerSetup-*.exe`) is discontinued, and the Windows and macOS release archives now hold the agent only and are renamed.** The server is supported on Linux only (ADR-0035): run it from the container image or the Linux `.deb`/`.rpm` packages. The archives are now `yuzu-agent-windows-x64.zip` and `yuzu-agent-macos-arm64.tar.gz` (previously `yuzu-windows-x64.zip` and `yuzu-macos-arm64.tar.gz`, which also held `yuzu-server`), with matching SBOM names; update any script that downloads them by name. The installer never produced a running service (#5325, #1835); to remove one installed by an earlier release, run its uninstaller and then delete `%ProgramData%\Yuzu Server` once you no longer need the configuration and keys it keeps. Until a later release trims the Windows build's dependencies, the Windows agent archive still contains some unused server-side DLLs (`libpq.dll` among them) and its SBOM still lists them.
