- **Sample alert rules for the OIDC name lookup pool.** The new `yuzu-oidc-resolver` group of `docs/prometheus/yuzu-alerts.yml` adds `YuzuOidcResolverPoolHigh` (the pool above 75% of its capacity for 5 minutes) and `YuzuOidcResolverLookupsRefused` (refused lookups sustained for 10 minutes), each with promtool cases. The shipped rule file is a set of samples and is not loaded by anything in this repository.
