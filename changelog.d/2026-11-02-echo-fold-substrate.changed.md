- **Breaking — `echo.sql` refuses `WITH`, `NATURAL`, `USING` and bound-parameter markers.** A query that starts with `WITH` is answered `only SELECT queries are allowed`; `WITH` elsewhere, a `NATURAL` join and a `USING` join are answered `query contains forbidden keyword: <word>`; `?`, `$x`, `:x`, `@x` and `#x` are answered `query contains a bound-parameter marker`. A subquery replaces a CTE and a join is written with `ON`; table names such as `$Process_Hourly` still work. Stored schedules, pinned result sets, workflow steps and REST or MCP callers that carry such a query fail on an upgraded agent (see the upgrade notes).
