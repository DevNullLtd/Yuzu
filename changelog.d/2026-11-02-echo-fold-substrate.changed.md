- **`echo.sql` refuses `WITH`, `NATURAL` and `USING`.** A query using a common table expression (`WITH`) or a `NATURAL` / `USING` join is rejected with `query contains forbidden keyword`, and a `--`, `/*` or quote character inside a quoted identifier (`"..."`, `` `...` `` or `[...]`) no longer hides one of these words from the check. No shipped query used them: a subquery or window function expresses the same reads, and a join is written with `ON`.
