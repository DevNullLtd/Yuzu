- **Echo no longer treats an unreadable or damaged `usage_generation` as generation 0, and the v10 upgrade no longer expires long usage runs early.** A read fault on that row could report the usage lifecycle as Active, let a `usage_enabled` change bump from a guessed generation, or stamp a baseline that deleted the open runs; each now fails closed (the lifecycle reads PendingBaseline, the change is refused, nothing is stamped). Separately, the v10 migration's chunked usage walk now defers the open-run expiry and cap to one closing sweep, so a run older than seven days whose stop lands in a later chunk is credited instead of expired. The manual gains a troubleshooting entry for process roll-ups that stop while usage is enabled.
