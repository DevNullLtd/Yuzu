- **The DEX score policy gains the scoring model parameters.** The per-device event cap (default 5), the regression full-weight ratio (3.0) and start ratio (1.0) can be set globally and per application, and the interval confidence level (0.95) globally. The confidence level applies to the Apps share and rate intervals only. Bounds: cap 1 to 1000 (an integer), start 1.0 to 1000.0, full above start up to 1000.0, confidence 0.5 to 0.999. The defaults reproduce the previous scores, intervals and bands exactly, and stored version 1 documents stay valid. A document that sets any model parameter is written as version 2; an older replica refuses it and scores under the shipped defaults (see the upgrade notes). The Apps description now states the interval level instead of a fixed 95 percent. The new parameters are accepted by the existing `PUT /api/v1/dex/score-policy`, and the Apps response does not yet report them.
