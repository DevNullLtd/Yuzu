- **Read-only deployment list and detail over REST and MCP, and an NVD status card.** `GET /api/v1/deployments`, `GET /api/v1/deployments/{id}` and MCP `list_deployments` / `get_deployment` show your deployments from the live `/auto` pipeline without advancing the engine or writing an audit row per read. A deployment reads Running or Complete, with the failed or skipped count on a finished one ("Complete, 2 failed"); the installer URL and arguments are never returned. Store faults answer `503` with a retry hint rather than an empty list. The dashboard fragments `GET /fragments/auto/deployments` and `GET /fragments/auto/deployments/detail?dep=` render the same data. `GET /fragments/auto/nvd` shows the NVD feed status (CVE count, last sync, running, last error).
