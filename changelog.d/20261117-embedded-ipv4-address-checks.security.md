- **Breaking — outbound address checks decode two more IPv6 forms that embed an IPv4 address, and refuse an undecodable local-use NAT64 address.** The check the server runs before an OIDC request (discovery, JWKS, Test Connection, token POST) and before registering a CRL source now also classifies SIIT (`::ffff:0:0:0/96`) and IPv4-compatible (`::/96`) addresses by the IPv4 address they embed, never as more open than non-global. An embedded unspecified, link-local, cloud-metadata, multicast or reserved address is refused even with `--oidc-allow-private-networks`; for a CRL source an embedded loopback address or one of the server's own addresses is refused too. Plain http to the SIIT or IPv4-compatible form of a public address is refused as plain http to a public address is. An address in the local-use NAT64 prefix `64:ff9b:1::/48` that no known prefix covers is refused whatever the switch says: for OIDC a configured or learned prefix, for a CRL source a prefix declared with `--oidc-nat64-prefix`. See `docs/user-manual/upgrading.md`.
