- **Dashboard audit rows record a hashed session identifier.** For requests carrying a dashboard session cookie, the `session_id` column of `audit_store.audit_events` now holds the SHA-256 hex digest of that cookie — the same value the session store keys on and the analytics event store already records — instead of the cookie value itself. Rows for requests without a cookie keep an empty `session_id`; agent-session rows written by the gRPC service are unchanged. Rows written by earlier releases keep the value recorded at the time; anything that correlates a dashboard audit row with a live session should compare against the digest.
