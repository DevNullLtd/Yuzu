- MCP tools `list_hardware_ci`, `get_hardware_ci` and `list_quarantined_devices`, twins of `GET /api/v1/hardware`, `GET /api/v1/hardware/{id}` and `GET /api/v1/quarantine`. They apply the same fleet-read confinement as the REST routes and return the same bytes. The two hardware tools carry personal data (serial, UUID, MAC) and withhold it when their audit row cannot be written; `list_quarantined_devices` returns its list and flags `audit_persisted:false` instead. A registry tool called with a non-object `arguments` value is now refused with a `-32602` error and a denied audit row before its handler runs.
