- **Behaviour change: a CRL source registration refused because the resolver pool was at its cap, or a lookup worker could not be started, while looking up a listen-host name is now counted as `dns_busy`.** It used to be counted as `own_addresses_unavailable` in `yuzu_server_revocation_source_degrade_total`, so an alert or query that selects only `own_addresses_unavailable` should also select `dns_busy` (or use `sum by (reason)`). The request is unchanged: the same retryable `503`, the same body and the same `retry_after_ms` of `5000`, and nothing registered. A listen-host lookup that times out, fails transiently or runs out of budget still counts `own_addresses_unavailable`. See `docs/user-manual/upgrading.md`.
