- **`installed_apps` (Windows): an unreadable Uninstall hive is reported, never presented as complete.** A root that cannot be opened or enumerated to the end, or a denied application subkey, now makes `list`/`query` return one `error|installed_apps: acquisition degraded (...)` row with rc 1 instead of a partial list, and `list_inventory` return rc 1 with no rows (`CONSTRAINED`, `installed_apps:acquisition_degraded`), so the daily inventory sync skips the cycle instead of committing a silently shorter inventory; `list_per_user` keeps its rows and adds `warning|hive_read_failed`. Automation that treated a Windows `list` as always succeeding needs the same update the Linux/macOS legs already require. A registry string over 511 characters is now read (up to 64 KiB) and carried at up to 4 KiB per field instead of dropping the application (#4711, #4714, #4716).
