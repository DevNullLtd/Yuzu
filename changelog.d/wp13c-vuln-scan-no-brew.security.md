- **macOS `vuln_scan` (`cve_scan`, `scan`, `summary`, `inventory`) no longer executes Homebrew's `brew` as root.** The macOS agent runs as root and a Homebrew prefix is owned by the installing user, so `brew list --versions` ran a user-controlled script as root. The macOS software list is `system_profiler` apps only; Homebrew formulae and casks are not scanned by this plugin (`pkg_inventory.packages` reports them without a subprocess). The four macOS actions report `CONSTRAINED`/`PARTIAL` (`macos:vuln_scan:homebrew_not_scanned`, or `macos:vuln_scan:system_profiler_unreadable` when `system_profiler` fails or returns no applications), and the macOS commands run by absolute path.
