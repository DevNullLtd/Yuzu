- **macOS `vuln_scan` (`cve_scan`, `scan`, `summary`, `inventory`) no longer executes Homebrew's `brew` as root.** The macOS agent runs as root and a Homebrew prefix is owned by the installing user, so `brew list --versions` ran a user-controlled script as root. The macOS software list is now `system_profiler` apps only; Homebrew formulae and casks are not scanned by this plugin (`pkg_inventory.packages` reports them without a subprocess).
