- **macOS `vuln_scan` (`cve_scan`, `scan`, `summary`, `inventory`) does not execute Homebrew's `brew` as root.** The macOS agent runs as root and a Homebrew prefix is owned by the installing user, so `brew list --versions` ran a user-controlled script as root. The macOS software list is `system_profiler` apps only; Homebrew formulae and casks are not scanned by this plugin (`pkg_inventory.packages` reports them without a subprocess). `cve_scan` and `scan` end with an `INFO|scan|Coverage|Homebrew formulae and casks are not scanned` row and `summary` with `summary|COVERAGE|...` (when `system_profiler` fails, times out or returns no applications the row says the software list is empty, not clean); `inventory` stays pure name/version rows. The agent log records `CONSTRAINED`/`PARTIAL` for the same runs. A macOS config check whose tool cannot be read reports `INFO ... Unknown (read failed)`, never a HIGH/CRITICAL finding (`macos:vuln_scan:config_unreadable`). The macOS commands run as absolute-path argvs through the agent's bounded subprocess runner (no shell, no `PATH` search, a 60 s deadline, an 8 MB output cap).
