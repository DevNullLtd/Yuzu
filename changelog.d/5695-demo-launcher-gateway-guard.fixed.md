- **`scripts/start-demo.sh` no longer reports a demo that cannot work as up.** The demo's gateway config uses the `{yuzu_gw, grpc_listeners}` shape, and a gateway image older than 0.15.0 given it binds no listener while still answering `/healthz` and `/readyz` with 200. The launcher now refuses a pinned `YUZU_VERSION` older than 0.15.0 before starting anything (use `--build`, or a newer `--version`), checks that the started gateway is really listening on its agent and management ports, and exits non-zero with the gateway's last log lines, without the "demo is up" banner, when the agents have not all registered within `DEMO_REGISTER_TIMEOUT` (default 120 s). Host ports can be moved with `DEMO_HTTP_PORT` and `DEMO_GATEWAY_{AGENT,HEALTH,METRICS}_PORT`.
