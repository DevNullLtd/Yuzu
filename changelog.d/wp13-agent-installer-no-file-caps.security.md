- **The Linux dev/UAT installer no longer puts file capabilities on the agent binary, and the systemctl and launchctl sudoers globs are gone.** `install-agent-user.sh` set `cap_net_admin,cap_net_raw,cap_dac_read_search,cap_sys_ptrace` on a 0755 binary whose invoker chooses the plugin directory it loads, so any local user could become root. It now strips file capabilities (re-run it on every existing dev/UAT host) and `scripts/start-UAT.sh --as-user` grants `cap_dac_read_search` ambiently to the launched process instead. The `systemctl enable|disable|mask|unmask *` grants, which matched `enable --now <unit path>`, are replaced by one grant for a root-owned validating wrapper `/usr/libexec/yuzu/yuzu-systemctl`; the unused macOS `launchctl bootstrap|bootout system *` grants are deleted. The `iptables`, `nft` and `pfctl` grants are unchanged (#7634, #7629). See "Upgrading".
