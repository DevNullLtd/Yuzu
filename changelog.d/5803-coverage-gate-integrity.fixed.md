- The local `/test` coverage gate no longer reports an unreliable run as an ordinary figure. A second concurrent run on one build directory is refused. A run with failed or timed-out tests, libgcov counter-write errors or a nearly full disk (`YUZU_COVERAGE_MIN_FREE_KB`, default 262144) is inconclusive: a WARN row, no coverage metric, no baseline comparison, and `--capture-baselines` refuses it with a FAIL. An unknown line figure is no longer recorded as 0.0, and a failed gate or metric DB write now fails the gate (#6112, #6113, #6114).
