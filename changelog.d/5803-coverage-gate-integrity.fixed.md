- The local `/test` coverage gate no longer presents an unreliable run as a coverage figure (#6112, #6113, #6114). A second concurrent run on one build directory, or a run next to a surviving `meson test`, is refused. A run with failed or timed-out tests, libgcov counter-write errors or a nearly full disk (`YUZU_COVERAGE_MIN_FREE_KB`, default 262144) is reported as a WARN row with no metric and no baseline comparison, and `--capture-baselines` refuses it. An unknown line figure is no longer recorded as 0.0, a failed gate or metric DB write now fails the gate, a truncated baseline is reported as unreadable, and Ctrl-C or SIGTERM stops the running `meson test`.
