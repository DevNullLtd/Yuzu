- **The agent's log-error diagnostic thread no longer has a theoretical crash path if the OS-level `detach()` call itself throws.** The thread that writes `LogHandoff`'s stderr diagnostic (#5023) used to be created with `std::thread(...).detach()`; per the standard, `detach()` can itself throw, and if it did, the still-joinable temporary's destructor would call `std::terminate()` while unwinding, before the surrounding handler could run. The thread is now launched already-detached (`io_detail::spawn_detached`, the same primitive already used elsewhere in the agent for background work), so there is no joinable object and no separate `detach()` call to throw. No behavior change on the common path; this closes a narrow, previously-unobserved crash risk on thread-creation failure.
