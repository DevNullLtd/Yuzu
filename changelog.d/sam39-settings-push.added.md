- **Saved software collection settings now reach the machines and change what they do.** Each agent reports the version of the settings it last applied in its heartbeat; when that differs from the settings that apply to it, the server sends the document once, and the agent checks it, stores it and applies it: how often installed software is collected, in which window, and which collectors run. A change reaches a device within about a minute of the save plus one heartbeat (about ten minutes for a change in group membership); there is no push at the moment of saving. A collector switched off, by a document or by a plugin kill switch (including registered apps collection, which only a kill switch can stop), is not run and reports `disabled`. An interval of several days is placed one interval after the last clean sync, inside the window when one is set. A named time zone is stored and delivered but the window runs in the machine's own local time in this release, and the device says so in its heartbeat. The server must be upgraded before the agents. Delivery is counted by `yuzu_server_inventory_settings_push_total`, `yuzu_server_inventory_settings_push_degrade_total` and `yuzu_server_inventory_settings_reconcile_exceptions_total`, `__sync__.settings` is the fifth server-internal push that still reaches a contained device (changing only the agent's own collection schedule and collector switches), and the `YuzuInventorySettingsPushLoop` alert fires when the server keeps re-sending settings.
