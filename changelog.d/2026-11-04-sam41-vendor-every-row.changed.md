- **Every installed-software row now carries a publisher.** Each row an agent reports is labelled with the vendor its source declares (rpm `VENDOR`, falling back to `PACKAGER`; deb `Maintainer`; Windows `Publisher`; the macOS signing certificate; a Python interpreter's vendor; `Microsoft` for Windows optional features; `Homebrew` for the Homebrew presence row), and with the origin label `via:<ecosystem>` (for example `via:brew`, `via:snap`, `via:pacman`) where the source declares none, so the field is never empty. The server treats a `via:` label as no vendor: it is excluded from the catalogue's publisher total, a declared vendor is preferred as a title's representative publisher, and title matching ignores it. The software title dimension keys a title with no declared vendor under its `via:` label, not under an empty publisher.
