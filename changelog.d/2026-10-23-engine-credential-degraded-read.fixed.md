- **Engine credential mint and rotate fail closed when the token store cannot be read.** `POST /api/v1/engine-principals/{id}/credentials` now checks for an existing active credential through the checked read, and answers `503` with `Retry-After: 2` (minting nothing) when that read fails, so retrying after that failure is safe. `POST /api/v1/engine-principals/{id}/credentials/rotate` now reads the new successor back before it records the reveal; when that read fails it answers `503`, withholds the secret, writes an `engine_principal.credential.rotate` audit row with `result=partial` and no reveal row, instead of returning `200` with an empty `token_id`. A retry by the same operator within the grace window re-serves the same secret.
