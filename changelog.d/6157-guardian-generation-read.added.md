- **A read-only way to read the Guardian policy generation.** `GET /api/v1/guaranteed-state/policy-generation` and the MCP tool `get_guardian_policy_generation` return the server's policy generation and the largest target a raise accepts, so the value can be read before a raise target is chosen. They need `GuaranteedState:Read`, are refused for a service-scoped API token, and answer a degraded store with a `503` or a retryable error, never a generation of `0`.
