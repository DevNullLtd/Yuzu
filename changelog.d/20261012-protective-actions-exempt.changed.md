- **Breaking — a kill-switch row for `__guard__.push_rules` or a `quarantine.*` action no longer stops dispatch.** The quarantine plugin's `quarantine`/`unquarantine`/`status`/`whitelist` actions and the Guardian rule push (`__guard__.push_rules`) are now protective: exempt from the per-plugin/action kill switch, the per-OS switch and its agent-presence read, the plugin-presence filter and a degraded plugin-config store, so a quarantined device can no longer fail to be released because of plugin enablement. Stored kill-switch rows for these pairs are kept but inert, and a write to one is audited with `protective_exempt=true`. To stop Guardian rule delivery, disable or remove the rules. See [Upgrading](docs/user-manual/upgrading.md#behaviour-change-protective-actions-exempt-from-plugin-enablement) before upgrading.
