- **The plain-HTTP port answers the four health probes when HTTPS is on.** `GET /livez`, `/readyz`, `/health` and `/api/health` on the redirect port (8080 by default) are now served directly, to GET and HEAD requests, instead of answering `301`; every other request on that port still redirects. The HTTP port never resolves a session (`/health` always returns the unauthenticated shape) and answers `503` while the HTTPS listener is not bound.
