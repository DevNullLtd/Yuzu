- **`printing.clear_queue` resolves the effective user with the reentrant `getpwuid_r`.** The identity sent as `requesting-user-name` and the `Authorization: PeerCred` header no longer comes from `getpwuid()`'s shared libc static buffer, which concurrent agent commands (`users`, `filesystem.get_acl`) rewrite. The name is copied into an owned, ERANGE-growing buffer, and any failure still refuses to send (`no_identity`). The lookup is not time-bounded; a by-uid form of agent-core's bounded passwd lookup remains a follow-up (#4679).
