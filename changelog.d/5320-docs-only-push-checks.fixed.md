- **A docs- or changelog-only push to `main`/`dev` now gets the required CI checks (#5320).** `ci.yml`'s push trigger dropped its `paths` filter, so every push runs; preflight's `code_changed` gate skips the build matrix for a docs-only push, as it already did for a docs-only PR, and the required contexts appear on the commit as success or skipped instead of being absent. The v0.14.0 release commit was tagged without them because its only change was `CHANGELOG.md`. The skip also requires the previous commit's push run to have succeeded, so a docs commit never stands in for an unbuilt or failed code commit, and a push touching `docs/os-capability-matrix.md` still builds and runs its drift gate. The release skill's tag gate now says that skipped required checks count as passing and absent, failed or cancelled ones do not.
