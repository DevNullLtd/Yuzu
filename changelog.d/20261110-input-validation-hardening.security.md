- **Input-validation hardening across four seams.** The Windows agent reads each Java runtime's `release` file in one open relative to the drive root that refuses any link below the root, so a link in a directory leading to the file is never followed and the file reads as unreadable; a name spelled with `.`, `..`, an empty part or a trailing dot or space also reads as unreadable, and a Windows build that rejects the open reads every release file as unreadable and logs the cause once. The management-group owner check now has one definition used by the group role routes (REST and MCP) and by service-scoped token minting: it refuses service-scoped tokens and engine sessions on both transports and any MCP-tier session on REST, and a caller who is only the group's owner can remove only `Operator` and `Viewer` assignments. The Linux package inventory keeps an rpm or dpkg row when its vendor, packager or maintainer text contains a tab (the publisher is the text before the tab); the rpm query output now lists vendor and packager last. A wide-scope installs continuation is refused once it would pass over more than 100 000 rows outside the caller's scope since the last row served, with its own message asking the caller to narrow the filter.
