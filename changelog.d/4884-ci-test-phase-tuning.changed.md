- **CI test phase: per-case duration summary, Linux-only `docs` suite, faster preflight.** Each CI test invocation now appends a job-summary table of every meson entry's wall time and share of its timeout, plus the 25 slowest Catch2 test cases (from Catch2's own `--durations=yes`, reported once per case rather than per nested section); it is reporting only and never changes a pass or fail (#4884). The `docs` suite now runs on the Linux leg only; the four tests that pin OS-specific behaviour (`gateway build wrapper`, `instructions runner hardening`, `windows sdk contract`, `Windows toolchain contract`) moved to a new `platform` suite that runs on every leg. The runner-pool probe and docs-only gate now run in a short `preflight-gate` job so the compile jobs start sooner, while the required `Preflight (runner health)` check keeps its name and the source gates and fails closed if the gate did not succeed. Linux `dev` push legs now run four at a time (`max-parallel` 3 to 4), and a Linux-only probe step logs host RAM and the Postgres container's data size after the full pg run. Details: `docs/ci-architecture.md`.
