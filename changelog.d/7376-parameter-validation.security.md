- **Parameter validation.** A NUL byte in text bound into a database statement is now refused instead of being cut at that byte. At the edges this means: a gateway stream-status notification with a NUL in an identifier is rejected; the asynchronous result-set producers (REST and MCP) refuse a NUL in the name, the parameters or the parent set id before anything is dispatched, and the direct result-set create (REST and MCP) refuses a NUL in the name, the source kind or the parent set id; a directory-sync record with a NUL in a key field is skipped and counted, a NUL in a display field is replaced and the record kept, and a snapshot whose records would all be skipped is refused and leaves the roster unchanged; and a schedule create refuses a NUL byte or a value the store refuses as invalid text with `400`; a schedule create that fails after its write ran answers `503` with an unknown outcome and no retry hint. Where the surface allows it, invalid input (a control byte, invalid UTF-8) is answered with a client error rather than a server fault, including on the management-group member and role routes and MCP tools; a group that does not exist is `404` on REST and the invalid-params error `group not found` on MCP. Operations that refuse a write now report that outcome accurately, with no success audit row and no success response for a write that did not happen, across management-group member and role changes, OTA package upload and removal, schedule create, enable, disable and delete, and execution status updates. A NUL byte in an agent's failure text (other than a Forensics-tier plugin's, which is reduced to a bounded token) is stored and published as U+FFFD. An OTA upload whose registry write fails restores the previously published binary and signature sidecar (the previous files are kept as `*.yuzu_prev_*` copies until the registry write is confirmed (a crash, a failed restore or an unconfirmed write can leave one behind; the server administration guide has the checks for removing it)), and the Entra directory sync response and audit row report the counts that sync applied.
