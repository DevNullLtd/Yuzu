- **Per-OS plugin kill-switch rows.** The server-side plugin kill switch can now be narrowed per agent OS (`windows`/`linux`/`darwin`): a per-OS OFF row withholds dispatch of that plugin/action to agents of that OS, including agents connected through another replica, while other OSes keep the plugin-level state; a per-OS row only ever narrows, and existing plugin/action rows are unchanged on upgrade. The kill-switch REST routes and MCP tools accept an optional `os`. A dispatch withheld this way answers `503` with `reason: kill_switched_os` (or the transient `os_gate_unreadable` when agent presence cannot be read while a per-OS switch is set), and is recorded in the audit log as `command.dispatch_withheld` and counted on `yuzu_server_dispatch_target_rejected_total{reason="kill_switched_os"}`. Store schema `plugin_config_store` migration v2.
