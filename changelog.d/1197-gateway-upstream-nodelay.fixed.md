- **A gateway now registers agents much faster after a server restart on a large fleet (#1197).** Every `ProxyRegister` runs one at a time over one gateway-to-server connection, and that socket waited about 43 ms per call for Nagle's algorithm and the server's delayed ACK, so one gateway registered about 24 agents per second. In a rig test, 1000 agents registering at once left 297 past the agents' 30 s deadline, and 2000 took 776 s with 5.9 attempts per agent. The gateway now sets TCP_NODELAY on that channel by default. Set `upstream_tcp_nodelay` to `false` in the `yuzu_gw` section of `sys.config` to turn it off (no environment variable maps to it). Restart the gateway to deploy. Refs #1197.
