- **Software inventory store accepts the extended software row.** `installed_software` gains `install_location`, `uninstall_string`, `package_id` and `source` (the plugin action that produced the row) plus a row id for keyset paging (migration v7, additive). The ingest seam parses 16-field blob records while 4- and 12-field records from older agents still parse; the server-side canonical hash covers the new fields only when present, so existing agents keep hash-skipping. The store query gains a case-insensitive `q` filter over name, publisher, ecosystem and source, exact `kind`/`ecosystem`/`source` filters and a keyset cursor (store-level only; no REST/UI change in this release). Deploy the server before any agent that emits the new fields. On first start after upgrade the migration rewrites `installed_software` under an exclusive lock (roughly 20 s at 4M rows); start one server replica first and let it finish before starting the rest.
