- **`asset_tags` plugin: `init()` starts from the plugin's defaults.** `init()` now resets the store path, the cache and the check interval before reading its configuration, so a second `init()` in the same process (a test harness, or a loader that keeps the plugin image mapped across `dlclose`) keeps the documented 300 s default for a malformed `asset_tags.check_interval` instead of the previous lifecycle's value. No change for a running agent, which initialises the plugin once. The persist-failure counters stay process-lifetime, as documented (#6053).
