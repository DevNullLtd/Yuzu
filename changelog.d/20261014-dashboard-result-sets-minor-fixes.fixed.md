- **Dashboard and Result sets small fixes.** A Dashboard send to a scope expression that matches no connected agent now says "The expression matched no connected agent. Nothing was sent." instead of "No agents connected" while agents are connected. The Result sets producer picker no longer says its list is cut when exactly 200 definitions exist (it now asks for one more than it shows). The members list's "Show more" link percent-encodes its cursor, so a device id containing `&`, `#`, `+`, `=`, `%` or a space pages correctly. Ctrl+K and Ctrl+Enter no longer open the palette or send the instruction while the cursor is in the scope expression field.
