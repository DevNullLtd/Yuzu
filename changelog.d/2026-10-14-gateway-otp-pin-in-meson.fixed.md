- **Meson builds of the gateway use the pinned Erlang/OTP, resolved at configure.** `meson setup` now finds an Erlang/OTP 28.4-or-later-28.x install itself (PATH, kerl, asdf, mise, Homebrew `erlang@28`, distro prefixes, the Windows installer under `C:\Program Files`) and the gateway build and tests run on it, so a newer OTP first on PATH (Homebrew `erlang` 29) no longer breaks the build and no `source scripts/ensure-erlang.sh` is needed first. `ensure-erlang.sh` now uses the same resolver and checks the version instead of accepting any working `erl`. The rebar3 compile output is written to `meson-logs/yuzu_gateway_build.log` on every platform, not only Windows, and every script target on Windows runs on the native Python that runs Meson instead of MSYS2's. Released gateway artifacts are unaffected: they are built by rebar3 directly.
