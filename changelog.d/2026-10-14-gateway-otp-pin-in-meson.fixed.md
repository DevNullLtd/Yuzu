- **Gateway builds use the pinned Erlang/OTP, resolved by Meson.** `meson setup` now finds an OTP 28.4-or-later-28.x install itself (PATH, kerl, asdf, mise, Homebrew, Windows installers) and the gateway build and tests run on it, so a newer OTP first on PATH (Homebrew `erlang` 29) no longer breaks the build and no `source scripts/ensure-erlang.sh` is needed first; a `rebar3` with no matching OTP now skips the gateway with a warning (an error under `-Drequire_gateway=true`). `ensure-erlang.sh` checks the version too instead of accepting any working `erl`. The rebar3 compile output is now written to `meson-logs/yuzu_gateway_build.log` on every platform, not only Windows, and Windows script tests run on the native Python Meson itself runs under instead of MSYS2's.
