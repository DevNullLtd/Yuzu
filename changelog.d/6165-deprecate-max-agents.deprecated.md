- **`--max-agents` / `YUZU_MAX_AGENTS` is deprecated and has no effect (#6165).** The limit was never enforced. Setting it explicitly now logs one startup warning; the `max_agents` field stays in `GET /api/v1/settings/server-config` (marked deprecated) and the flag will be removed in a future release. There is no replacement: the server does not cap how many agents connect; spread a large fleet across gateways. Do not use `--grpc-max-threads` to limit agents: it is a fleet-size ceiling that must stay above the connected-agent count (size it at about 1.5x that count); set below it, every RPC fails.
