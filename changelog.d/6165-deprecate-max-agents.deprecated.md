- **`--max-agents` / `YUZU_MAX_AGENTS` is deprecated and has no effect (#6165).** The limit was never enforced. Setting it explicitly now logs one startup warning; the `max_agents` field stays in `GET /api/v1/settings/server-config` (marked deprecated) and the flag will be removed in a future release. The server does not cap the number of connected agents; bound load with `--grpc-max-threads` and `--grpc-max-resource-memory-mb`.
