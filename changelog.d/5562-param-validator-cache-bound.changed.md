- **The compiled-validator cache behind `POST /api/instructions/{id}/execute` is now bounded by estimated retained memory (128 MiB in total, 32 MiB per entry) as well as by entry count (4096), and is owned by the server rather than created per route registration.** A definition whose `parameter_schema` would weigh more than 32 MiB (for example one declaring many large `pattern` constraints) is still validated correctly but is rebuilt on every execute call instead of being kept, so it can no longer evict the validators of every other definition; the shipped catalogue uses about 27 MiB. Nothing changes for clients. Single-flight rebuilds, hit and eviction counters and a retained-bytes gauge are not part of this change and are tracked in #5562.
