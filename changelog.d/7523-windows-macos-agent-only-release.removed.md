- **Breaking: the Windows server installer (`YuzuServerSetup-*.exe`) is discontinued, and the Windows and macOS release archives now hold the agent only and are renamed.** The server is supported on Linux only (ADR-0035): run it from the container image or the Linux `.deb`/`.rpm` packages. The archives are now `yuzu-agent-windows-x64.zip` and `yuzu-agent-macos-arm64.tar.gz` (previously `yuzu-windows-x64.zip` and `yuzu-macos-arm64.tar.gz`, which also held `yuzu-server`), with matching SBOM names, and the top-level directory inside each archive is renamed the same way; update any script that downloads or unpacks them by name. To move an existing Windows or macOS server to Linux, follow "Moving a Windows or macOS server to Linux" in the server administration guide: the old server's data cannot be carried over, so you deploy a new Linux server, enroll agents with it as new installations, and delete the old server's leftover files, which hold secrets. Known limitation: the Windows and macOS SBOMs are generated from the whole build workspace, so they can list components the archive does not ship.
