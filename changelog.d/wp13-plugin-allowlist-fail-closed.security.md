- **Breaking —** **A configured agent plugin allowlist that is missing, unreadable, empty or in the wrong format now stops the agent instead of disabling the check.** With `--plugin-allowlist` set, a missing file, an unopenable file or one with no `<64 hex sha256>  <filename>` line used to load every plugin unverified (a missing file logged nothing, and a permission fault on the path's parent crashed the start). The agent now logs a critical line and exits non-zero before loading any plugin, as `--plugin-require-signature` without a trust bundle already did; a UTF-8 BOM, CRLF and the `sha256sum` `*` marker are accepted. Check the allowlist before starting an agent that has one. Under systemd, after fixing the file, run `systemctl reset-failed yuzu-agent`. See the WP13 section of `docs/user-manual/upgrading.md`.
