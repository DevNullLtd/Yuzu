- **A configured agent plugin allowlist that is missing, unreadable or empty now stops the agent instead of disabling the check.** With `--plugin-allowlist` set, a missing file, an unopenable file or a file with no parseable line used to load every plugin unverified (a missing file logged nothing, and a permission fault on the path's parent crashed the start). The agent now logs a critical line and exits before loading any plugin, as `--plugin-require-signature` without a trust bundle already did. Fix or remove the setting before upgrading an agent that has one. See "Upgrading".
