- **A very long field value no longer drops every facet of a command response.** A single field value of a few KB or more (the database cannot index it) made the whole facet insert fail, so that agent silently fell out of the dashboard facet filter, group-from-results and the agent-count preview. Facet values over 1,024 bytes are now left out of the facets (the response and its other facets are kept), the per-response 5,000-facet limit now keeps the most frequent facets in a fixed order instead of whichever the server happened to hold first, and the new `yuzu_server_response_facets_dropped_total{reason}` counter makes dropped facets visible.
