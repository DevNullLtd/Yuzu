- **Opening a stored instruction definition in the editor can no longer run script or hang the server.** The editor filled its form template in several passes over text that already contained stored field values, so a definition whose name, description, YAML or concurrency mode carried a `{{PLACEHOLDER}}` token could inject unescaped markup into the page (stored cross-site scripting in the dashboard session of whoever opened it) or make a server worker loop forever (denial of service). The editor now fills the template in a single pass and escapes every stored value, so such text is shown literally.
