Source
------
https://github.com/cytoscape/cytoscape.js (release 3.33.3)
npm tarball: https://registry.npmjs.org/cytoscape/-/cytoscape-3.33.3.tgz
Vendored file: server/core/static/cytoscape.min.js, byte-identical to the
tarball's dist/cytoscape.esm.min.mjs (the ESM build, so the importmap in
viz_host_page_ui.cpp can resolve `import cytoscape from "cytoscape"`).

Integrity
---------

Recompute with `shasum -a 256 server/core/static/cytoscape.min.js`. The test
suite pins the byte count (see kExpectedCytoscapeJsBytes in
tests/unit/server/test_static_js_bundle.cpp). When refreshing the upstream
release, update both this hash and the byte-count constant in lock-step.
