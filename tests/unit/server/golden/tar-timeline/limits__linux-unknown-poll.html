What this record cannot tell you

  • There is no starting snapshot: TAR records what it sees from the time it was switched on, so what was already running then has no recorded start.
  • The record is read on the agent's polling interval, not continuously.
  • Processes are read on the agent's polling interval; a process that starts and exits between reads is missed, and start times are snapshot times.
  • TAR does not record file changes or the content of alerts.
  • The limits shown are the agent's defaults.
