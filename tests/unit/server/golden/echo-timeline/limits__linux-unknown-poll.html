What this record cannot tell you

  • There is no starting snapshot: Echo records what it sees from the time it was switched on, so what was already running then has no recorded start.
  • The record is read on the agent's polling interval, not continuously.
  • The agent did not state how processes are captured. If it polls, a process that starts and exits between reads is missed and start times are snapshot times.
  • Echo does not record file changes or the content of alerts.
  • The limits shown are the agent's defaults.
