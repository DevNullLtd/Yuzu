# DEX score policy core Resource Ledger (governance Gate 1)

Production-code ledger for the score policy core, kept here so the ownership analysis is retrievable with the change. Files: `server/core/src/dex_score_policy.hpp` (new, std-only, header-only), `server/core/src/dex_stability_score.hpp` (a defaulted band-edges parameter, `stability_edges_valid` and the `invalid_edges` withheld reason) and the tests `tests/unit/server/test_dex_score_policy.cpp` and `test_dex_stability_score.cpp`.

## Resource Ledger (C++)
- No file descriptor, handle, socket, `FILE*`, sqlite or Postgres object, OpenSSL object, allocated C string, mapped library, temp-file path, subprocess, shell string, thread, lock or callback context is acquired, owned or released by any new code. Every type is a value type (`std::string`, `std::array`, `std::optional`, `std::vector`, trivially copyable structs of doubles).
- Borrowed data: `resolve_dex_score_policy` takes a `std::string_view` image name and copies it at once (`ascii_lower`), nothing stores the view; the result `DexEffectivePolicy` owns its strings and copies the policy's tiers and weights, so reallocation or destruction of the source policy cannot affect a held result. `dex_tier_name` returns a `const std::string&` into its argument: the rvalue and const-rvalue overloads are deleted, with compile-time locks in the tests, so a temporary can never be bound. The compile-time locks are guards, not runtime witnesses.
- Static state: one function-local `static const DexScorePolicy` in `dex_default_score_policy()` (thread-safe initialisation, no dependency on another static, never read from a static destructor); the default tier names are copied from `stability_band_label` literals.
- Casts and cleanup: only `static_cast<unsigned char>` / `static_cast<char>` on bytes and `static_cast` of an enum to an index; no `reinterpret_cast`, `const_cast`, raw `new`/`delete`, manual cleanup or early-return release path exists.
- Integer and floating-point hazards: `llround` runs only on edges already proven finite, in (0,100) and exact at one decimal; no signed overflow is reachable; `std::signbit` guards negative zero. Sanitiser evidence: the real test files were compiled and run under AddressSanitizer and UndefinedBehaviorSanitizer (including float-cast-overflow and integer groups) with no report in repository code; a ThreadSanitizer run over concurrent validate/resolve/default-policy calls reported nothing.
- Tests (harness only): memory-only, no temp files, no sleeps, no sockets, no threads; the random sweeps use a fixed-seed `std::mt19937` with a modulo mapping that is deterministic across standard libraries.
