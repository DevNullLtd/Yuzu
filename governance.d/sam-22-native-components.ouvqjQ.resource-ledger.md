## Decision lines

- **Per-run bounds.** One `native` run: at most 400,000 directory entries, 45 seconds, 5,000 rows; per file at most 128 ELF program headers, 64 KiB of dynamic section, 256 KiB of Mach-O load commands, 16 fat slices, a 255-byte name. A count or size past a bound makes that one file `unreadable`, never a partial answer.
- **Default off.** One new kill-switch row, an action-level row for `component_inventory.native`, seeded `enabled=false` at boot with `ON CONFLICT DO NOTHING`; `component_inventory.scan` is not affected and a restart never overwrites an operator's own row.
- **Windows.** Not in this change: the plugin has no Windows filesystem leg, so the Windows `native` answer is the shared planned-leg reporter and no resource is held for it.
