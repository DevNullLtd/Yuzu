# Resource Ledger: 7112-echo-dashboard-audit-followups

Every owning boundary the C++ in this branch acquires: the Echo purge and re-enable repeat bound (`EchoActionCooldown` and its `Slot`), the typed per-device gate `std::function` carried into `DashboardRoutes` and `RestApiV1`, and the throwaway response the gate helper writes to. The diff adds no fd, handle, socket, `FILE*`, SQLite or OpenSSL object, thread, subprocess or temp path.

## Decision lines

- **The cooldown is per server process.** It is not shared across replicas; the repeat bound is one dispatch per action, device and source per 30 s on one process. It is an availability limit, not a bypass.
- **No new OS resource.** The only synchronisation added is the one `std::mutex` in R1, taken for a map operation and never across a dispatch, an audit write or a store read.
