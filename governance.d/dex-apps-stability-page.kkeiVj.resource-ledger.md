## Exception behaviour

The renderer and the handler contain no `try`/`catch`. The only exception reachable is `std::bad_alloc` from `std::string` growth or `std::format` (the format strings are constant, so no `std::format_error`). One thrown out of `dex_api_->apps()` or the renderer leaves the handler, and httplib answers 500 with an empty body that htmx drops: the same posture as the REST twin and every other fragment (cps-F1; the comment at `dex_routes.cpp:2509` now says model-level failures are a 200 panel and anything thrown is not). Making a throwing read visible is tracked as #7520.

## Facts corrected against the code at HEAD (76c9455de)

The brief and the Gate 1 Change Summary were checked against `git show HEAD:...`. Corrections:

- `kAppsCss` and `kThead` are `const char* const` in an anonymous namespace (internal linkage), not `static const char* const`; the effect is the same. `kWindows` is a function-local `static const` array, as described.
- `set_dex_api` stores a `std::shared_ptr<const DexApi>`, not a raw pointer (the Change Summary said raw; cps-F3).
- `dex_api` is a local of `start_web_server()`, not a `ServerImpl` member. The holders are `dex_routes_->dex_api_`, `mcp_server_`, the REST registration and by-value captures.
- Member destruction order is the reverse of declaration, so `dex_routes_` destructs BEFORE `guaranteed_state_store_` and `web_server_`. That is safe only because `web_server_->stop()` ends every handler first (R5); it is not an ordering guarantee between those members.
- The dev merge 155e42488 DID touch two files this change also touches: `docs/user-manual/rest-api.md` and `server/core/src/rest_api_v1.cpp` (it merged cleanly; the change's `rest_api_v1.cpp` hunk is one OpenAPI description string). It touched none of `dex_apps_ui.*`, `dex_routes.*`, `dex_read_model.hpp` or the `server.cpp` wiring site. The governance fix later edited three more files that dev also changed (`docs/ci-architecture.md`, `docs/enterprise-readiness-soc2-first-customer.md`, `docs/user-manual/upgrading.md`), none of them C++.
