## Decision lines

- **Per-run bounds.** One run: at most 400,000 directory entries, 45 seconds, 3,000 rows per application folder and 20,000 rows in all; python depth 8, node nesting 8 `node_modules`; one 16 KiB (python) or 64 KiB (node) read per candidate; name 256 bytes, version 128 bytes.
- **Enabled by default.** No kill-switch seed for either action (owner default (c), plan gate 2026-11-21); an operator can still switch either off through the generic plugin-config kill-switch route.
- **Windows.** Not in this change: the Windows answer is the shared planned-leg reporter; a separate PR (sam-49-windows) adds the leg.
