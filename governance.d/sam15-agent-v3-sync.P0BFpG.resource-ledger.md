The only new threads are the detached collector workers of R1, bounded by the per-action limit and drained before any plugin is unloaded.

## Decision lines

- **Workers are drained, never joined.** A worker abandoned at its time limit may stay inside a plugin for as long as the plugin keeps it; the single-flight flag stops a second worker piling in (`busy`), and the barrier turns a worker that never returns into a hard exit at shutdown rather than an unload under it. A plugin that never returns therefore makes the restart a hard exit; this is disclosed in the ADR Update and the user manual.
- **No weekly full resend.** The source sets `SyncSource::no_full_floor`; the server's per-section base and `expect` checks answer a diverged section with `installed_software:<facet>`, which the agent resends in full.
