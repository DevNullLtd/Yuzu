## Summary verdict

Production: no new fd, `FILE*`, SOCKET, `sqlite3*`/`sqlite3_stmt*`, OpenSSL object, BCrypt handle, allocated C string, subprocess, temp path, mapped library, callback context or thread. The owned things
are: one `std::mutex` (`discovery_mu_`) plus a `bool` in-flight flag and three plain value members it guards, one `std::atomic<int>` timeout, a stack-local `std::unique_ptr<httplib::Client>` per GET and per
token POST (owns the socket and, for https, the SSL context), one `std::unique_lock` local in `ensure_discovered` that is released and re-taken around the network call, by-value strings, `std::optional` and
`std::expected` results, and file-local `std::string_view`s that borrow only from string literals or from a parameter that outlives them. Everything is released by destructors (`std::unique_lock`,
`std::lock_guard`, `std::unique_ptr`, `std::string`, `std::optional`). No `new`/`delete`/`malloc`/`free`/`release()`/`detach()`/`goto` was added in production. Three value `static_cast`s were added
(`unsigned char` for `std::isxdigit` and for the UTF-8 continuation test, and `unsigned` for the port digit): no pointer or reinterpreting cast. The one explicit release is `client.reset()` in two places
(rows P4 and P20), on an RAII owner, kept from the code it replaces. The removed `exchange_script` plumbing was dead (the old constructor copied the path into a member that nothing read,
`cc73504a8:oidc_provider.cpp:1055`), so removing it releases nothing and starts nothing; the Python script itself is still in the tree (row F5).

Tests: the `MockIdp` acceptor thread (joined in the destructor body) gains a chunked trickle writer paced by a condition variable that the destructor signals first (rows T1, T2). Test worker threads are now
`std::jthread` (rows T6, T9, T10), never a bare `std::thread`; the one policy-floor finding of the first ledger (F1, a bare `std::vector<std::thread>`) is closed. No temp file, no env var, no fixed-port BIND was
added; one fixed-port CONNECT target (`127.0.0.1:1`) is used by two cases (F4).
