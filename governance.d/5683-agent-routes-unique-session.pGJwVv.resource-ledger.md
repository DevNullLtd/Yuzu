Compares against `GatewayRouteStore::kSessionUniqueIndexName`, a `static constexpr std::string_view` over a string literal (static storage, implicitly inline).
- Constructor additions: reuse the one `PgPool::Lease` taken at construction for `current_version`, `run` and a `pg::PgResult meta` (move-only RAII) that reads `route_meta` by the explicit key `v5_session_dedup_tombstoned_rows`; `v`/`end` borrowed from `meta` and consumed by `std::from_chars` (checks `ec`, `ptr == end`, `>= 0`; `PQgetisnull` first) before `meta` dies; no second acquire; every return path is covered by the lease RAII; a failed or unparsable read logs a WARN (migrating start) or is ignored (later starts) and can never prevent `open_ = true`. `boot_session_dedup_rows_` (int64) is written only in the constructor and read through a `noexcept` accessor on the same thread in `ServerImpl`'s constructor.
