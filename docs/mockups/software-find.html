Design choices to review

  1. Placement. The panel is the first block on /software, above the KPI strip, because it is the CISO's first action.
  2. Unconfirmed apart. Unconfirmed installs never enter the count cards; they get their own dashed box and stay in the table, marked by status.
  3. Python and Node chips. Assumed to share the Java component layout (state 3); Applications is the only installs view.
  4. Version labels. pom.properties, MANIFEST.MF and file name are sample values for the “read from” tag.
  5. New styling. Limited to fs-* (panel head, version group row, path truncation, unconfirmed box); everything else reuses the page's inv-*, hw-*, gp-* and pill classes.
